= Пользовательские сессии

Дополнение Audit включает бин `UserSessions`, который предоставляет детальную информацию о текущих активных пользовательских сессиях.

Кроме того, дополнение содержит экран, который отображает активные сессии и позволяет их завершать. Этот экран доступен через пункт главного меню *Audit → User sessions*.

Дополнительную информацию о сессиях смотрите в разделе xref:security:authentication.adoc#user-session[Аутентификация: Пользовательская сессия].
