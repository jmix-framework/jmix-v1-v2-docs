The `Dialogs` interface is designed to display standard dialog windows. A dialog window is a small popup window that you can use to present information and user interface elements in an overlay.

The `createMessageDialog()`, `createOptionDialog()`, and `createInputDialog()` methods are the entry points to the fluent API that allows you to construct and show dialogs.

[NOTE]
====
When using the `InputParameter.withField()` method, only the `label` attribute from the `InputParameter` is propagated to the created field. Other attributes set on the `InputParameter` are *not* automatically applied to the field created inside the `withField()` lambda.

The following `InputParameter` attributes are *not* propagated when using `withField()`:

- `required`
- `requiredMessage`
- `datatype`
- `defaultValue`

=== Position and Size

Use `withSideDialogPosition()` to define where the dialog appears. Possible values are `RIGHT`, `TOP`, `BOTTOM`, `LEFT`, `INLINE_START`, and `INLINE_END`. The default value is `RIGHT`. `INLINE_START` and `INLINE_END` follow the text direction (LTR/RTL).

The dialog size is configured differently depending on its orientation.

For horizontal dialogs (`LEFT`, `RIGHT`, `INLINE_START`, `INLINE_END`):

* `setHorizontalSize()`
* `setHorizontalMaxSize()`
* `setHorizontalMinSize()`

For vertical dialogs (`TOP`, `BOTTOM`):

* `setVerticalSize()`
* `setVerticalMaxSize()`
* `setVerticalMinSize()`

=== Content

You can define dialog content using providers:

[cols="1h,4", grid=rows]
|===
|Method |Description
|`withContentComponents()`
|Provides components for the dialog content area.
|`withHeaderProvider()`
|Provides custom components for the header.
|`withFooterProvider()`
|Provides custom components for the footer.
|===

=== Events

The following events are available:

[cols="1h,4", grid=rows]
|===
|Event |Description
|`SideDialogOpenedChangeEvent`
|Fired when the dialog is opened or closed.
|`SideDialogCloseActionEvent`
|Fired when the user presses `Esc` or clicks outside the dialog. You can use this event to control whether the dialog should close.
|===

=== Styling

Side dialog appearance and sizing can be customized using CSS.

==== Sizing

You can configure dialog size globally using CSS variables. These values are applied to all `SideDialog` instances.

NOTE: If sizes are set programmatically with Java API, they take precedence over CSS variables.

Horizontal sizing (for `LEFT`, `RIGHT`, `INLINE_START`, `INLINE_END`):

[cols="2h,3,1", grid=rows]
|===
|Variable |Description |Default
|`--jmix-side-dialog-horizontal-size`
|Base horizontal size of the dialog.
|`auto`
|`--jmix-side-dialog-horizontal-max-size`
|Maximum horizontal size.
|`50%`
|`--jmix-side-dialog-horizontal-min-size`
|Minimum horizontal size.
|`16em`
|===

Vertical sizing (for `TOP`, `BOTTOM`):

[cols="2h,3,1", grid=rows]
|===
|Variable |Description |Default
|`--jmix-side-dialog-vertical-size`
|Base vertical size of the dialog.
|`auto`
|`--jmix-side-dialog-vertical-max-size`
|Maximum vertical size.
|`50vh`
|`--jmix-side-dialog-vertical-min-size`
|Minimum vertical size.
|`16em`
|===

==== Appearance

[cols="2h,3,1", grid=rows]
|===
|Variable |Description |Default
|`--jmix-side-dialog-transition-duration`
|Animation duration of dialog opening and closing.
|`200ms`
|===

[[with-modal]]
* `withModal()` - when set to `false`, displays the dialog as non-modal, allowing interaction with other application components. Dialogs are modal by default.

[[with-themeName]]
* `withThemeName()` - sets the dialog's theme name(s), replacing any previously set values.

[[with-className]]
* `withClassName()` - sets the CSS class name(s) for the component, replacing all previously defined classes.

[[with-draggable]]
* `withDraggable()` - sets whether dialog is enabled to be dragged by the user or not. Dialogs are draggable by default.

[[with-resizable]]
* `withResizable()` - sets whether dialog can be resized by user or not.
By default, the dialog is not resizable.

[[with-min-max-sizes]]
* `withMinWidth()`, `withMaxWidth()`, `withMaxWidth()`, `withMaxHeight()` - set the dialog's minimum/maximum width and height dimensions respectively.

[[with-closeOnOutsideClick]]
* `withCloseOnOutsideClick()` - controls whether clicking outside the dialog closes it. By default, the dialog is closable with an outside click.

[[with-closeOnEsc]]
* `withCloseOnEsc()` - controls whether pressing `ESC` closes the dialog. By default, the dialog is closable with `ESC`.

[[with-draggedListener]]
* `withDraggedListener()` - registers a callback invoked after user dragging completes. It is called only if dragging is enabled.
