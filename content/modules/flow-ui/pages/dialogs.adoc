`Dialogs` 接口用来展示标准的对话框窗口。对话框窗口是一个小的弹出窗口，可以在当前页面叠加展示信息或者 UI 元素。

使用流式接口可以创建和展示对话框，入口方法是 `createMessageDialog()`、`createOptionDialog()` 和 `createInputDialog()`。

[NOTE]
====
当使用 `InputParameter.withField()` 方法时，只有 `InputParameter` 中的 `label` 属性会自动传递给创建的字段。其他在 `InputParameter` 中设置的属性不会 *自动* 应用到通过 `withField()` 创建的字段中。

使用 `withField()` 时，`InputParameter` 属性中的下面这些不会 *自动* 应用：

- `required`
- `requiredMessage`
- `datatype`
- `defaultValue`

这是因为，开发者需要对通过 lambda 方法手动创建的字段全权负责。因此，除了 `label` 外，所有额外的设置必读显式地配置。

[[dialog-configuration]]
== 对话框配置

可以通过下面的方法自定义对话框的标题、大小、位置：

[[with-header]]
* `withHeader()` - 设置标题。

[[with-width]]
* `withWidth()` - 设置对话框的宽度。

[[with-height]]
* `withHeight()` - 设置对话框的高度。

[[with-left]]
* `withLeft()` - 设置对话框与其外部容器的左边距（无单位值按像素处理）

[[with-top]]
* `withTop()` - 设置对话框与其外部容器的上边距（无单位值按像素处理）

示例：

----

----

特定的对话框类型还有些额外的外观和行为设置：

[[with-text]]
* `withText()` - 设置对话框显示的文本信息。

[[with-content]]
* `withContent()` - 设置对话框的内容。这里的文本会通过 `Paragraph` 组件渲染。注意，这个设置会覆盖 `withText()` 的设置。
+
[NOTE]
====
文本格式支持 HTML - 即，调用 `withContent()` 方法可以在对话框显示 HTML 内容。此时，HTML 文本内容需要通过一个组件封装：

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/dialogsandnotifications/dialogs/DialogsSampleView.java[tags=inject-dialogs;messageDialog-html]
----
====

[[with-modal]]
* `withModal()` - 设置为 `false` 时，对话框以非模态窗展示，此时可以与应用程序的其他 UI 组件交互。对话框默认以模态窗显示。

[[with-themeName]]
* `withThemeName()` - 设置组件的主题样式名称，覆盖之前设置的任何值。

[[with-className]]
* `withClassName()` - 设置组件的 CSS 类名称，覆盖之前设置的任何值。

[[with-draggable]]
* `withDraggable()` - 设置对话框是否可拖动。对话框默认可拖动。

[[with-resizable]]
* `withResizable()` - 设置对话框是否可手动调节大小。
对话框大小默认不能调。

[[with-min-max-sizes]]
* `withMinWidth()`、`withMaxWidth()`、`withMaxWidth()`、`withMaxHeight()` - 分别设置对话框的最小、最大宽度和高度。

[[with-closeOnOutsideClick]]
* `withCloseOnOutsideClick()` - 是否可以通过点击对话框外部区域关闭对话框。默认支持该行为。

[[with-closeOnEsc]]
* `withCloseOnEsc()` - 是否可以通过按下 `ESC` 关闭对话框。默认支持该行为。

[[with-draggedListener]]
* `withDraggedListener()` - 注册一个用户拖拽的监听器，拖拽完成后调用。仅当启用拖拽时有效。
+
NOTE: 默认情况下，组件会在拖拽后提供所在位置的 top/left 值。
+

+

----

----

NOTE: 默认情况下，组件会在每次改变大小后提供 top/left 和 width/height 值。
