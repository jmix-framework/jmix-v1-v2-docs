= 用户菜单操作
:page-aliases: actions/standard-actions/user-menu-substitute-user-action.adoc,actions/standard-actions/user-menu-theme-switch-action.adoc

用户菜单操作通过 xref:vc/components/userMenu.adoc#actionItem[actionItem] 在 xref:vc/components/userMenu.adoc[] 组件中使用。

下面是标准的用户菜单操作类型。

[[sec_userMenuSubstituteUser]]
== sec_userMenuSubstituteUser

操作类：`UserMenuSubstituteUserAction`

根据替代用户的数量不同，打开一个查找视图选择替代用户或显示一个包含所有替代用户的子菜单。

image::actions/standard-actions/user-menu-substitute-user-action.png[align="center",width="474"]

TIP: 可以用 `jmix.security.ui.substitute-user-action-max-substitutions` 应用程序属性指定当替代用户数小于这个数量时，显示子菜单而非查找视图。默认值是 5。

[[userMenu_themeSwitch]]
== userMenu_themeSwitch

操作类：`UserMenuThemeSwitchAction`

提供一个子菜单，用于切换主题：*light*、*dark* 和 *system*。

image::actions/standard-actions/user-menu-theme-switch-action.png[align="center",width="400"]

`userMenu_themeSwitch` 需要导入一个 JavaScript 文件，负责在 HTML 中应用所选的主题。可以依据：Web 本地存储（Local Storage）中保存的值；如果用户选择根据系统变化，则订阅 https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-color-scheme[prefers-color-scheme^]；以及 user agent 的设置。
