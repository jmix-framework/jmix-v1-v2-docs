= 自定义操作类型

在项目中可以新建自定义操作类型或者重载已有的标准操作类型。之后这些自定义的操作可以在应用程序的所有视图中使用，如下面的示例所展示的。

== BaseAction

可以创建自定义的操作，然后分配给一个组件。下面是一个简单的示例，点击按钮显示 “Hello”。

. 创建一个操作类，继承自 `BaseAction` 然后添加 `@ActionType` 注解，设置操作类型名称：
+
[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/actions/MyCustomAction.java[]
----
+
NOTE: 如果需要重载已有类型，只需要在 `@ActionType` 注解中使用相同的类型名称注册新的操作即可。
+
. 现在可以在视图中通过指定操作类型使用该操作：
+
[source, xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/department/department-list-view.xml[tags=my-action]
----
+
. 为组件设置新操作：
+
[source, xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/department/department-list-view.xml[tags=action-button]
----
