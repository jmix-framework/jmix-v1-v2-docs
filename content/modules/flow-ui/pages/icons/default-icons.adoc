There are two default icon sets: Vaadin and Lumo. You can view all available icons from these sets by visiting https://demo.jmix.io/ui-samples/sample/icon-all[live demo^].

[[declarative-usage]]
== Declarative Usage

Set an icon for a component with the `icon` attribute. Use the `vaadin:` and `lumo:` prefixes for different icon sets. If no prefix is present, the Vaadin set is used.

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative]
----

When set through the Studio component inspector, the *Choose Icon* dialog appears, displaying icon names and preview for easier selection:
