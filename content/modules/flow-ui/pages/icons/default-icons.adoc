Есть два стандартных набора иконок: Vaadin и Lumo. Вы можете увидеть все доступные иконки из этих наборов, посетив https://demo.jmix.ru/ui-samples/sample/icon-all[демо-приложение^].

[[declarative-usage]]
== Декларативное использование

Установите иконку для компонента с помощью атрибута `icon`. Используйте префиксы `vaadin:` и `lumo:` для разных наборов иконок. Если префикс отсутствует, используется набор Vaadin.

----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative]
----

При установке через инспектор компонентов Studio появляется диалоговое окно *Choose Icon*, которое отображает названия иконок и их превью для удобного выбора:
