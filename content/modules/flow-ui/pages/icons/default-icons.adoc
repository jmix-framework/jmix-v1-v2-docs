有两组默认的图标：Vaadin 和 Lumo。可以从 https://demo.jmix.io/ui-samples/sample/icon-all[在线示例^] 中查看这两个图标集中的所有图标。

[[declarative-usage]]
== 声明式用法

为带有 `icon` 属性的组件设置图标。使用 `vaadin:` 和 `lumo:` 前缀引用不同分组内的图标。如果不带前缀，则默认使用 Vaadin 图标集。

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative]
----

当通过 Studio 的组件属性面板配置图标时，在 *Choose Icon* 对话框中会显示图标的名称和预览，以便进行选择：
