= Пользовательские иконки

Дополнительные иконки можно добавить в виде SVG-спрайта или отдельных иконок и использовать вместе со встроенными наборами.

[[icon-set]]
== Набор иконок

SVG-спрайт — это коллекция SVG-изображений, загружаемых в приложение как единый файл, что обеспечивает лучшую производительности. Вы можете создать спрайт вручную или с помощью сторонних инструментов.

Чтобы добавить набор иконок, выполните следующие шаги:

. Создайте JavaScript-файл для вашего набора иконок в директории `/frontend/icons/`. Используйте следующий код как пример создания набора, содержащего три иконки:
+
.my-icons.js
[source,javascript,indent=0]
----
include::example$/onboarding/frontend/icons/my-icons.js[tags=my-icons-sprite]
----
+
. Создайте Java enum, реализующий `IconFactory` и добавьте ему аннотацию `@JsModule` со ссылкой на JavaScript-файл:
+
.MyIcons.java
[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/icons/MyIcons.java[tags=my-icons-enum]
----

Теперь пользовательские иконки можно использовать так же, как стандартные:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=sprite]
----

image::icons/sprite-icons.png[align="center", width="125"]

Или установить их для компонента в Java-коде:

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/icons/IconsView.java[tags=programmatic-sprite]
----

== Отдельная иконка

Отдельные иконки можно добавить в директорию статического контента. По умолчанию Spring Boot обслуживает статические ресурсы из следующих путей в classpath: `/static`, `/public`, `/resources` или `/META-INF/resources`. Для удобства организации иконок можно создать подкаталог `META-INF/resources/icons`.

Чтобы использовать статический ресурс, воспользуйтесь компонентом `svgIcon`:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative-standalone-1]
----

Чтобы установить иконку для компонента, используйте его xref:flow-ui:vc/miscellaneous/prefix-suffix.adoc[префиксные или суффиксные] элементы. Например, чтобы разместить иконку перед текстом кнопки:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative-standalone-2]
----

Или воспользуйтесь программным подходом:

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/icons/IconsView.java[tags=programmatic-standalone]
----
