= 添加更多图标

额外的图标可通过三种方式添加：作为图标字体、作为 SVG sprite 或以独立的 SVG 文件添加。

[[icon-fonts]]
== 图标字体

图标字体是一种以字体形式提供的图标集合。图标作为该字体中的字符进行渲染。

TIP: 添加自定义图标字体后，可以使用它来覆盖默认的应用程序图标。详细信息请参考 xref:icons/override-icons.adoc[]。

如需添加图标字体，需要提供以下信息：

* 一个字体文件 - 通常是 `.woff` 或 `.woff2`，或者较旧的格式如 `.ttf` 或 `.eot`。
* 一个 `@font-face` 声明 - 通常主题主样式表（`styles.css`）中导入的自定义样式表里。
* 可选，一个包含图标 CSS 类的样式表 - 通常与 `@font-face` 声明一起添加，并同样导入到 `styles.css` 中。

这个示例演示如何在 xref:flow-ui:themes/themes.adoc#application-theme[应用程序主题] 中添加 Material 图标。

在主题的文件夹下创建一个目录，包含：

* `material-icons-outlined.woff2`
* `outlined.css` – 包含 `@font-face` 声明以及图标的 CSS 类：
+
.outlined.css
[source,css]
----
include::example$/onboarding/frontend/themes/onboarding/material/outlined.css[tags=material-font-face;material-css]
----

在主题的主样式表中导入自定义的样式表：

.styles.css
[source,css]
----
include::example$/onboarding/frontend/themes/onboarding/styles.css[tags=import-material]
----

创建图标时，使用 `fontIcon` 组件，提供字体家族名称（需匹配 `@font-face` 中的声明），以及字符编码或连子：

[source,xml,indent=0]
----

include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=font-icon]
----

TIP: `fontIcon` 组件可以在 `prefix`、`suffix` 或 `icon` 元素内部使用。

== 单独的 SVG 图片

SVG 文件可以添加至静态资源目录。默认情况下，Spring Boot 的静态资源分布在 classpath 的这些位置：`/static`、`/public`、`/resources` 或 `/META-INF/resources`。图标可以放在一个子目录中，例如 `META-INF/resources/icons`。

XML 中通过 `svgIcon` 组件使用 SVG：

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative-standalone-1]
----

[source,xml,indent=0]

include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative-standalone-2]
