= Добавление иконок

Дополнительные иконки можно добавить тремя способами: в виде иконочного шрифта, SVG-спрайта или отдельных SVG‑файлов.

[[icon-fonts]]
== Иконочный шрифт

Иконочный шрифт — это набор иконок, поставляемый как шрифт. Иконки отображаются как символы этого шрифта.

TIP: Иконочный шрифт можно использовать для замены стандартных иконок приложения. Подробности см. xref:icons/override-icons.adoc[].

Для добавления иконочного шрифта потребуются:

* Файл шрифта – обычно `.woff` или `.woff2`, либо старые форматы, такие как `.ttf` или `.eot`.
* Определение `@font-face` – как правило, содержится в файле стилей, который необходимо импортировать в основной файл стилей вашей темы (`styles.css`).
* Опционально, файл стилей с CSS-классами для иконок — обычно добавляется вместе с определением `@font-face` и также импортируется в `styles.css`.

=== Пример: Добавление Material иконок

Рассмотрим добавление Material иконок в xref:flow-ui:themes/themes.adoc#application-theme[тему приложения].

image:flow-ui:icons/material-icons.png[width=298]

Создайте в папке темы каталог, содержащий:

* `material-icons-outlined.woff2`
* `outlined.css` – содержит определение `@font-face` и CSS-класс для иконок:
+
.outlined.css
[source,css]
----
include::example$/onboarding/frontend/themes/onboarding/material/outlined.css[tags=material-font-face;material-css]
----
Импортируйте этот файл в основной файл стилей:
+
.styles.css
[source,css]
----
include::example$/onboarding/frontend/themes/onboarding/styles.css[tags=import-material]
----

Чтобы создать иконку, используйте компонент `fontIcon`, указав название семейства шрифтов (`fontFamily`) (совпадающее с названием определенным в `@font-face`) и либо код символа, либо лигатуру:

[source,xml,indent=0]
----

include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=font-icon]
----

TIP: Компонент `fontIcon` можно вложить в элементы `prefix`, `suffix`, или `icon`.

== SVG-спрайт

SVG-спрайт — это коллекция SVG-изображений, загружаемых в приложение как единый файл. Вы можете создать спрайт вручную или с помощью сторонних инструментов.

Чтобы использовать SVG‑спрайт как набор иконок:

. . Создайте JavaScript-файл для вашего набора иконок в директории `/frontend/icons/`. Пример ниже определяет спрайт с тремя иконками:

+
.my-icons.js
[source,javascript,indent=0]
----
include::example$/onboarding/frontend/icons/my-icons.js[tags=my-icons-sprite]
----
+
. Создайте Java enum, реализующий `IconFactory` и добавьте ему аннотацию `@JsModule` со ссылкой на JavaScript-файл:
+
.MyIcons.java
[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/icons/MyIcons.java[tags=my-icons-enum]
----

Теперь пользовательские иконки можно использовать так же, как стандартные:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=sprite]
----

image::icons/sprite-icons.png[align="center", width="125"]

Чтобы установить их для компонента в Java-коде:

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/icons/IconsView.java[tags=programmatic-sprite]
----

[[standalone-svg-images]]
== Отдельная SVG иконка

Отдельные иконки можно добавить в директорию статического контента. По умолчанию Spring Boot использует статические ресурсы из следующих путей в classpath: `/static`, `/public`, `/resources` или `/META-INF/resources`. Для удобства организации иконок можно создать подкаталог `META-INF/resources/icons`.

Чтобы добавить такую иконку, воспользуйтесь компонентом `svgIcon`:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative-standalone-1]
----

Чтобы установить иконку в компонент, используйте его вложенный элемент `icon`:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative-standalone-2]
----

Если компонент поддерживает xref:flow-ui:vc/miscellaneous/prefix-suffix.adoc[префикс или суффикс], разместите значок там, чтобы разместить его относительно содержимого. Например, чтобы поместить значок перед текстом кнопки:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/icons/icons-view.xml[tags=declarative-standalone-3]
----

Или воспользуйтесь программным подходом:

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/icons/IconsView.java[tags=programmatic-standalone]
----
