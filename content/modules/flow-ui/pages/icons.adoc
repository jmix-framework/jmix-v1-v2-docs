= 图标

本节介绍如何使用内置的图标以及如何添加自定义图标。

== 使用场景

在 Jmix 中，图标可以出现在 UI 的下列场景中：

* 专用的组件：`icon`、`svgIcon` 或 `fontIcon`。
* UI 组件的属性，例如 `icon`、`uploadIcon`、`downloadButtonIcon`。
* 内部的 XML 元素，例如 `<icon>` 或 `<uploadIcon>`。
* 组件的 xref:vc/miscellaneous/prefix-suffix.adoc[]。
* xref:actions.adoc[]。
* xref:menu-config.adoc[] 的 header 或菜单项。
