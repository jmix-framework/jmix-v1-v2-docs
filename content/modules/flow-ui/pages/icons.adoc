= Icons

This section explains using the built-in icon sets and adding custom icons.

== Where Icons Are Used

In Jmix, icons can appear in several places in the UI:

* Dedicated components: `icon`, `svgIcon`, or `fontIcon`.
* UI component attributes such as `icon`, `uploadIcon`, `downloadButtonIcon`.
* Nested elements such as `<icon>` or `<uploadIcon>`.
* xref:vc/miscellaneous/prefix-suffix.adoc[] slots in components.
* xref:actions.adoc[].
* xref:menu-config.adoc[Main menu] section headers and items.
