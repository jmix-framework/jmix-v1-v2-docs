= Icons

Jmix includes two built-in icon sets and enables adding custom icons. You can use icons in numerous places, such as:

* Dedicated xref:vc/components/icon.adoc[] component
* Any component with the icon property (xref:vc/components/button.adoc[], xref:vc/layouts/tabSheet.adoc[], etc.)
* xref:vc/miscellaneous/prefix-suffix.adoc[Prefix and suffix]
* xref:actions.adoc[]
* xref:menu-config.adoc[Main menu]
