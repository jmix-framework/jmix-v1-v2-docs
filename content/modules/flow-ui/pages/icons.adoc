= Иконки

Jmix включает два встроенных набора иконок и позволяет добавлять пользовательские иконки. Вы можете использовать иконки в различных местах, таких как:

* Специальный компонент xref:vc/components/icon.adoc[]
* Любой компонент со свойством `icon` (xref:vc/components/button.adoc[], xref:vc/layouts/tabSheet.adoc[] и т. д.)
* xref:vc/miscellaneous/prefix-suffix.adoc[]
* xref:actions.adoc[]
* xref:menu-config.adoc[Главное меню]

В следующих разделах описано, как использовать существующие иконки и шаги для добавления новых иконок.
