= Горячие клавиши

Горячие клавиши могут быть назначены для различных элементов интерфейса Jmix, включая xref:actions.adoc[действия], xref:vc/components/button.adoc[кнопки] и xref:menu-config.adoc#item-attributes[элементы главного меню].

Горячая клавиша — это комбинация кодов клавиш и модификаторов, которые определены в классах Vaadin {vaadin-api}/com/vaadin/flow/component/Key.html[Key^] и {vaadin-api}/com/vaadin/flow/component/KeyModifier.html[KeyModifier^].

[[adding-shortcuts]]
== Задание горячих клавиш

В XML-описании экрана коды клавиш должны быть записаны в верхнем регистре и разделены дефисом (`-`). Модификаторы должны предшествовать кодам клавиш. Например:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/step/step-detail-view.xml[tags=keyboard-shortcuts]
----
<1> Фокусировать эту кнопку при нажатии Meta (Win или ⌘) + Enter
<2> Выполнить действие при нажатии Shift + Escape

При назначении горячих клавиш в XML можно использовать свойства приложения вместо прямого указания кодов клавиш. Например:

[source,xml]
.some-detail-view.xml
----
<button id="closeBtn" action="closeAction"
        shortcutCombination="${shortcut.close-detail-view}"/>
----

[source,properties,indent=0]
.application.properties
----
shortcut.close-detail-view=SHIFT-ESCAPE
----

Для программного назначения горячих клавиш используйте соответствующие слушатели и метод `setShortcutCombination()`. Класс `io.jmix.flowui.kit.component.KeyCombination` позволяет создавать горячие клавиши из строк или из констант `Key` и `KeyModifier`. Например:

[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/step/StepDetailView.java[tags=keyboard-shortcuts]
----

[[submitting-change-events-before-shortcut-activation]]
== Отправка событий изменения перед активацией горячих клавиш

Чтобы гарантировать, что событие изменения значения для активного компонента будет отправлено до активации горячих клавиш, включите флаг `resetFocusOnActiveElement` с помощью API `KeyCombination` или Vaadin `ShortcutRegistration`. Эта настройка приводит к тому, что активный элемент теряет фокус, а затем снова получает его перед срабатыванием горячих клавиш.

[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/user/UserDetailView.java[tags=keyboard-shortcuts-injects;on-init-start;keyboard-shortcuts;on-init-end]
----

При назначении горячих клавиш для действий в XML можно использовать вложенный элемент `shortcutCombination` для дополнительных настроек. Например:

[source,xml]
.some-detail-view.xml
----
<action id="saveAction" text="msg:///actions.Save" icon="CHECK">
    <shortcutCombination keyCombination="META-ENTER" resetFocusOnActiveElement="true"/>
</action>
----

[[configuring-active-scope]]
== Настройка активной области

По умолчанию горячие клавиши регистрируются в глобальной области. Это означает, что они срабатывают при нажатии пользователем соответствующих клавиш, независимо от положения курсора или того, какой элемент в фокусе на экране. Доступность горячих клавиш можно настроить (например, только когда пользователь фокусируется на определённом элементе) с помощью API `KeyCombination` или Vaadin `ShortcutRegistration`.

[source,java,indent=0]
----
@ViewComponent
private TypedTextField<String> searchField;
@ViewComponent
private JmixButton searchButton;

@Subscribe
public void onInit(final InitEvent event) {
    KeyCombination keyCombination = KeyCombination.create("CONTROL-ENTER", searchField, searchButton);
    searchButton.setShortcutCombination(keyCombination);
    // -- OR --
    searchButton.addClickShortcut(Key.ENTER, KeyModifier.CONTROL)
            .listenOn(searchField, searchButton);                   // <1>
}
----
<1> Слушатель горячих клавиш сработает только если фокус находится на `searchField` или `searchButton`.

== Key Codes

В таблице ниже приведены наиболее часто используемые коды клавиш. Полный список доступен в классе {vaadin-api}/com/vaadin/flow/component/Key.html[Key^].

Клавиши, которые могут использоваться как модификаторы: `SHIFT`, `CONTROL`, `ALT`, `ALT_GRAPH`, `META`.
