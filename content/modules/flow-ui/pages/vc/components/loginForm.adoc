Форма для ввода учетных данных аутентификации.

* XML-элемент: `loginForm`

* Java-класс: `JmixLoginForm`

== Основы

Базовая форма входа `loginForm` включает поля имени пользователя и пароля, а также кнопку, которую пользователь нажимает для попытки входа в систему. Форма может также включать необязательные элементы, такие как выпадающий список выбора языка, флажок "Запомнить меня" и кнопку "Забыли пароль".

[[remember-me]]
=== Запоминание пользователя

Флажок *Remember me* ("Запомнить меня") позволяет пользователю сохранять состояние своего входа в систему в течение длительного периода времени, превышающего время жизни HTTP-сессии. Это состояние сохраняется даже после перезапуска сервера.

Когда пользователь устанавливает флажок *Remember me* при входе в систему, система сохраняет постоянный токен в cookie браузера. При последующих посещениях пользователь автоматически аутентифицируется без повторного ввода учетных данных.

Для обработки состояния `Remember me` в логике входа в систему используйте событие <<RememberMeChangedEvent,RememberMeChangedEvent>>.

Смотрите https://docs.spring.io/spring-security/reference/servlet/authentication/rememberme.html[документацию Spring Security Remember-Me^] для получения дополнительной информации.

[[locale]]
== Локаль

Форма входа может включать выпадающий список, позволяющий пользователю выбрать предпочтительную локаль (язык). Чтобы сделать этот параметр доступным, вам необходимо xref:localization:message-bundles.adoc#setting-locales[настроить локаль] в вашем приложении. Как только будет настроена дополнительная локаль, она появится в списке.

image::visual-components/components/login-form-locales.png[align="center", width="480"]

Всякий раз, когда пользователь выбирает новую локаль из списка, генерируется событие <<LocaleChangedEvent,LocaleChangedEvent>>. Создав обработчик для этого события, вы можете гарантировать, что сообщения формы входа будут обновляться немедленно, без необходимости перезагрузки страницы. Вот как это делается в стандартном экране входа:

[[forgotPasswordButtonVisible]]
=== forgotPasswordButtonVisible

Устанавливает видимость кнопки **Forgot password** ("Забыли пароль").

[[localesVisible]]
=== localesVisible

Устанавливает видимость выпадающего списка выбора языка.

[[rememberMeVisible]]
=== rememberMeVisible

Устанавливает видимость флажка *Remember me* ("Запомнить меня"). Если значение `true`, пользователи могут выбрать опцию оставаться в системе между сеансами браузера.

Значение по умолчанию — `false`.

[[ForgotPasswordEvent]]
=== ForgotPasswordEvent

Событие `ForgotPasswordEvent` отправляется при нажатии кнопки "Забыли пароль". Добавьте обработчик для этого события, чтобы предоставить пользователям инструкции по восстановлению пароля.

[[LocaleChangedEvent]]
=== LocaleChangedEvent

Событие `LocaleChangedEvent` отправляется при выборе другой локали (языка). Обработчик для этого события может быть использован для обновления надписей и сообщений в форме в соответствии с выбранной локалью.

[[LoginEvent]]
=== LoginEvent

Событие `LoginEvent` отправляется, когда пользователь пытается войти в систему.

[[RememberMeChangedEvent]]
=== RememberMeChangedEvent

Событие `RememberMeChangedEvent` отправляется при изменении состояния флажка "Запомнить меня".

=== localeItemLabelGenerator

Настраивает имена локалей (языков) в списке. Например, вместо использования полного названия языка для каждой локали можно использовать трехбуквенное сокращение в верхнем регистре.
