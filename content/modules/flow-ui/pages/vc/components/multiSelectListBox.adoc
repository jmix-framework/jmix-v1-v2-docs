`multiSelectListBox` позволяет пользователям выбирать несколько значений из прокручиваемого списка элементов с помощью флажков.

* XML-элемент: `multiSelectListBox`

* Java-класс: `JmixMultiSelectListBox`

== Основы

Для создания списка элементов используются атрибуты xref:vc/components/entityComboBox.adoc#itemsContainer[itemsContainer] или xref:vc/components/comboBox.adoc#itemsEnum[itemsEnum]:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/multiselectlistbox/multi-select-list-box-view.xml[tags=data;hobbiesDc;layout;basics]
----

<1> `CollectionContainer` для сущности `Hobby`.
<2> `multiSelectListBox` получает `hobbiesDc` в качестве контейнера элементов, чтобы отобразить список хобби.

image::visual-components/components/multi-select-list-box-basics.png[align="center", width="183"]
