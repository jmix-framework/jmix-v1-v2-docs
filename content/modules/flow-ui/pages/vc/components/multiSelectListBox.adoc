== Basics

Use the xref:vc/components/entityComboBox.adoc#itemsContainer[itemsContainer] or xref:vc/components/comboBox.adoc#itemsEnum[itemsEnum] attribute to create a list of items:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/multiselectlistbox/multi-select-list-box-view.xml[tags=data;hobbiesDc;layout;basics]
----

<1> `CollectionContainer` for the `Hobby` entity.
<2> `multiSelectListBox` gets `hobbiesDc` as an items container so that the list of hobbies displayed.

== Item Enabled Provider

`itemEnabledProvider` allows you to dynamically control the enabled state of individual items based on specific conditions. Disabled items appear grayed out and cannot be selected by the user. All items are enabled by default.

----

[[rendering-items]]
== Rendering Items

It is possible to customize the render of items. The renderer is applied to each item to create a component which represents the item.

You can use the `setRenderer()` method or the `@Supply` annotation for it.

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/multiselectlistbox/MultiSelectListBoxView.java[tags=renderer]
----

[[fragment-renderer]]
Alternatively, you can render items using a nested `fragmentRenderer` element. Refer to the xref:flow-ui:vc/miscellaneous/renderers.adoc#fragment-renderer[Fragment Renderer] section for more information.

== Handlers

xref:vc/common-handlers.adoc[Common handlers] are configured in the same way for all components.
The following handlers are specific to `multiSelectListBox`.

include::../handler-generation-tip.adoc[]

[cols="1h,6", grid=rows, frame=none]
|===
|*Name*
|*Description*
|[[itemEnabledProvider]]itemEnabledProvider
|`itemEnabledProvider` is applied to each item of this `multiSelectListBox` to determine whether the item should be enabled (`true`) or disabled (`false`). See <<item-enabled-provider,Item Enabled Provider>>.
|[[itemLabelGenerator]]itemLabelGenerator
|Allows you to customize the labels displayed for each item in `multiSelectListBox`. See <<customizing-item-labels,Customizing Item Labels>>.
|[[renderer]]renderer
|Sets the item renderer for this `multiSelectListBox`. See <<rendering-items,Rendering Items>>.
|===
