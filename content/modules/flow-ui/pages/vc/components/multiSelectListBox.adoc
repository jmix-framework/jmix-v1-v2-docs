使用 xref:vc/components/entityComboBox.adoc#itemsContainer[itemsContainer] 或 xref:vc/components/comboBox.adoc#itemsEnum[itemsEnum] 创建选项列表：

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/multiselectlistbox/multi-select-list-box-view.xml[tags=data;hobbiesDc;layout;basics]
----

<1> `Hobby` 实体的 `CollectionContainer` 容器。
<2> `multiSelectListBox` 使用 `hobbiesDc` 作为选项容器，列表中显示 hobby 选项。

[[item-enabled-provider]]
== 选项状态 Provider

`itemEnabledProvider` 支持按特定条件动态控制单个选项是否启用。禁用的选项显示灰色，无法被用户选中。所有选项默认启用。

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/multiselectlistbox/MultiSelectListBoxView.java[tags=itemEnabledProvider]
----

== 自定义选项标签

`itemLabelGenerator` 支持自定义选项在 `multiSelectListBox` 组件中的显示标签。可以控制用户看到的文本，能以更友好的方式或上下文更相关的方式展示选项。

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/multiselectlistbox/MultiSelectListBoxView.java[tags=itemLabelGenerator]
----

[[rendering-items]]
== 选项渲染

可以自定义选项的渲染方式。渲染器在每个选项应用，返回一个表示该选项的组件。

可以使用 `setRenderer()` 方法或 `@Supply` 注解实现。

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/multiselectlistbox/MultiSelectListBoxView.java[tags=renderer]
----

[[fragment-renderer]]
或者，还可以使用嵌套的 `fragmentRenderer` 元素来渲染选项。更多信息请参考 xref:flow-ui:vc/miscellaneous/renderers.adoc#fragment-renderer[Fragment 渲染器] 部分。

|[[itemEnabledProvider]]itemEnabledProvider
