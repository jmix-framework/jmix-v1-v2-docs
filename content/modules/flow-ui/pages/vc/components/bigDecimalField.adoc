== Привязка данных

Вы можете связать компонент с сущностью и её атрибутами, хранящимися в xref:data/data-containers.adoc[контейнере данных].

Чтобы связать `bigDecimalField` с атрибутом сущности:

. Укажите имя контейнера данных в значении атрибута xref:flow-ui:vc/common-attributes.adoc#dataContainer[dataContainer].
. Укажите имя атрибута сущности в значении атрибута xref:flow-ui:vc/common-attributes.adoc#property[property].

Атрибут сущности должен иметь тип `BigDecimal`.

----

Внешний вид компонента можно настроить с помощью атрибута xref:vc/common-attributes.adoc#themeNames[themeNames], который позволяет выбрать один из пяти вариантов:

* `small`
* `align-left`
* `align-center`
* `align-right`
* `helper-above-field`

Подробнее смотрите в разделе xref:vc/components/textField.adoc#themeVariants[Варианты оформления] для `textField`.
