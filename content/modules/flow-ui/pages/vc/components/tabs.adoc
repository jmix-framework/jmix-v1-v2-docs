Набор вкладок, которые могут вызывать изменения в связанной области содержимого. В отличие от xref:vc/layouts/tabSheet.adoc[tabSheet], этот компонент не может содержать контент внутри себя.

* XML-элемент: `tabs`

* Java-класс: `Tabs`

== Основы

По умолчанию вкладки отображаются в горизонтальном ряду, с надписями, расположенными одна за другой. Этот ряд вкладок обычно располагается в верхней или нижней части связанной области содержимого.

Следующий пример демонстрирует базовую функциональность `tabs`.

image::visual-components/components/tabs-basic.png[align="center", width="210"]

.XML код
[%collapsible%open]
====
[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/tabs/tabs-view.xml[tags=basics]
----
====

В этом примере компонент содержит две вложенные <<tab,вкладки>>. Для обновления контента, связанного с выбранной вкладкой, определите обработчик событий, который отслеживает <<SelectedChangeEvent, SelectedChangeEvent>>. При выборе вкладки это событие срабатывает, позволяя соответствующим образом обновить отображаемое содержимое.

== Ориентация

Хотя горизонтальная ориентация используется по умолчанию, вертикальная ориентация может быть альтернативным вариантом в некоторых сценариях. Например, при большом количестве вкладок такая ориентация может предоставить дополнительное пространство для их надписей.

image::visual-components/components/tabs-vertical.png[align="center", width="114"]

Используйте атрибут <<orientation, orientation>> для изменения ориентации компонента tabs.

== Состояния

Вкладка может находиться в одном из состояний: выбрана, не выбрана или отключена:

image::visual-components/components/tabs-states.png[align="center", width="316"]

Эти состояния позволяют пользователям легко определить, какая вкладка активна в данный момент, а какие временно недоступны или отключены.

== Варианты оформления

Внешний вид компонента можно настроить с помощью атрибута xref:vc/common-attributes.adoc#themeNames[themeNames]. Доступны следующие темы, которые можно комбинировать:

=== icon-on-top

Когда <<labels, надпись вкладки>> включает иконку, располагает её над текстом вместо стандартного бокового расположения:

image:visual-components/components/tabs-icon-on-top.png[width=308]

Каждый элемент <<tab,вкладки>> должен иметь эту тему применённой индивидуально.

.Показать XML
[%collapsible]
====
[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/tabs/tabs-view.xml[tags=icon-on-top]
----
====

=== centered

Выравнивает вкладки по центру контейнера или экрана вместо стандартного выравнивания по левому краю:

image::visual-components/components/tabs-centered.png[width=610]

=== small

Уменьшает размер вкладок:

image:visual-components/components/tabs-small.png[width=366]

=== minimal

Упрощает стиль, оставляя только надписи без дополнительных визуальных элементов:

image:visual-components/components/tabs-minimal.png[width=394]

=== hide-scroll-buttons

Скрывает кнопки прокрутки для навигации по не помещающимся вкладкам:

image:visual-components/components/tabs-hide-scroll-buttons.png[width=394]

Имейте ввиду, что горизонтальная прокрутка может быть затруднена при отключении этих кнопок.

=== equal-width-tabs

Распределяет равное пространство для каждой вкладки и отключает возможность прокрутки:

image:visual-components/components/tabs-equal-width.png[width=538]
