`avatar` - это область контента, в которой отображается изображение, обычно фотография человека или логотип компании.

* XML-элемент: `avatar`

* Java-класс: `Avatar`

[[basics]]
== Основы

В приведённом примере показаны четыре возможных варианта содержимого для компонента `avatar`.

image::visual-components/components/avatar-basic.png[align="center", width="205"]

[source, xml, indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/avatar/avatar-view.xml[tags=basics]
----

Обратите внимание на приоритет атрибутов: сначала отображается <<image,image>>. Если изображение не задано или не может быть отображено, вместо него показывается значение сокращения (<<abbreviation, abbreviation>>). Если не заданы ни изображение, ни сокращение, отображаются первые буквы имени (<<name, name>>). Также предусмотрено запасное изображение, которое показывается, если отсутствует любое другое содержимое.

[[image-resource]]
== Источник изображения

Компонент `avatar` может отображать изображение из различных источников. Путь к изображению можно задать декларативно с помощью атрибута <<image, image>> или установить программно.

[[static-image]]
=== Статическое изображение

Изображение может быть статически загружено приложением.

По умолчанию статический контент обслуживается из каталогов `/static`, `/public`, `/resources` или `/META-INF/resources` в classpath (подробности см. в документации https://docs.spring.io/spring-boot/docs/current/reference/html/web.html#web.servlet.spring-mvc.static-content[Spring Boot^]).

* В XML:
+
Если ваше изображение находится по пути `/src/main/resources/META-INF/resources`, например, `/src/main/resources/META-INF/resources/icons/mary.png`, вы можете указать его следующим образом:
+
[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/avatar/avatar-view.xml[tags=static-image]
----
+
* В Java:
+
[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/component/avatar/AvatarView.java[tags=static-image]
----

[[url-image]]
=== Изображение из URL

Аналогично, изображение можно загрузить с любого URL-адреса.

* В XML:
+
[source, xml, indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/component/avatar/AvatarView.java[tags=url-image]
----

* В Java:
+
[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/component/avatar/AvatarView.java[tags=url-image]
----

[[stream-image]]
=== Изображение, предоставляемое DownloadHandler

Изображение может быть предоставлено через `DownloadHandler`.

Используйте фабричные методы `com.vaadin.flow.server.streams.DownloadHandler` для создания обработчика источника изображения.

Например, `DownloadHandler.forClassResource()` создает обработчик для изображения, расположенного в classpath приложения.

[[abbreviation]]
=== abbreviation

Устанавливает сокращение для отображения в компоненте. Это могут быть инициалы или другая короткая форма для идентификации владельца аватара. Рекомендуется ограничиваться 2–3 символами.

[[colorIndex]]
=== colorIndex

Задает цвет фона для компонента `avatar`. Доступно семь различных цветов, соответствующих индексам от 0 до 6.

image::visual-components/components/avatar-colorindex.png[align="center", width="360"]

[[image]]
=== image

Задает путь к ресурсу изображения. Изображение может быть получено из каталога <<static-image,статических ресурсов>> или загружено с <<url-image,произвольного URL>>.

[[name]]
=== name

Задает имя владельца аватара.

[[themeNames]]
=== themeNames

По умолчанию компонент имеет стандартный средний размер. Доступно четыре варианта размера:

* `xsmall`
* `small`
* `large`
* `xlarge`
