= drawerToggle

Компонент-переключатель, который управляет видимостью выдвижной панели меню (drawer).

* XML-элемент: `drawerToggle`

* Java-класс: `DrawerToggle`

== Основы

Компонент `drawerToggle` создает кнопку-переключатель, которая управляет открытием и закрытием компонента `drawerLayout`, содержащего элементы xref:menu-config.adoc[главного меню].

image::visual-components/components/drawer-toggle-basic.png[align="center", width="450"]

Чтобы пользователи могли получить доступ к главному меню из любой точки приложения, компонент `drawerToggle` обычно размещают внутри компонента `navigationBar` главного экрана приложения.

[[themeNames]]
== Варианты оформления

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames] для настройки цвета и размера компонента.

=== Цвет

Выберите один из четырех вариантов цвета: default (по умолчанию), `success`, `error` и `contrast`. Комбинируйте варианты цвета с темой `primary`, чтобы добавить дополнительный акцент.

=== Размер

Доступны три варианта размера: `small`, default, `large`.

[[ClickEvent]]
=== ClickEvent

Событие `com.vaadin.flow.component.ClickEvent` возникает при нажатии на компонент. Чтобы определить количество щелчков, связанных с событием, обработчик должен указать один из следующих трех типов событий:

* click – событие возникает каждый раз, когда нажимается компонент.

* singleClick – событие возникает после таймаута, чтобы убедиться, что это не двойной щелчок.

* doubleClick – событие возникает при двойном щелчке на компоненте.
