Область для ввода многострочного текста.

* XML-элемент: `textArea`

* Java-класс: `JmixTextArea`

== Основы

Используйте `textArea`, когда ожидается ввод многострочного текста, такого как комментарии или описания.

image::visual-components/components/text-area-basic.png[align="center", width="200"]

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/textarea/text-area-view.xml[tags=basics]
----

Если не задана фиксированная высота, компонент автоматически подстраивает высоту под содержимое. Минимальная и стандартная высота - две строки текста.

== Привязка данных

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/text-area-dataaware" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Привязка данных означает связывание визуального компонента с контейнером данных. Изменения в компоненте или соответствующем контейнере могут вызывать взаимные обновления. Подробнее смотрите в разделе xref:data/data-examples.adoc[].

Пример создания `textArea` с привязкой к данным:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/textarea/text-area-view.xml[tags=data-binding]
----

Убедитесь, что атрибут сущности, к которому выполняется привязка, имеет строковый тип. В отличие от xref:vc/components/textField.adoc[], `textArea` специально предназначен для работы с текстовыми данными.
