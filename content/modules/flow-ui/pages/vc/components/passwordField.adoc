Поле для ввода паролей. По умолчанию символы, вводимые в это поле, скрываются.

TIP: Компонент xref:vc/components/loginForm.adoc[loginForm] включает поле для ввода пароля, где пользователи могут ввести пароль при входе в систему.

* XML-элемент: `passwordField`

* Java-класс: `JmixPasswordField`

Набор атрибутов для компонента `passwordField` схож с атрибутами, доступными для компонента xref:vc/components/textField.adoc[]. Однако атрибут `datatype` отсутствует - ввод для `passwordField` может быть только типа `String`.
