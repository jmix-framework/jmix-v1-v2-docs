== Основы

Компонент `markdown` преобразует контент, написанный в синтаксисе Markdown, в форматированный HTML. Он поддерживает базовое форматирование текста, списки, ссылки и другие распространенные возможности Markdown. Весь контент автоматически санируется для предотвращения отображения потенциально опасного HTML.

Подробную информацию о синтаксисе Markdown смотрите в https://www.markdownguide.org/basic-syntax/[Руководстве Markdown^].

[[content]]
Вы можете предоставить контент компоненту, используя либо атрибут `content`, либо вложенный элемент `content`.

* В этом примере показано, как добавить контент Markdown через атрибут `content` и строку в xref:localization:message-bundles.adoc[пакете сообщений]:
+
[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/markdown/markdown-view.xml[tags=content]
----
+
.messages.properties
[source,properties,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/messages_en.properties[tags=markdown-content]

* Пример использования вложенного элемента `content`:
+
[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/markdown/markdown-view.xml[tags=content-element]
----
+
image::visual-components/components/markdown-content-element.png[align="center", width="371"]
+
IMPORTANT: При использовании вложенного элемента `content` избегайте пробелов в начале каждой строки. Синтаксис Markdown чувствителен к отступам, и неожиданные пробелы могут повлиять на отображение форматированных элементов, таких как заголовки, списки и блоки кода.
