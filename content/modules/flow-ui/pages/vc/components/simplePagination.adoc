`simplePagination` - это компонент для постраничной загрузки данных. Он предназначен для совместного использования с компонентами xref:flow-ui:vc/components/dataGrid.adoc[dataGrid] и xref:flow-ui:vc/components/treeDataGrid.adoc[treeDataGrid].

* XML-элемент: `simplePagination`

* Java-класс: `SimplePagination`

== Основы

`simplePagination` имеет простой экран с отображением количества строк и кнопками навигации.

Также может содержать <<items-per-page,выпадающий список>> для выбора количества элементов на странице.

image::visual-components/components/simple-pagination.png[align="center", width="818"]

По умолчанию Jmix Studio генерирует `simplePagination` при создании xref:flow-ui:views/view-classes.adoc#standard-list-view[StandardListView] для сущности.

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/simplepagination/simple-pagination-view.xml[tags=data;layout;basics]
----
<1> Определяем xref:flow-ui:data/data-loaders.adoc[загрузчик коллекции] для загрузки сущностей `User`.
<2> Связываем `simplePagination` с данными через атрибут `dataLoader`.

[[items-per-page]]
== Количество элементов на странице

[[itemsPerPageVisible]]
Компонент `simplePagination` содержит специальный `comboBox` с вариантами ограничения количества элементов на странице. Для его отображения установите атрибут `itemsPerPageVisible` в значение `true`. По умолчанию: `false`.

image::visual-components/components/items-per-page.png[align="center", width="264"]

Значения по умолчанию для этого списка задаются в свойстве xref:flow-ui:ui-properties.adoc#jmix.ui.component.pagination-items-per-page-items[jmix.ui.component.pagination-items-per-page-items].

[[itemsPerPageItems]]
Вы можете настроить собственный список вариантов через атрибут `itemsPerPageItems`. Значение должно быть списком чисел, разделенных запятыми:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/simplepagination/simple-pagination-view.xml[tags=itemsPerPageItems]
----

Варианты со значением, меньшим или равным `0`, игнорируются. Варианты, превышающие <<max-fetch-size,максимально допустимый размер выборки>> сущности, заменяются на максимальное значение.

[[itemsPerPageDefaultValue]]
Для установки значения по умолчанию используйте атрибут `itemsPerPageDefaultValue`:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/simplepagination/simple-pagination-view.xml[tags=itemsPerPageDefaultValue]
----

[[itemsPerPageUnlimitedItemVisible]]
Атрибут `itemsPerPageUnlimitedItemVisible` управляет отображением варианта `null` в `comboBox`. По умолчанию: `true`.

При выборе null-варианта компонент попытается загрузить все данные в пределах ограничения максимально допустимого размера выборки.

[[max-fetch-size]]
[NOTE]
====
Максимально допустимый размер выборки для всех сущностей определяется свойством xref:flow-ui:ui-properties.adoc#jmix.ui.default-max-fetch-size[jmix.ui.default-max-fetch-size] (по умолчанию 10000). Для конкретной сущности можно задать отдельное ограничение через xref:flow-ui:ui-properties.adoc#jmix.ui.entity-max-fetch-size[jmix.ui.entity-max-fetch-size].
====

[[items-per-page-empty-label]]
=== Надпись пустого элемента

Когда <<itemsPerPageUnlimitedItemVisible,itemsPerPageUnlimitedItemVisible>>=`"true"`, в выпадающем списке отображается пустой элемент, который позволяет загрузить все данные (ограниченные максимальным размером выборки). По умолчанию этот элемент отображается как пустая строка.

Вы можете настроить надпись для этого пустого элемента, добавив ключ сообщения в ваш xref:localization:message-bundles.adoc[пакет сообщений]:

[source,properties]
----
pagination.itemsPerPage.emptySelectionCaption=Show all
----

[NOTE]
====
Если ключ сообщения `pagination.itemsPerPage.emptySelectionCaption` присутствует в пакете сообщений, его значение будет отображаться вместо пустого элемента в выпадающем списке. Если ключ не найден, элемент остается пустым.
====

[[autoLoad]]
=== autoLoad

Атрибут `autoLoad` определяет, должно ли количество элементов загружаться автоматически. Когда `autoLoad` отключен, компонент не знает общее количество элементов и отображает кнопку с вопросительным знаком `[?]`. При включении компонент выполняет запрос для получения общего количества элементов и отображает его. Значение по умолчанию: `false`.

[NOTE]
====
Когда для `autoLoad` установлено значение `true`, делегат <<totalCountDelegate,totalCountDelegate>> может быть вызван из `BackgroundTask`. В этом случае обновления пользовательского интерфейса внутри делегата не допускаются.
====

[[dataLoader]]
=== dataLoader

Для создания `simplePagination`, связанного с данными, используйте атрибут `dataLoader`.

[[totalCountDelegate]]
=== totalCountDelegate

Устанавливает делегат для получения общего количества элементов. Например:

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/simplepagination/SimplePaginationView.java[tags=dataManager;totalCountDelegate]
----

[IMPORTANT]
====
Когда для `simplePagination` установлено `autoLoad="true"`, делегат `totalCountDelegate` может быть вызван из `BackgroundTask`. Это означает, что код внутри обработчика `totalCountDelegate` не может обновлять UI-компоненты (например, вызывать `setText()` для `TextField` или выполнять другие модификации UI). Попытка сделать это вызовет `IllegalStateException`.

Не обновляйте UI-компоненты внутри `totalCountDelegate`. Используйте этот обработчик только для вычисления и возврата общего количества элементов.
====
