== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] выполняют ту же функцию для всех компонентов.
Следующие атрибуты специфичны для `iframe`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Имя*
|*Описание*
|*По умолчанию*

|[[importance]]importance
| Указывает браузеру, насколько важен ресурс для рендеринга страницы. Возможные значения:  `AUTO`, `HIGH`, `LOW`
| `AUTO`
|[[resource]]resource
|Путь к статическому ресурсу, например `resource="pdf/tutorial.pdf"` или URL.
| –
|[[resourceDoc]]resourceDoc
a|Отображает HTML‑код в компоненте. Для этого код необходимо экранировать, например:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/htmlcomponent/iframe/iframe-view.xml[tags=iframe-resourceDoc]
----
| –
|===
