== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `iframe` 的特殊属性：

[cols="1h,5,1", grid=rows, frame=none]
|===
|*名称*
|*描述*
|*默认值*

|[[importance]]importance
| 告诉浏览器渲染的页面的重要程度。支持：`AUTO`、`HIGH`、`LOW`
| `AUTO`
|[[resource]]resource
|设置静态资源的路径，例如 `resource="pdf/tutorial.pdf"` 或站点的 URL。
| –
|[[resourceDoc]]resourceDoc
a|在组件内显示 HTML 代码。但是需要转义代码，示例：

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/htmlcomponent/iframe/iframe-view.xml[tags=iframe-resourceDoc]
----
| –
|===
