== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.
The following attributes are specific to `iframe`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Name*
|*Description*
|*Default*

|[[importance]]importance
| Tells the browser how critical a resource is for rendering a page. Possible values:  `AUTO`, `HIGH`, `LOW`
| `AUTO`
|[[resource]]resource
|Specifies the path to the static resource such as `resource="pdf/tutorial.pdf"` or site URL.
