[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是标题组件的特殊属性：

[cols="1h,5,1", grid=rows, frame=none]
|===
|*名称*
|*描述*
|*默认值*
|[[themeNames]]themeNames
|为组件添加一个样式。支持 `badge`、`normal`、`success`、`error`、`contrast`、`primary`、`small`、`pill`。样式生效需要与 `badge` 一起使用。

*预定义的样式是一组 CSS 类，有可能影响组件或内部组件的其他样式设置。*
|-
|===

[[handlers]]
== 事件和处理器

xref:vc/common-handlers.adoc[通用事件和处理器] 对所有组件都是一样的配置。
下面是标题组件的特殊事件和处理器：

include::../handler-generation-tip.adoc[]

[cols="1h,6", grid=rows, frame=none]
|===
|*名称*
|*描述*
|[[ClickEvent]]ClickEvent
|当点击组件时触发 `com.vaadin.flow.component.ClickEvent` 事件。该事件的处理方法需要指定处理的是以下哪种点击事件：

*click* – 当用户点击组件时触发。

*singleClick* – 当用户在单击组件一小段时间后会（确保不是双击）触发。

*doubleClick* – 当用户在短时间内点击组件两次时触发。
|===
