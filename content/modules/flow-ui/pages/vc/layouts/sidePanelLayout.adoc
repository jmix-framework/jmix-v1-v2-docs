[[basics]]
== 基本用法

`SidePanelLayout` 将页面内容分为两个区域：

* **主内容区** – 主要的布局区域
* **侧面板内容区** – 从某一个侧边滑入的侧边内容。

image:flow-ui:visual-components/layouts/side-panel-layout-basic.png[width=1150]

如需在 XML 中定义该组件，请使用 `sidePanelLayout` 元素，并为其提供两个根元素。

[source,xml]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/layout/sidepanellayout/side-panel-layout-view.xml[tags=basics]
----

<1> 侧边面板一般会包含一个关闭按钮。使用专门的 `sidePanelLayoutCloser` 组件添加这个按钮。

== 样式

使用 CSS 变量和主题选择器可以自定义 `SidePanelLayout` 的外观和大小。

=== 尺寸

下列全局变量定义了侧边面板的尺寸。对所有 `SidePanelLayout` 实例有效。

NOTE: 在 XML 中设置或使用 Java API 设置的值会覆盖 CSS 变量。

水平侧边面板（`LEFT`、`RIGHT`、`INLINE_START`、`INLINE_END`）：

[cols="3h,2,1", grid=rows]
|===
|变量 |描述 |默认值
|`--jmix-side-panel-layout-horizontal-size`
|侧边面板的默认宽度。
|`auto`
|`--jmix-side-panel-layout-horizontal-max-size`
|最大宽度。
|`50%`
|`--jmix-side-panel-layout-horizontal-min-size`
|最小宽度。
|`14em`
|===

垂直侧边面板（`TOP`、`BOTTOM`）：

[cols="3h,2,1", grid=rows]
|===
|变量 |描述 |默认值
|`--jmix-side-panel-layout-vertical-size`
|侧边面板的默认高度。
|`auto`
|`--jmix-side-panel-layout-vertical-max-size`
|最大高度。
|`50%`
|`--jmix-side-panel-layout-vertical-min-size`
|最小高度。
|`10em`
|===

=== 外观

[cols="4h,3,1", grid=rows]
|===
|变量 |描述 |默认值
|`--jmix-side-panel-layout-transition-duration`
|控制打开和关闭动画的时长。
|`200ms`
|===

=== 状态

组件开放了以下 xref:themes/styling-ui-components.adoc#component-states[状态]：

[cols="4h,4", grid=rows]
|===
|状态 |描述
|`jmix-side-panel-layout[side-panel-opened]`
|当侧边面板打开时使用。
|`jmix-side-panel-layout[modal]`
|当侧边面板为模态时使用。
|`jmix-side-panel-layout[side-panel-position='left']`
|匹配当前的侧边面板位置（`right`、`top` 等）。
|`jmix-side-panel-layout[side-panel-overlay]`
|当面板覆盖内容而不是推开内容时使用。
|===

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。下面是 `sidePanelLayout` 的特殊属性：

[cols="1h,5,1", grid=rows, frame=none]
|===
|*名称*
|*描述*
|*默认值*

|[[sidePanelPosition]]sidePanelPosition
|定义面板出现在哪个侧边。可选值为 `LEFT`、`RIGHT`、`TOP`、`BOTTOM`、`INLINE_START` 和 `INLINE_END`。

`INLINE_START` 和 `INLINE_END` 遵循页面的阅读方向（LTR 或 RTL）。
|`RIGHT`

|[[sidePanelOverlay]]sidePanelOverlay
|决定侧边面板与主内容的交互方式。

如果为 `true`，面板覆盖在内容上而不改变其布局。
如果为 `false`，面板打开时将内容推开。
|`true`

|[[modal]]modal
|当为 `true` 时，侧边面板后面会出现一个模态遮罩层，并阻止与主内容的交互，直到面板关闭。
|`true`

|[[closeOnOutsideClick]]closeOnOutsideClick
|当为 `true` 时，点击模态遮罩层会关闭侧边面板。

此属性仅在启用 <<modal, modal>> 时有效。
|`true`

|[[overlayAriaLabel]]overlayAriaLabel
|设置覆盖元素的可访问标签。
|–

|[[displayAsOverlayOnSmallDevices]]displayAsOverlayOnSmallDevices
|如果为 `true`，侧边面板在小设备上显示为全屏覆盖层，确保内容在移动布局中仍然可用。
|`true`

|[[sidePanelHorizontalSize]]sidePanelHorizontalSize
|定义侧边面板位于布局左侧或右侧时的水平尺寸。

值可以是任何有效的 CSS 尺寸，例如 `400px`、`30%` 或 `auto`。
|`auto`

|[[sidePanelHorizontalMinSize]]sidePanelHorizontalMinSize
|定义侧边面板位于左侧或右侧时的最小水平尺寸。
|–

|[[sidePanelHorizontalMaxSize]]sidePanelHorizontalMaxSize
|定义侧边面板位于左侧或右侧时的最大水平尺寸。
|–

|[[sidePanelVerticalSize]]sidePanelVerticalSize
|定义侧边面板从顶部或底部出现时的垂直尺寸。
|`auto`

|[[sidePanelVerticalMinSize]]sidePanelVerticalMinSize
|定义侧边面板的最小垂直尺寸。
|–

|[[sidePanelVerticalMaxSize]]sidePanelVerticalMaxSize
|定义侧边面板的最大垂直尺寸。
|–
|===

== 事件和处理器

xref:vc/common-handlers.adoc[通用事件和处理器] 对所有组件都是一样的配置。下面是 `sidePanelLayout` 的特殊事件和处理器：

[cols="1h,6", grid=rows, frame=none]
|===
|*名称*
|*描述*

|[[ModalityCurtainClickEvent]]ModalityCurtainClickEvent
|当用户点击模态遮罩层时触发。

|[[SidePanelBeforeOpenEvent]]SidePanelBeforeOpenEvent
|在侧边面板打开之前、显示之前以及开启动画开始之前触发。使用此事件可在面板变得可见之前修改内容。

|[[SidePanelAfterOpenEvent]]SidePanelAfterOpenEvent
|在侧边面板完全打开且开启动画完成之后触发。

|[[SidePanelCloseEvent]]SidePanelCloseEvent
|当侧边面板关闭时触发。
|===
