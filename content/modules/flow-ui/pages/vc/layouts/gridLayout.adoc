== Основы

// `gridLayout` displays data in a grid-based format. Provides integration with data sources to support data binding, items enumeration, and other features.
//
// Components can be added as nested elements in XML markup, or programmatically via the `gridLayout#add` method.
//
// To customize the gap between elements and the minimum column width, you can use the `gap` and
// `minColumnWidth` properties. Properties accept CSS values and variables, such as `150px`, `2em` or `var(--lumo-space-m)`.

Привязка данных означает связывание визуального компонента с xref:data/data-containers.adoc[контейнером данных].

В компоненте `gridLayout` это достигается путем установки атрибута `itemsContainer`, который ссылается на контейнер данных.

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/layout/gridlayout/grid-layout-view.xml[tags=data;layout;itemsContainer]
----
<1> Контейнер данных для хранения коллекции всех существующих экземпляров `User`.
<2> Координатор загрузки данных для автоматического предоставления компоненту экземпляров для отображения.
<3> Указание контейнера, который содержит список элементов для отображения.

По умолчанию компонент отображает xref:data-model:entities.adoc#instance-name[имя экземпляра] сущности.

Существует возможность настройки рендеринга элементов. Рендерер применяется к каждому элементу для создания компонента, который его представляет.

Это можно выполнить двумя различными методами.

[[programmatically]]
=== Программный подход

В контроллере экрана используйте либо:

* Метод `setRenderer()`;
* Аннотацию `@Supply`.

Основываясь на <<data-binding,предыдущем примере>>, мы можем создать `renderer` для отображения каждого пользователя в виде пользовательского компонента xref:flow-ui:vc/layouts/card.adoc[Card].

.Показать код
[%collapsible]
====
[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/layout/gridlayout/GridLayoutView.java[tags=renderer]
----
<1> Предоставляет пользовательский рендерер для отображения каждого `User` в виде карточки.
<2> Создает базовый компонент `Card` с общим стилем.
<3> Инициализирует содержимое карточки данными конкретного пользователя. Вызывается для каждого экземпляра карточки с соответствующей сущностью `User`.
<4> Создает компонент xref:flow-ui:vc/html-components/image.adoc[image] из изображения пользователя.

== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] служат одной и той же цели для всех компонентов.

Следующие атрибуты специфичны для `gridLayout`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Название*
|*Описание*
|*Значение по умолчанию*
|[[alignSelf]]alignSelf
|Управляет вертикальным выравниванием компонента внутри ячейки `gridLayout` вдоль поперечной оси. Это соответствует CSS-свойству https://developer.mozilla.org/en-US/docs/Web/CSS/align-self[align-self^]. Смотрите также xref:flow-ui:vc/common-attributes.adoc#alignSelf[alignSelf].

Доступно для проектов с версии 2.7.2 и выше.
|`AUTO`
|[[columnMinWidth]]columnMinWidth
|Задает минимальную ширину для столбцов сетки в `gridLayout`. Это гарантирует, что столбцы не станут слишком узкими при изменении размера контейнера.
Значение представляется в виде CSS-значения длины (например, `"50px"`, `"10rem"`).
|`19rem`
|[[gap]]gap
|Управляет промежутком между ячейками сетки (как между строками, так и между столбцами). Создает визуальное разделение между компонентами. Значение представляется в виде CSS-значения длины (например, `"10px"`, `"1rem"`).
|`var(--lumo-space-s)`
|[[justifySelf]]justifySelf
|Управляет горизонтальным выравниванием компонента внутри ячейки `gridLayout` вдоль горизонтальной оси. Это соответствует CSS-свойству https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/justify-self[justify-self^].

Доступно для проектов с версии 2.7.2 и выше.
|`AUTO`
|===
