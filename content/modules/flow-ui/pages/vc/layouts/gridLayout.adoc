== 基本用法

// `gridLayout` displays data in a grid-based format. Provides integration with data sources to support data binding, items enumeration, and other features.
//
// Components can be added as nested elements in XML markup, or programmatically via the `gridLayout#add` method.
//
// To customize the gap between elements and the minimum column width, you can use the `gap` and
// `minColumnWidth` properties. Properties accept CSS values and variables, such as `150px`, `2em` or `var(--lumo-space-m)`.

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。

下面是 `gridLayout` 的特殊属性：

[cols="1h,5,1", grid=rows, frame=none]
|===
|*名称*
|*描述*
|*默认值*
|[[alignSelf]]alignSelf
|控制组件在其网格单元格内沿块轴（列轴）的垂直对齐方式。对应于 CSS 的 https://developer.mozilla.org/en-US/docs/Web/CSS/align-self[align-self^] 属性。另请参考 xref:flow-ui:vc/common-attributes.adoc#alignSelf[alignSelf]。

适用于版本 2.7.2+ 的项目。
|`AUTO`
|[[columnMinWidth]]columnMinWidth
|设置 `gridLayout` 中网格列的最小宽度。可以防止在容器调整大小时列变得过窄。该值为 CSS 长度值（例如 `"50px"`、`"10rem"`）。
|`19rem`
|[[gap]]gap
|控制网格单元格之间的间距（行间距和列间距）。该值为 CSS 长度值（例如 `"10px"`、`"1rem"`）。
|`var(--lumo-space-s)`
|[[justifySelf]]justifySelf
|控制组件在其网格单元格内沿内轴（行轴）的水平对齐方式。对应于 CSS 的 https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/justify-self[justify-self^] 属性。

适用于版本 2.7.2+ 的项目。
|`AUTO`
|===
