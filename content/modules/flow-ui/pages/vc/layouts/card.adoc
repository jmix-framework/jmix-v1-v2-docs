下面的示例展示如何创建一个简单的 `card` 用于显示产品的信息。

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/layout/card/card-view.xml[tags=basics]

<1> `elevated` <<theme-variants,样式>> 使用阴影效果。
<2> 使用预定义的 <<slot-title,title>> 插槽定义主标题。
<3> 使用预定义的 <<slot-subtitle,subtitle>> 插槽定义副标题。
<4> <<slot-media,media>> 插槽包含产品图片。
<5> <<slot-content,content>> 插槽包含主要的描述文本。
<6> <<slot-footer,footer>> 插槽将操作按钮组合在一起，并固定在卡片底部。

image::visual-components/layouts/card-basic.png[align="center", width="510"]

`Card` 组件以结构化的卡片式布局展示内容。卡片内的信息可以通过组件属性填充，也可以使用其内部元素（称为 <<slots,slots - 插槽>>）填充。

卡片的视觉外观（包括阴影、边框和背景）都是可定制的。通过使用不同的 <<theme-variants,样式版本>> 实现。

[[slots]]
== 插槽

组件提供了多个预定义的插槽，可以灵活地组织内容。插槽是组件的一个内部元素。

TIP: 如需在 Jmix Studio 中添加插槽，在视图 XML 或 *Jmix UI* 结构面板中选择 `card`，然后在 *Component Inspector* 面板中点击 *Add→[Slot Name]*。

NOTE: 除 <<slot-content,content>> 和 <<slot-footer,footer>> 之外的所有插槽都只能包含一个内部组件。

[[slot-title]]
=== 标题

具有预定义样式的文本内容。

可以通过以下任一方式定义卡片的标题：

* 使用组件上的 `title` 属性。
* 使用内部的 `title` 元素。

[IMPORTANT]
====
* 如果同时使用 `title` 属性和内部的 `title` 元素指定标题，则内部元素的值优先，忽略属性值。

* 如果存在 <<slot-header,header>> 插槽，则 `title`（和 `subtitle`）不会渲染。自定义的 header 会完全替换标题。
====

----

[source,xml,indent=0]

[[slot-subtitle]]
=== 副标题

副标题是带有预定义样式的次要文本内容，直接显示在标题下方。一般与标题一起使用。

可以通过以下任一方式定义卡片的副标题：

* 使用组件上的 `subtitle` 属性。
* 使用内部的 `subtitle` 元素。

[IMPORTANT]
====
* 如果同时使用 `subtitle` 属性和内部的 `subtitle` 元素指定副标题，则内部元素的值优先，忽略属性值。

* 如果存在 <<slot-header,header>> 插槽，则 `subtitle`（和 `title`）不会渲染。自定义的 header 会完全替换标题。
====

[[theme-variants]]
== 样式版本

组件的外观可以通过 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性自定义，支持五个不同的选项：


.`outlined`
[%collapsible]
====
为卡片添加边框

image:visual-components/layouts/card-outlined.png[align="center", width=172]
====

.`elevated`
[%collapsible]
====
为卡片添加阴影效果。

image:visual-components/layouts/card-elevated.png[align="center", width=178]
====

.`horizontal`
[%collapsible]
====
卡片内容水平布局。

image:visual-components/layouts/card-horizontal.png[align="center", width=174]
====

.`stretch-media`
[%collapsible]
====
调整媒体以填满其容器。

image:visual-components/layouts/card-stretch-media.png[align="center", width=171]
====

.`cover-media`
[%collapsible]
====
裁剪媒体内容以覆盖其容器。

image:visual-components/layouts/card-cover-media.png[align="center", width=176]
====

TIP: 可以混合使用这些样式。

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。

下面是 `card` 的特殊属性：

[cols="1h,5,1", grid=rows, frame=none]
|===
|*名称*
|*描述*
|*默认值*
|[[subtitle]]subtitle
|设置具有预定义样式的次要文本内容。参阅 <<slot-subtitle>>。
|
|[[title]]title
|设置具有预定义样式的文本内容。参阅 <<slot-title>>。
|
|[[titleHeadingLevel]]titleHeadingLevel
|设置标题的 heading level 属性。用该属性的值设置 https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Attributes/aria-level[aria-level^] HTML 属性。`titleHeadingLevel` 的值必须在 1-6 范围内。*重要*：超出有效范围（1-6）的值可能导致严重的访问性问题，应避免使用。
|2
|===
