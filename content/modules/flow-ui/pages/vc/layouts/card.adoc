== Основы

Следующий пример демонстрирует создание простой карточки с информацией о товаре.

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/layout/card/card-view.xml[tags=basics]
----
<1> <<theme-variants,Вариант темы>> `elevated` применяет эффект тени.
<2> Определяет основной заголовок с помощью предопределенного слота <<slot-title,title>>.
<3> Определяет дополнительный заголовок с помощью предопределенного слота <<slot-subtitle,subtitle>>.
<4> Слот <<slot-media,media>> содержит изображение товара.
<5> Слот <<slot-content,content>> содержит основной описательный текст.
<6> Слот <<slot-footer,footer>> группирует кнопки действий, фиксируя их в нижней части карточки.

image::visual-components/layouts/card-basic.png[align="center", width="510"]

Компонент `Card` отображает контент в структурированном, карточном макете. Информация внутри карточки может быть заполнена либо через атрибуты компонента, либо с использованием его внутренних элементов, известных как <<slots,слоты>>.

Визуальный вид карточки - включая тени, границы и фон - настраивается. Это достигается применением различных <<theme-variants,вариантов темы>>.

[[slots]]
== Слоты

Компонент предоставляет несколько предопределенных слотов для гибкой организации контента. Слот - это вложенный элемент внутри компонента.

TIP: Чтобы добавить слот в Jmix Studio, выберите `card` в XML-дескрипторе экрана или на панели структуры *Jmix UI* и нажмите *Add→[Slot Name]* на панели *Component Inspector*.

NOTE: Все слоты, кроме <<slot-content,content>> и <<slot-footer,footer>>, ограничены содержанием одного вложенного компонента.

[[slot-title]]
=== Title

Title (заголовок) - текстовое содержимое с предопределенным стилем.

Определить заголовок карточки можно одним из следующих способов:

* Используя атрибут `title` на компоненте.
* Используя вложенный элемент `title`.

[IMPORTANT]
====
* Если заголовок указан и с помощью атрибута `title`, и с помощью вложенного элемента `title`, используется значение из вложенного элемента, а значение атрибута игнорируется.

* `title` (и `subtitle`) не отображаются, если присутствует слот <<slot-header,header>>. Пользовательская разметка заголовка полностью их заменяет.
====

[[slot-subtitle]]
=== Subtitle

Subtitle (подзаголовок) предоставляет дополнительный текстовый контент с предопределенным стилем, отображаемым непосредственно под основным заголовком. Он предназначен для использования вместе с заголовком.

Определить подзаголовок карточки можно одним из следующих способов:

* Используя атрибут `subtitle` на компоненте.
* Используя вложенный элемент `subtitle`.

[IMPORTANT]
====
* Если подзаголовок указан и с помощью атрибута `subtitle`, и с помощью вложенного элемента `subtitle`, используется значение из вложенного элемента, а значение атрибута игнорируется.

* `subtitle` (и `title`) не отображаются, если присутствует слот <<slot-header,header>>. Пользовательская разметка заголовка полностью их заменяет.
====

[[slot-header]]
=== Header

Header (заголовок) определяет пользовательский компонент, используемый в качестве заголовка карточки.

[IMPORTANT]
====
Когда определен слот заголовка, он имеет приоритет над слотами <<slot-title,title>> и <<slot-subtitle,subtitle>>. Пользовательская разметка заголовка отображается вместо них, полностью заменяя заголовок и подзаголовок по умолчанию.
====

[[slot-media]]
=== Media

Media (медиа) определяет визуальный компонент, такой как xref:flow-ui:vc/html-components/image.adoc[изображение], xref:flow-ui:vc/components/avatar.adoc[аватар] или xref:flow-ui:vc/components/icon.adoc[иконка], для отображения в качестве медиа-контента карточки.

Чтобы управлять размером медиа-контента, примените <<theme-variants,варианты темы>> `stretch-media` или `cover-media` с помощью атрибута `themeNames`.

[[slot-footer]]
=== Footer

Footer (нижний колонтитул) определяет область нижнего колонтитула карточки. Этот слот поддерживает несколько элементов, обеспечивая гибкие макеты для действий, индикаторов статуса и дополнительной информации.

Нижний колонтитул остается расположенным внизу карточки независимо от высоты основного контента.

[[theme-variants]]
== Варианты темы

Внешний вид компонента настраивается с помощью атрибута xref:vc/common-attributes.adoc#themeNames[themeNames], который позволяет выбрать один из пяти различных вариантов:

.`outlined`
[%collapsible]
====
Применяет границу (рамку) вокруг карточки.

image:visual-components/layouts/card-outlined.png[align="center", width=172]
====

.`elevated`
[%collapsible]
====
Добавляет эффект тени для создания ощущения глубины.

image:visual-components/layouts/card-elevated.png[align="center", width=178]
====

.`horizontal`
[%collapsible]
====
Располагает содержимое карточки горизонтально.

image:visual-components/layouts/card-horizontal.png[align="center", width=174]
====

.`stretch-media`
[%collapsible]
====
Масштабирует медиа-контент, чтобы заполнить его контейнер.

image:visual-components/layouts/card-stretch-media.png[align="center", width=171]
====

.`cover-media`
[%collapsible]
====
Обрезает медиа-контент для заполнения его контейнера.

image:visual-components/layouts/card-cover-media.png[align="center", width=176]
====

TIP: Все варианты темы можно комбинировать вместе.

== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] служат одной и той же цели для всех компонентов.

Следующие атрибуты специфичны для `card`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Название*
|*Описание*
|*Значение по умолчанию*
|[[subtitle]]subtitle
|Задает дополнительное текстовое содержимое с предопределенным стилем. Смотрите <<slot-subtitle,Subtitle>>.
|
|[[title]]title
|Задает текстовое содержимое с предопределенным стилем. Смотрите <<slot-title,Title>>.
|
|[[titleHeadingLevel]]titleHeadingLevel
|Этот параметр определяет уровень HTML-заголовка для текста заголовков. Его значение присваивается https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Attributes/aria-level[HTML-атрибуту aria-level^]. Значение `titleHeadingLevel` должно быть в пределах от 1 до 6. *Важно*: Значения вне допустимого диапазона (1-6) могут вызвать серьезные проблемы с доступностью, и их следует избегать.
|2
|===
