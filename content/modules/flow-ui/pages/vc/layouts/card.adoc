<1> The `elevated` <<theme-variants,theme variant>> applies a shadow effect.
<2> Defines the primary heading using the <<slot-title,title>> predefined slot.
<3> Defines the secondary heading using the <<slot-subtitle,subtitle>> predefined slot.
<4> The <<slot-media,media>> slot contains the product image.
<5> The <<slot-content,content>> slot holds the main descriptive text.
<6> The <<slot-footer,footer>> slot groups action buttons, anchoring them to the bottom of the card.

image::visual-components/layouts/card-basic.png[align="center", width="510"]

The `Card` component displays content in a structured, card-based layout. Information within the card can be populated either through component attributes or by using its internal elements, known as <<slots,slots>>.

The card's visual appearance - including shadows, borders, and backgrounds - is customizable. This is achieved by applying different <<theme-variants,theme variants>>.

[[slots]]
== Slots

The component provides several predefined slots for flexible content organization. A slot is a nested element within the component.

TIP: To add a slot in Jmix Studio, select `card` in the view XML descriptor or in the *Jmix UI* structure panel and click *Add→[Slot Name]* in the *Component Inspector* panel.

NOTE: All slots except <<slot-content,content>> and <<slot-footer,footer>> are limited to containing a single nested component.

[[slot-title]]
=== Title

Textual content with predefined styling.

You can define the card's title in either of the following ways:

* Using the `title` attribute on the component.
* Using a nested `title` element.

[IMPORTANT]
====
* If a title is specified using both the `title` attribute and a nested `title` element, the value from the nested element takes precedence, and the attribute value is ignored.

* The `title` (and `subtitle`) are not rendered if a <<slot-header,header>> slot is present. The custom header markup replaces them entirely.
====

[[slot-subtitle]]
=== Subtitle

The subtitle provides secondary textual content with predefined styling, displayed directly below the title. It is designed to be used in conjunction with a title.

You can define the card's subtitle in either of the following ways:

* Using the `subtitle` attribute on the component.
* Using a nested `subtitle` element.

[IMPORTANT]
====
* If a subtitle is specified using both the `subtitle` attribute and a nested `subtitle` element, the value from the nested element takes precedence, and the attribute value is ignored.

* The `subtitle` (and `title`) are not rendered if a <<slot-header,header>> slot is present. The custom header markup replaces them entirely.

== Theme Variants

The component's appearance is customizable with the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute, which allows you to select among five different options:


.`outlined`
[%collapsible]
====
Applies a border around the card.

image:visual-components/layouts/card-outlined.png[align="center", width=172]
====

.`elevated`
[%collapsible]
====
Adds a shadow effect to create elevation.

image:visual-components/layouts/card-elevated.png[align="center", width=178]
====

.`horizontal`
[%collapsible]
====
Arranges the card content horizontally.

image:visual-components/layouts/card-horizontal.png[align="center", width=174]
====

.`stretch-media`
[%collapsible]
====
Scales the media content to fill its container.

image:visual-components/layouts/card-stretch-media.png[align="center", width=171]
====

.`cover-media`
[%collapsible]
====
Crops the media content to cover its container.

image:visual-components/layouts/card-cover-media.png[align="center", width=176]
====

TIP: You can combine all theme variants together.

== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.

The following attributes are specific to `card`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Name*
|*Description*
|*Default*
|[[subtitle]]subtitle
|Set the secondary textual content with predefined styling. See <<slot-subtitle,Subtitle>>.
|
|[[title]]title
|Set the textual content with predefined styling. See <<slot-title,Title>>.
|
|[[titleHeadingLevel]]titleHeadingLevel
|Sets the title heading level property for the titles. The value of the attribute is set to the https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Attributes/aria-level[aria-level^] HTML attribute. The `titleHeadingLevel` value must be in the range 1-6. *Important*: Values outside the valid range (1-6) can cause significant accessibility issues and should be avoided.
|2
|===
