[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。

下面是 `vbox` 的特殊属性：

[cols="1h,5,1", grid=rows, frame=none]
|===
|*名称*
|*描述*
|*默认值*
|[[boxSizing]]boxSizing
|设置如何计算元素的总宽度和总高度。可选值为：`UNDEFINED`、`CONTENT_BOX`、`BORDER_BOX`。参阅： https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing[MDN 关于 box-sizing^]。
|-
|[[expand]]expand
|设置在布局中需要延展以使用剩余空间的组件。对于 `hbox`，此属性将组件的宽度设置为 100%。
|-
|[[justifyContent]]justifyContent
|定义浏览器如何在内容条目之间和周围分配空间。有关 xref:vc/layout-rules.adoc#justify-content-mode[使用示例]，请参阅布局规则部分。
|`START`
|[[margin]]margin
|定义外边框与容器内容之间的缩进。可选值：`true`、`false`。参阅： https://developer.mozilla.org/en-US/docs/Web/CSS/margin[MDN 关于 margin^]。
|`false`
|[[padding]]padding
|同时设置元素四个边的内边距区域。可选值：`true`、`false`。参阅： https://developer.mozilla.org/en-US/docs/Web/CSS/padding[MDN 关于 padding^]。
|`false`
|[[spacing]]spacing
|设置布局内组件之间的间距。可选值：`true`、`false`。
|`false`
|[[wrap]]wrap
|如果为 `true`，则在空间不足时允许组件换行到新行。参见 Vaadin 文档中的 https://vaadin.com/docs/latest/components/vertical-layout#wrapping[Wrapping]。
|`false`
|===
