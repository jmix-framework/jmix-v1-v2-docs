[[attributes]]
== Атрибуты

В Jmix существует множество xref:vc/common-attributes.adoc[общих атрибутов], которые служат одной цели для всех компонентов.

Следующие атрибуты специфичны для `vbox`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Название*
|*Описание*
|*Значение по умолчанию*
|[[boxSizing]]boxSizing
|Задает способ вычисления общей ширины и высоты элемента. Возможные значения: `UNDEFINED`, `CONTENT_BOX`, `BORDER_BOX`. Смотрите также: https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing[страницу MDN о box-sizing^].
|-
|[[expand]]expand
|Указывает компонент внутри контейнера, который должен быть расширен для использования всего доступного пространства. В случае `hbox` этот атрибут устанавливает ширину компонента на 100%.
|-
|[[justifyContent]]justifyContent
|Определяет, как браузер распределяет пространство между элементами содержимого и вокруг них. См. xref:vc/layout-rules.adoc#justify-content-mode[примеры использования] в разделе Правила компоновки.
|`START`
|[[margin]]margin
|Определяет отступ между внешними границами и содержимым контейнера. Возможные значения: `true`, `false`. Смотрите также: https://developer.mozilla.org/en-US/docs/Web/CSS/margin[страницу MDN о margin^].
|`false`
|[[padding]]padding
|Устанавливает внутренние отступы со всех четырех сторон элемента одновременно. Возможные значения: `true`, `false`. Смотрите также: https://developer.mozilla.org/en-US/docs/Web/CSS/padding[страницу MDN о padding^].
|`false`
|[[spacing]]spacing
|Устанавливает промежутки между компонентами внутри контейнера. Возможные значения: `true`, `false`.
|`false`
|[[wrap]]wrap
|Если true, компоненты будут переноситься на следующую строку при нехватке места. См. https://vaadin.com/docs/latest/components/vertical-layout#wrapping[Wrapping] в документации Vaadin.
|`false`
|===
