* XML-элемент: `vbox`

* Java-класс: `VerticalLayout`

[[boxSizing]]
=== boxSizing

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing" class="mdn-docs-btn" target="_blank">MDN</a>
</div>
++++

Задает способ вычисления общей ширины и высоты элемента. Возможные значения:

* `UNDEFINED`

* `CONTENT_BOX`

* `BORDER_BOX`

[[expand]]
=== expand

Указывает компонент внутри контейнера, который должен быть расширен для использования всего доступного пространства. В случае `vbox` этот атрибут устанавливает высоту компонента на `100%`.

//For a container with vertical placement, this attribute sets 100% height to a component; for the containers with horizontal placement - 100% width. Additionally, resizing a container will resize the expanded component.

[[justifyContent]]
=== justifyContent

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/justify-content" class="mdn-docs-btn" target="_blank">MDN</a>
</div>
++++

Определяет, как браузер распределяет пространство между элементами содержимого и вокруг них. Возможные значения:

* `START`

* `END`

* `CENTER`

* `BETWEEN`

* `AROUND`

* `EVENLY`

Примеры xref:vc/layout-rules.adoc#justify-content-mode[использования] смотрите в разделе Правила компоновки.

[[margin]]
=== margin

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/margin" class="mdn-docs-btn" target="_blank">MDN</a>
</div>
++++

Определяет отступ между внешними границами и содержимым контейнера. Возможные значения - `true`, `false`. По умолчанию `false`.

[[padding]]
=== padding

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/padding" class="mdn-docs-btn" target="_blank">MDN</a>
</div>
++++

Устанавливает внутренние отступы со всех четырех сторон элемента одновременно. Возможные значения - `true`, `false`. По умолчанию `false`.

[[spacing]]
=== spacing

Устанавливает промежутки между компонентами внутри контейнера. Возможные значения - `true`, `false`. По умолчанию `false`.
