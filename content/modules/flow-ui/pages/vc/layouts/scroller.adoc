`scroller` - это контейнер, который создает область содержимого с возможностью прокрутки.

* XML-элемент: `scroller`

* Java-класс: `JmixScroller`

== Основы

`scroller` позволяет отображать содержимое, занимающее много пространства, в меньшей области. Компоненты, размещенные внутри прокручиваемой области, должны быть обернуты в контейнер, такой как xref:flow-ui:vc/layouts/vbox.adoc[].

[[scrollBarsDirection]]
=== scrollBarsDirection

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://vaadin.com/docs/v24/components/scroller/#scroll-direction" class="vaadin-docs-btn" target="_blank">Vaadin</a>
</div>
++++

Определяет, в каких направлениях доступна прокрутка при переполнении области содержимым. Возможные значения:

* `VERTICAL` -- включает вертикальную прокрутку.
* `HORIZONTAL` -- включает горизонтальную прокрутку.
* `BOTH` -- включает прокрутку в обоих направлениях (вертикальном и горизонтальном). Это значение по умолчанию.
* `NONE` -- отключает прокрутку.
