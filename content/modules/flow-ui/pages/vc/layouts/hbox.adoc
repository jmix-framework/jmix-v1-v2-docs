[[justification]]
=== 容器对齐

容器对齐模式可以定义内部元素如何在可用的水平空间中排布。支持：

* `START`（默认）
+
内部元素对齐在左侧（从左到右的地区语言）或右侧（从右到左的地区语言）。

* `CENTER`
+
内部所有元素放置于布局容器的中间。

* `END`
+
内部元素对齐在右侧（从左到右的地区语言）或左侧（从右到左的地区语言）。

* `BETWEEN`
+
在内部元素之间均匀分配可用空间。在第一个元素之前或最后一个元素之后没有额外的空间。

* `AROUND`
+
在内部元素之间均匀分配可用空间。在第一个元素之前或最后一个元素之后的额外的空间是元素之间空间的一半。

* `EVENLY`
+
在内部元素之间均匀分配可用空间。在第一个元素之前或最后一个元素之后的额外的空间跟元素之间空间一样。

使用 <<justifyContent,justifyContent>> 属性设置布局的内容对齐。

请参阅布局规则部分了解 xref:vc/layout-rules.adoc#justify-content-mode[更多用例]。

[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。

下面是 `hbox` 的特殊属性：

[cols="1h,5,1", grid=rows, frame=none]
|===
|*名称*
|*描述*
|*默认值*
|[[boxSizing]]boxSizing
|设置内部元素的宽高如何计算。支持值：`UNDEFINED`、`CONTENT_BOX`、`BORDER_BOX`。参阅 https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing[MDN^]。
|-
|[[expand]]expand
|指定布局容器内的一个组件，该组件可以使用所有的剩余空间。在 `hbox` 中，这个属性会设置组件的宽度为 `100%`。
|-
|[[justifyContent]]justifyContent
|定义浏览器如何在子组件之间分配空间。参阅 <<justification,内容对齐>>。
|`START`
|[[margin]]margin
|定义外部边界与容器内容之间的边距。支持值：`true`、`false`。参阅 https://developer.mozilla.org/en-US/docs/Web/CSS/margin[MDN^]。
|`false`
|[[padding]]padding
|一次性设置子元素的四个内边距。支持值：`true`、`false`。参阅 https://developer.mozilla.org/en-US/docs/Web/CSS/padding[MDN^]。
|`false`
|[[spacing]]spacing
|设置子元素之间的空间。支持值：`true`、`false`。
|`false`
|[[wrap]]wrap
|如果为 `true`，则当空间不足时组件可以依次排入一个新行。参阅 Vaadin 文档的 https://vaadin.com/docs/latest/components/horizontal-layout#wrapping[Wrapping]。
|`false`
|===
