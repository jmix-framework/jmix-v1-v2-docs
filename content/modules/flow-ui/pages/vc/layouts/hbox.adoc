[[justification]]
=== Justification

Justification modes define how items are distributed within the available horizontal space. The following modes are supported:

* `START` (default)
+
Aligns items to the left (for left-to-right languages) or to the right (for right-to-left languages).

* `CENTER`
+
Centers all items horizontally within the layout.

* `END`
+
Aligns items to the right (for left-to-right languages) or to the left (for right-to-left languages).

* `BETWEEN`
+
Distributes available space evenly between items. No extra space is added before the first item or after the last.

* `AROUND`
+
Distributes space evenly around items. The space before the first item and after the last is half the space between adjacent items.

* `EVENLY`
+
Distributes space evenly between all items, including before the first and after the last, ensuring equal spacing throughout.

Use the <<justifyContent,justifyContent>> attribute to set the justify content mode of the layout.

For xref:vc/layout-rules.adoc#justify-content-mode[usage examples] visit the Layout Rules section.

[[attributes]]
== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.

The following attributes are specific to `hbox`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Name*
|*Description*
|*Default*
|[[boxSizing]]boxSizing
|Sets how the total width and height of an element is calculated. Possible values are: `UNDEFINED`, `CONTENT_BOX`, `BORDER_BOX`. See also: https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing[MDN page about box-sizing^].
|-
|[[expand]]expand
|Specifies a component within the layout that should be expanded to use all available space. In the case of `hbox`, this attribute sets the component's width to 100%.
|-
|[[justifyContent]]justifyContent
|Defines how the browser distributes space between and around content items. See <<justification,Justification>>.
|`START`
|[[margin]]margin
|Defines indentation between the outer borders and the container content. Possible values: `true`, `false`. See also: https://developer.mozilla.org/en-US/docs/Web/CSS/margin[MDN page about margin^].
|`false`
|[[padding]]padding
|Sets the padding area on all four sides of an element at once. Possible values: `true`, `false`. See also: https://developer.mozilla.org/en-US/docs/Web/CSS/padding[MDN page about padding^].
|`false`
|[[spacing]]spacing
|Sets spacing between components within a layout. Possible values: `true`, `false`.
|`false`
|[[wrap]]wrap
|If `true` enables components to flow onto a new line when space runs out. See https://vaadin.com/docs/latest/components/horizontal-layout#wrapping[Wrapping] in the Vaadin documentation.
|`false`
|===
