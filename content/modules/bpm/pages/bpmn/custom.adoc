= Custom Form

When an element needs a form that cannot be shown as a simple xref:bpm:input-dialog.adoc[] and cannot use the usual xref:bpm:bpmn/jmix-view-forms.adoc[] annotation-driven approach, you can supply a custom form. This form may still be a Jmix view, or it can be built with an alternative UI technology (e.g., React).

In the modeler, you will need to provide an id for this form. The custom form must read the supplied input parameters and return the outcomes.

== Using Alternative UI Technology

It is possible to create forms with an alternative UI technology (e.g., React) that talk to Jmix BPM via REST. You can obtain form information directly from the engine using Flowable’s `FormService`, that provides the following methods:

* `StartFormData getStartFormData (String processDefinitionId)`
* `TaskFormData getTaskFormData (String taskId)`

Or, expose form metadata using `ProcessFormDataExtractor` in Jmix. See the xref:process-form-data-extractor.adoc[] section for example.
