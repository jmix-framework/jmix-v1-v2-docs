= BPM компоненты

В этой секции описаны ключевые компоненты системы управления бизнес-процессами. xref:bpm:process-engine.adoc[Движок процессов] выполняет процессы, определенные в нотации BPMN. xref:bpm:job-executor.adoc[Исполнитель задач] управляет асинхронными задачами и планирует фоновые задания. xref:bpm:history.adoc[Служба истории] отслеживает экземпляры процессов для анализа производительности и аудита.
