<1> 提供一个 `processDefinitionID` 参数，返回流程启动表单的数据。
<2> 提供一个 `taskID` 参数，返回任务表单的数据。

----
{
  "type": "jmix-screen",
  "screenId": "FormExample",
  "openMode": "DIALOG",
  "businessKey": null,
  "businessKeySource": null,
  "allowedProcessKeys": [],
  "fields": [],
  "outcomes": [],

  "outputVariables": []
}
----
