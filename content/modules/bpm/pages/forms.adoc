= Процессные формы

Элементы xref:bpmn/bpmn-events.adoc#start-events[Start Event] и xref:bpmn/bpmn-user-task.adoc[User Task] могут быть настроены с процессной формой. Это позволит пользователям вводить и отправлять данные, необходимые для выполнения задач.

Доступны следующие типы форм:

* *No form:* для процессов и задач, которые запускаются автоматически без ввода от пользователя.
* xref:input-dialog.adoc[Input dialog]: простой диалог с полями ввода, определёнными в модели процесса.
* xref:bpmn/jmix-view-forms.adoc[Jmix view]: в качестве процессной формы используется экран пользовательского интерфейса Jmix.
* *Custom:* уникально определённая форма, не соответствующая стандартным конфигурациям.
