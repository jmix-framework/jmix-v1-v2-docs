= Start Process

Этот экран позволяет запускать процессы. Пользователи увидят только те процессы, которые им разрешено запускать. Для этого пользователи должен быть указаны как xref:bpmn/bpmn-process.adoc#starter-candidates[starter candidates].

Если процесс имеет форму запуска, она отобразится перед его началом.
