= User Tasks

Этот экран отображает все активные задачи пользователей. Задачи можно фильтровать, используя несколько критериев: по названию процесса, по назначенному исполнителю, по кандидату либо по группе кандидатов.

NOTE: По умолчанию список задач пуст. Нажмите *Apply*, чтобы загрузить все задачи. Чтобы увидеть определенные задачи, настройте фильтр и снова нажмите *Apply*.

image::bpm-menu-views/user-tasks-list.png[,800]

С помощью действий на экране, вы можете перейти экземпляр процесса, к которому принадлежит задача, а также переназначить исполнителя.
