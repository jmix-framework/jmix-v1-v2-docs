* xref:menu-views/decision-tables.adoc[Decision tables]
* xref:menu-views/decision-table-modeler.adoc[Decision table modeler]

[NOTE]
====
Для доступа к экранам, пользователю необходимо назначить соответствующую роль:

* *BPM: process actor* – для доступа к экранам xref:menu-views/start-process-view.adoc[Start process] и xref:menu-views/my-tasks.adoc[My tasks].
* *BPM: administrator* – для доступа ко всем экранам.
====
