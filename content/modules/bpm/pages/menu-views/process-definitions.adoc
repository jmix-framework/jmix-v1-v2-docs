= Process Definitions

Экран *Process Definitions* содержит список доступных определений процессов.

image::bpm-menu-views/process-definitions-list.png[,800]

Выбрав определение, можно выполнить над ним следующие действия:

* Перейти к моделированию на экране xref:bpm:menu-views/modeler-web.adoc[].
* Перейти на экран <<process_definition_details,Process Definition details>> с подробным описанием определения.
* Запустить новый экземпляр процесса.
* Загрузить BPMN XML файл процесса.

[[process_definition_details]]
== Process definition details

Нажав *View details* вы попадёте на экран *Process definition details*, в котором отображаются свойства определения процесса, BPMN XML, а также активные экземпляры процесса.

image::bpm-menu-views/process-deinition-details.png[,800]

* Используйте поле *Version,* чтобы переключаться между версиями определения процесса.

* Нажмите *Suspend,* чтобы приостановить выбранное определение процесса. Это сделает невозможным запуск новых экземпляров на его основе. В диалоге доступен чекбокс с помощью которого можно также приостановить все активные экземпляры процесса. Задачи приостановленных экземпляров не будут отображаться в xref:menu-views/my-tasks.adoc[My tasks], а все таймеры и задания будут остановлены.
+
image::bpm-menu-views/process-definition-suspend.png[,800]
+
* Нажмите *Activate,* чтобы возобновить остановленное ранее определение процесса. Используйте чекбокс, чтобы возобновить выполнение экземпляров процесса.
+
image::bpm-menu-views/process-definition-activate.png[,800]
+
* Нажмите *Migrate all process instances* чтобы запустить xref:bpm:instance-migration.adoc[миграцию экземпляров процесса].
+
image::bpm-menu-views/process-definition-migrate-all.png[]
+
* При необходимости можно удалить конкретную версию определения процесса. Для этого, выберите версию и нажмите кнопку *Delete deployment*.
+
image::bpm-menu-views/process-definitions-delete.png[]
+
IMPORTANT: При удалении определения процесса, будут удалены связанные с ним экземпляры процесса, историческая информация и задания.
