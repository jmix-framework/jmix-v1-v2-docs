= Process Definitions

The *Process Definitions* screen displays a list of available process definitions.

image::bpm-menu-views/process-definitions-list.png[,800]

By selecting a definition, you can perform the following actions:

* Proceed to modeling at xref:bpm:menu-views/modeler-web.adoc[] view.
* Navigate to the <<process_definition_details,Process Definition details>> view for a detailed description of the definition.
* Start a new process instance.
* Upload a BPMN XML process file.

[[process_definition_details]]
== Process definition details

Clicking *View details* takes you to the *Process Definition Details* view, showing the properties of the process definition, the BPMN XML, and any active process instances.

image::bpm-menu-views/process-deinition-details.png[,800]

* Use the *Version* field to switch between versions of the process definition.

* Click *Suspend* to pause the selected process definition. This will prevent new instances from being started based on it. A dialog will appear with a checkbox to also suspend all active instances of the process. Tasks for suspended instances will not appear in xref:menu-views/my-tasks.adoc[My tasks], and all timers and jobs will be halted.
+
image::bpm-menu-views/process-definition-suspend.png[,800]
+
* Click *Activate* to resume a previously suspended process definition. Use the checkbox to resume the execution of process instances.
+
image::bpm-menu-views/process-definition-activate.png[,800]
+
* Click *Migrate all process instances* to initiate the xref:bpm:instance-migration.adoc[process instances migration].
+
image::bpm-menu-views/process-definition-migrate-all.png[]
+
* If necessary, you can delete a specific version of the process definition. To do this, select the version and click the *Delete deployment* button.
+
image::bpm-menu-views/process-definitions-delete.png[]
+
IMPORTANT: Deleting a process definition will also remove any associated process instances, historical information, and tasks.
