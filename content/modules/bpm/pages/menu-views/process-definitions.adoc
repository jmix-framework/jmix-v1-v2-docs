= 流程定义

*Process Definitions（流程定义）* 页面展示可用的流程定义列表。

image::bpm-menu-views/process-definitions-list.png[,800]

选择一个定义后，可以执行下列操作：

* 打开 xref:bpm:menu-views/modeler-web.adoc[] 视图进行建模。
* 导航至 <<process_definition_details,流程定义详情>> 视图以查看定义的详细描述。
* 启动一个新的流程实例。
* 上传 BPMN XML 流程文件。

[[process_definition_details]]
== 流程定义详情

点击 *View details* 打开 *Process Definition Details（流程定义详情）* 视图，其中会展示流程定义的属性、BPMN XML 文件以及所有激活的流程实例。

image::bpm-menu-views/process-deinition-details.png[,800]

* 使用 *Version* 字段可在流程定义的不同版本间切换。

* 点击 *Suspend* 可挂起选中的流程定义。这个操作将防止基于该定义启动新的流程实例。随后会弹出一个带复选框的对话框，用于确认是否同时挂起该流程的所有已激活实例。被挂起实例的任务将不会出现在 xref:menu-views/my-tasks.adoc[我的任务] 中，且所有定时器和作业都会停止。
+
image::bpm-menu-views/process-definition-suspend.png[,800]
+
* 点击 *Activate* 可恢复先前被挂起的流程定义。勾选复选框可恢复流程实例的执行。
+
image::bpm-menu-views/process-definition-activate.png[,800]
+
* 点击 *Migrate all process instances（迁移所有流程实例）* 可启动 xref:bpm:instance-migration.adoc[流程实例迁移]。
+
image::bpm-menu-views/process-definition-migrate-all.png[]
+
* 如有必要，可以删除特定版本的流程定义。操作方法是：选中该版本，然后点击 *Delete deployment* 按钮。
+
image::bpm-menu-views/process-definitions-delete.png[]

[IMPORTANT]
====
实际上，无法删除单个流程定义。
在这种情况下，删除的是整个流程的部署。
请注意：部署可能包含多个流程和资源。
====
