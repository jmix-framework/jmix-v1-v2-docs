= Modeler

The *Modeler* view provides a canvas for creating and editing BPMN process diagrams at runtime.

image::bpm-menu-views/modeler-view.png[width=1392]

== Modeler Features

The following actions are available:

* *Drag-and-drop* – Drag BPMN elements from the palette at the left to add them to the canvas.
* *View properties* – Click the canvas to display process properties or click an element to display its properties; both are editable in the right panel.
* *Deploy process* – Click image:quick-start/deploy-process-button.png[width="32"] to deploy the current process. Redeploying creates a newer version of the corresponding process definition.
* *Open process draft* – Click image:quick-start/open-draft-button.png[width="32"] to open the xref:menu-views/process-drafts.adoc[] lookup view to browse and open saved drafts.
* *Save draft* – Click image:quick-start/save-draft-button.png[width="32"] to save process as draft.
* *Export* – Export the current process as a `.bpmn20.xml` file.
* *Import* – Import a process from a `.bpmn` or `.bpmn20.xml` file.
+
[IMPORTANT]
.Exporting and importing models from other tools
====
BPMN models created in third-party tools may not be fully compatible with Jmix BPM. Similarly, models created in Jmix BPM may have limitations in third-party tools; Jmix-specific elements (for example, xref:bpmn/jmix-entity-data-task.adoc[] and xref:bpmn/jmix-email-task.adoc[]), will appear as standard Service Task in other tools but retain their properties.
====
