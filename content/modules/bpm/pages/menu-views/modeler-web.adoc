= Modeler

Экран *Modeler* предоставляет рабочую область для создания и редактирования BPMN-диаграмм процессов во время выполнения.

image::bpm-menu-views/modeler-view.png[width=1392]

== Возможности Modeler

Доступны следующие действия:

* *Drag-and-drop* — перетаскивайте элементы BPMN из панели слева на рабочую область, чтобы добавить их в диаграмму.
* *Просмотр свойств* — щелкните по рабочей области, чтобы отобразить свойства процесса, или по элементу, чтобы отобразить его свойства; все свойства можно редактировать в правой панели.
* *Deploy process* — нажмите image:quick-start/deploy-process-button.png[width="32"], чтобы развернуть текущий процесс. Повторное развертывание создает новую версию соответствующего определения процесса.
* *Open process draft* — нажмите image:quick-start/open-draft-button.png[width="32"], чтобы открыть экран xref:menu-views/process-drafts.adoc[] для просмотра и открытия сохраненных черновиков.
* *Save draft* — нажмите image:quick-start/save-draft-button.png[width="32"], чтобы сохранить процесс как черновик.
* *Export* — экспортирует текущий процесс в файл `.bpmn20.xml`.
* *Import* — импортирует процесс из файла `.bpmn` или `.bpmn20.xml`.
+
[IMPORTANT]
.Экспорт и импорт моделей из сторонних инструментов
====
Модели BPMN, созданные в сторонних инструментах, могут быть не полностью совместимы с Jmix BPM. Аналогично, модели, созданные в Jmix BPM, могут иметь ограничения при использовании в сторонних инструментах. Элементы, специфичные для Jmix (например, xref:bpmn/jmix-entity-data-task.adoc[] и xref:bpmn/jmix-email-task.adoc[]), в других инструментах отображаются как стандартные Service Task, но сохраняют свои свойства.
