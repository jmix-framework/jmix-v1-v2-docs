= Modeler

Экран моделера позволяет создавать и редактировать модели процессов в запущенном приложении.

image::bpm-menu-views/web-modeler.png[,800]

* В центре находится холст для моделирования процессов, а слева расположена палитра элементов BPMN. Чтобы добавить новый элемент, перетащите его из палитры на холст.

* В панели свойств справа отображаются свойства процесса или свойства выбранного элемента.

* Панель кнопок содержит действия для развертывания процесса, работы с черновиками, импорта и экспорта моделей в формате XML.

[[model-drafts]]
== Черновики модели

Используйте кнопку *Сохранить черновик* чтобы сохранить модель для дальнейшего редактирования.

image::bpm-menu-views/save-draft.png[,800]

Чтобы открыть черновик, используйте кнопку *Открыть черновик* и выберите нужную модель.

image::bpm-menu-views/open-draft.png[]

== Импорт и экспорт моделей

Для экспорта модели, нажмите кнопку *Скачать*. XML модели будет сохранено в файле с расширением `.bpmn20.xml`. В качестве имени файла будет использован _process id_.

Для импорта модель, нажмите кнопку *Загрузить* и выберите файл. Импортированную модель можно редактировать, развернуть, или сохранить как черновик.

[IMPORTANT]
====
Модели BPMN, созданные в сторонних инструментах, могут быть несовместимы с Jmix BPM.

В свою очередь, модели созданные в Jmix BPM будут иметь ограничения в сторонних инструментах: cпециальные элементы из Jmix, такие, как Entity Data task, Email Sending task будут представлены как обычные Service Tasks. Однако они сохранят заданные свойства.
====
