= 建模器

*Modeler（建模器）* 视图提供了一个画布，支持在运行时的创建或编辑 BPMN 流程模型。

image::bpm-menu-views/modeler-view.png[width=1392]

== 建模器功能

可使用以下操作：

* *拖拽* – 从左侧工具箱拖拽 BPMN 元素并添加到画布。
* *查看属性* – 点击画布可以显示流程属性，或点击某个元素以显示其属性；还可以在右侧面板编辑这些属性。
* *部署流程* – 点击 image:quick-start/deploy-process-button.png[width="32"] 部署当前流程。重复部署会导致创建该流程定义的新版本。
* *打开流程草稿* – 点击 image:quick-start/open-draft-button.png[width="32"] 打开 xref:menu-views/process-drafts.adoc[] 列表视图查看已保存的流程草稿。
* *保存草稿* – 点击 image:quick-start/save-draft-button.png[width="32"] 保存流程草稿。
* *导出* – 将当前流程导出为 `.bpmn20.xml` 文件。
* *导入* – 从 `.bpmn` 或 `.bpmn20.xml` 文件导入流程。
+
[IMPORTANT]
.从其他工具导入导出模型
====
第三方工具创建的 BPMN 模型可能与 Jmix BPM 不完全兼容。类似地，用 Jmix BPM 创建的模型在第三方工具中也可能存在限制；Jmix 专有的元素（例如，xref:bpmn/jmix-entity-data-task.adoc[] 和 xref:bpmn/jmix-email-task.adoc[]）在其他工具中会作为标准服务任务出现，但保留其属性。
====
