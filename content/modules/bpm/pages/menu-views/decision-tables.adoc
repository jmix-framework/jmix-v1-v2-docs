= Decision Tables

The *Decision Tables* view displays a list of deployed decision tables and allows you to open them in the modeler, view details, and upload them from an XML file.

NOTE: By default, the list is empty. Click *Apply* to load all tables. To view specific tables, set the filter condition and click *Apply* again.

image::bpm-menu-views/decision-tables.png[,800]

By navigating to the *Decision editor* view, you can examine the decision table's XML definition. Besides, you can delete the deployment.
