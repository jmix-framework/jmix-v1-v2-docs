= Decision Tables

Экран *Decision Tables* содержит список развернутых таблиц решений и позволяет открывать их в моделере, просматривать свойства и загружать из XML-файла.

NOTE: По умолчанию список пуст. Нажмите *Apply*, чтобы загрузить все таблицы. Чтобы увидеть определенные таблицы, настройте фильтр и снова нажмите *Apply*.

image::bpm-menu-views/decision-tables.png[,800]

Перейдя на экран *Decision editor* вы сможете просмотреть таблицу решений в формате XML. Кроме того, вы можете удалить развернутую таблицу.
