== 草稿列表功能

可执行以下操作：

* *预览示意图* — 在右侧面板中预览流程示意图，支持平移和缩放。
* *过滤草稿* — 按名称和作者过滤草稿列表。在字段中输入值时会实时更新结果。
* *Create（新建）* — 从头创建新草稿，或上传 BPMN XML 文件（必须使用 `.bpmn` 或 `.bpmn20.xml` 扩展名）。
* *Edit（编辑）* – 重命名所选草稿并更新其备注，或通过上传其他文件替换其 BPMN XML 文件。
* *Remove（删除）* — 删除所选草稿。
* *Open in Modeler（在建模器打开）* — 在 xref:bpm:menu-views/modeler-web.adoc[] 中打开所选草稿以进行编辑。
* *下载* — 将所选草稿的图表下载为 `.bpmn` 文件。
