= Process Drafts

Экран *Process drafts* позволяет просматривать все доступные черновики процессов.

image:bpm:bpm-menu-views/process-drafts-view.png[width=1392]

[[draft-list-features]]
== Возможности списка черновиков

Доступны следующие действия:

* *Предпросмотр диаграммы* — отображает предварительный просмотр диаграммы процесса в правой панели. Поддерживает навигацию и масштабирование.
* *Фильтрация черновиков* — фильтруйте список по имени и автору. Результаты обновляются по мере ввода.
* *Create* — создает новый черновик с нуля или путем загрузки BPMN XML файла (поддерживаются расширения `.bpmn` и `.bpmn20.xml`).
* *Edit* — позволяет переименовать выбранный черновик, изменить его комментарий или заменить BPMN XML файл, загрузив новый.
* *Remove drafts* — удаляет выбранный черновик.
* *Open in Modeler* — открывает выбранный черновик в xref:bpm:menu-views/modeler-web.adoc[] для редактирования.
* *Download BPMN XML* — загружает диаграмму выбранного черновика в формате `.bpmn`.
