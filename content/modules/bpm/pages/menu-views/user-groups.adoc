= 用户组

*User Groups（用户组）* 视图用于管理用户的分组。用户组是可分配执行特定用户任务的候选人列表。用户可以同时是多个组的成员。

image::bpm-menu-views/user-groups-list.png[,800]

用户组可以是下列类型之一：

* *Users（用户）*。组内的成员需要显式选择。
* *Roles（角色）*。组内成员资格由配置的角色集合决定。如果用户被分配相应角色，将被视为组内成员。
* *All users（所有用户）*。该组包含所有用户。
