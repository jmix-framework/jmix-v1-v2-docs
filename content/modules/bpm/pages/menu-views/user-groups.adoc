= User Groups

The *User Groups* view manages user groups. A user group is a list of candidates that can be assigned to perform a specific user task. A user can be a member of multiple groups.

image::bpm-menu-views/user-groups-list.png[,800]

A group can be one of the following types:

* *Users*. Members of this group must be selected explicitly.
* *Roles*. Membership in the group is determined by the current set of user roles. Users are considered members of the user group if they are given appropriate roles.
* *All users*. This group automatically includes all users.
