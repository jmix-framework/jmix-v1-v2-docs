= 流程实例

*Process Instances（流程实例）* 视图显示激活和已完成的流程实例列表。

image::bpm-menu-views/process-instances-list.png[,800]

[[process-instance-list]]
== 实例列表功能

可执行以下操作：

* *实例过滤* — 按流程定义、业务键值或完成状态（`Active` 或 `Completed`）筛选实例。
* *实例排序* – 按 *Start time*、*End time* 或其他表格列对列表排序。
* *实例编辑* – 在列表中选择一个实例，然后点击 *Edit* 打开 **Process instance detail（流程实例详情）** 视图。


[[process-instance-detail]]
== 流程实例详情

**Process instance detail（流程实例详情）** 视图用于显示所选流程实例的详细信息，并支持对其进行管理。

image::bpm-menu-views/process-instance-detail.png[,800]

可执行以下操作：

* *Migrate（迁移）* — 启动 xref:bpm:instance-migration.adoc[流程实例迁移]，将其迁移至更新版本的流程定义。
* *Suspend（挂起）* – 暂停该流程实例。
* *Delete（删除）* — 永久删除该流程实例。
* *Runtime 标签页* — 显示该实例的运行时信息：
** *Execution tree（执行树）* — 以树形结构展示流程实例中的活动。
** *Variables 标签页* — 支持创建、编辑和删除流程变量。
+
image::bpm-menu-views/process-variable-editor.png[width=1204]
+
** *Tasks 标签页* — 显示活跃任务，并支持将任务 *重新分配* 给其他用户。
+
image::bpm-menu-views/task-reassignment.png[width=1204]
+
** *Failed jobs 标签页* — 列出发生错误的作业，提供堆栈跟踪信息，并支持在问题解决后重试这些作业。
+
image::bpm-menu-views/failed-job.png[width=1204]
+
* *History 标签页* — 显示所有用户任务（包括活跃和已完成的）、活动以及流程变量的最新值。
+
image::bpm-menu-views/process-instance-history.png[width=986]

* *Diagram 标签页* — 显示流程示意图，并以可视方式标示已执行的路径。
+
image::bpm-menu-views/process-instance-diagram.png[width=1260]
+
** 已完成的活动以绿色高亮显示。
** 当前活动元素以蓝色高亮显示。
