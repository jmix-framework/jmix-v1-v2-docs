= Process Instances

Экран *Process Instances* отображает список активных и завершенных экземпляров процессов.

image::bpm-menu-views/process-instances-list.png[,800]

[[process-instance-list]]
== Возможности списка экземпляров

Доступны следующие действия:

* *Фильтрация экземпляров* — фильтруйте экземпляры по определению процесса, бизнес-ключу или состоянию (`Active` или `Completed`).
* *Сортировка экземпляров* — сортируйте список по *Start time*, *End time* или другим столбцам таблицы.
* *Редактирование экземпляра* — выберите экземпляр в списке и нажмите *Edit*, чтобы открыть экран **Process instance detail**.


[[process-instance-detail]]
== Детали экземпляра процесса

Экран **Process instance detail** отображает подробную информацию о выбранном экземпляре процесса и позволяет управлять им.

image::bpm-menu-views/process-instance-detail.png[,800]

Доступны следующие действия:

* *Migrate* — запускает xref:bpm:instance-migration.adoc[миграцию экземпляра процесса] на более новую версию определения процесса.
* *Suspend* — приостанавливает экземпляр процесса.
* *Delete* — безвозвратно удаляет экземпляр процесса.
* *Runtime tab* — отображает информацию о состоянии выполнения экземпляра:
** *Execution tree* — показывает активности экземпляра процесса в виде дерева.
** *Variables tab* — позволяет создавать, редактировать и удалять переменные процесса.
+
image::bpm-menu-views/process-variable-editor.png[width=1204]
+
** *Tasks tab* — отображает активные задачи и позволяет переназначать их другим пользователям.
+
image::bpm-menu-views/task-reassignment.png[width=1204]
+
** *Failed jobs tab* — содержит список задач с ошибками, показывает стек вызовов и позволяет повторно выполнить их после устранения проблемы.
+
image::bpm-menu-views/failed-job.png[width=1204]
+
* *History tab* — отображает все пользовательские задачи (активные и завершенные), выполненные действия и последние значения переменных процесса.
+
image::bpm-menu-views/process-instance-history.png[width=986]

* *Diagram tab* — отображает диаграмму процесса с визуальной индикацией прогресса выполнения.
+
image::bpm-menu-views/process-instance-diagram.png[width=1260]
+
** Выполненные действия подсвечены зелёным.
** Активный элемент подсвечен синим.
