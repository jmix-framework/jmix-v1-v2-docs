= Роли безопасности

Для доступа к функциональности дополнения Data Tools пользователям с ограниченными системными разрешениями должна быть назначена одна из следующих предопределенных xref:security:resource-roles.adoc[ресурсных ролей]:

* *Data Tools: full access*: Эта системная роль предоставляет полный доступ ко всем функциям и возможностям Data Tools. Пользователи с этой ролью могут выполнять все операции в рамках дополнения Data Tools.
* *Data Tools: minimal access*: Эта системная роль предоставляет доступ только для чтения к функциям Data Tools. Пользователи с этой ролью могут просматривать данные и информацию в дополнении Data Tools, но не могут изменять или создавать данные.
* *Data Tools: Entity Information view*: Эта системная роль предоставляет доступ к конкретной функциональности `InfoValue` в рамках Data Tools, позволяя пользователям просматривать детальную информацию о сущностях.

Доступны следующие xref:security:resource-roles.adoc#specific-policy[специфические политики] для пользовательских конфигураций безопасности:

* *datatools.importExportEntity*: Управляет разрешениями на импорт и экспорт сущностей через экраны Data Tools.
* *datatools.showEntityInfo*: Управляет доступом к функциональности `InfoValue`. Эта политика гарантирует, что пользователи могут просматривать детальную информацию о сущностях только при наличии необходимых разрешений.
