= Действие просмотра информации о сущности

Дополнение Data Tools предоставляет xref:flow-ui:actions.adoc[действие] пользовательского интерфейса, которое отображает системную информацию о выбранной сущности. Оно включает название сущности, Java-класс, таблицу базы данных, идентификатор и значения системных атрибутов, составляющих xref:data-model:entities.adoc#traits[черты] (traits) сущности.

Например:

image::entity-info-action-2.png[align="center",width="816"]

Чтобы добавить действие в таблицу данных с помощью Studio, выберите таблицу данных в xref:studio:screen-designer.adoc[Дизайнере экранов], нажмите *Add -> Actions -> Action* на панели инспектора и выберите `datatl_showEntityInfo` в диалоговом окне *Add Action*. Действие будет добавлено в таблицу данных, например:

[source,xml,indent=0]
----
<dataGrid id="usersDataGrid" ...>
    <actions>
        ...
        <action id="showEntityInfo" type="datatl_showEntityInfo"/>
    </actions>
----

// todo flowui

Действие отображается в контекстном меню таблицы данных как пункт *Entity information*:

image::entity-info-action-1.png[align="center",width="460"]

NOTE: Для использования действия пользователь должен иметь ресурсную роль `datatools-entity-info`, предоставляемую дополнением Data Tools.
