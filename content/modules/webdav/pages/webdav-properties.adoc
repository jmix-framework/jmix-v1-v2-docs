= Свойства приложения WebDAV

[[jmix.webdav.applications]]
== jmix.webdav.applications

Сопоставляет форматы документов с внешними приложениями, которые должны открывать эти документы. Вы можете настроить набор расширений файлов для каждого приложения в свойстве "extensions".

Например, следующее сопоставление настраивает систему на открытие файлов PPT и PPTX в Microsoft PowerPoint:

[source,properties,indent=0]
----
"ms-powerpoint":{\
  "name":"Microsoft PowerPoint",\
  "protocols":{"writable":"ms-powerpoint:ofe%7Cu%7C","read_only":"ms-powerpoint:ofv%7Cu%7C"},\
  "extensions":["ppt","pptx"]\
  }
----

Значение по умолчанию:

[source,properties,indent=0]
----
{"ms-word":{"name":"Microsoft Word","protocols":{"writable":"ms-word:ofe%7Cu%7C",\
  "read_only":"ms-word:ofv%7Cu%7C"},"extensions":["docx","doc","rtf"]},\
  "ms-excel":{"name":"Microsoft Excel","protocols":{"writable":"ms-excel:ofe%7Cu%7C",\
  "read_only":"ms-excel:ofv%7Cu%7C"},"extensions":["xls","xlsx"]},\
  "ms-powerpoint":{"name":"Microsoft PowerPoint",\
  "protocols":{"writable":"ms-powerpoint:ofe%7Cu%7C","read_only":"ms-powerpoint:ofv%7Cu%7C"},\
  "extensions":["ppt","pptx"]}}
----

Пример значения для LibreOffice:

[source,properties,indent=0]
----
jmix.webdav.applications = {"vnd.libreoffice.command":\
  {"name":"LibreOffice","protocols":\
  {"writable":"vnd.libreoffice.command:ofe|u|",\
  "read_only":"vnd.libreoffice.command:ofv|u|"},\
  "extensions":["odt", "ods", "odp", "doc", "docx", "xls", "xlsx", "ppt", "pptx"]}}
----

[[jmix.webdav.authentication-method]]
== jmix.webdav.authentication-method

Определяет тип авторизации.

Значение по умолчанию: `basic`.

Хотя это не рекомендуется, вы можете установить в этом свойстве значение `digest` и не настраивать HTTPS на сервере. В этом случае не забудьте изменить свойство <<jmix.webdav.url-prefix>>, чтобы генерировать ссылки с правильным протоколом и портом сервера. Также обратите внимание, что у всех пользователей должны быть хешированные пароли, хранящиеся отдельно в базе данных. Дополнение обновляет эти пароли при изменении пароля пользователя, поэтому вам нужно сделать это для каждого пользователя после настройки digest-авторизации.

[[jmix.webdav.auto-generate-unique-resource-uri]]
== jmix.webdav.auto-generate-unique-resource-uri

Если это свойство установлено в значение `false` и у только что загруженного документа URI уже присвоен другому документу, произойдет нарушение ограничения уникальности.

Если это свойство установлено в значение `true` и URI уже присвоен какому-либо документу, автоматически будет сгенерирован новый путь в формате `\{id}.extension`.

Значение по умолчанию: `true`.

[[jmix.webdav.document-versions-cleaning-cron]]
== jmix.webdav.document-versions-cleaning-cron

Это свойство позволяет при необходимости изменить расписание задачи xref:webdav:configuration.adoc#webdav-document-versions-cleaning-job[WebdavDocumentVersionsCleaningJob] в виде http://www.quartz-scheduler.org/documentation/quartz-2.3.0/tutorials/crontrigger.html[cron^]-выражения.

Значение по умолчанию — `0 0 0 1 * ? *` (раз в месяц).

[[jmix.webdav.expired-lock-cleaning-cron]]
== jmix.webdav.expired-lock-cleaning-cron

Это свойство позволяет при необходимости изменить расписание задачи xref:webdav:configuration.adoc#expired-lock-cleaning-job[ExpiredLockCleaningJob] в виде http://www.quartz-scheduler.org/documentation/quartz-2.3.0/tutorials/crontrigger.html[cron^]-выражения.

Значение по умолчанию — `0 0 0/2 ? * *` (каждые два часа).

[[jmix.webdav.file-storage]]
== jmix.webdav.file-storage

Определяет xref:files:file-storage.adoc[хранилище файлов], используемое для хранения файлов WebDAV.

По умолчанию используется хранилище файлов, возвращаемое методом `FileStorageLocator.getDefault()`.

[[jmix.webdav.lock-timeout]]
== jmix.webdav.lock-timeout

Определяет интервал по умолчанию в миллисекундах для xref:webdav:webdav-documents.adoc#lock-unlock[блокировки] документа.

Значение по умолчанию: `600000`.

[[jmix.webdav.use-default-document-versions-cleaner-quartz-configuration]]
== jmix.webdav.use-default-document-versions-cleaner-quartz-configuration

Это свойство позволяет отключить конфигурацию по умолчанию, которая создает и планирует задачу xref:webdav:configuration.adoc#webdav-document-versions-cleaning-job[WebdavDocumentVersionsCleaningJob].

Значение по умолчанию: `true`.

[[jmix.webdav.use-default-expired-lock-cleaner-quartz-configuration]]
== jmix.webdav.use-default-expired-lock-cleaner-quartz-configuration

Это свойство позволяет отключить конфигурацию по умолчанию, которая создает и планирует задачу xref:webdav:configuration.adoc#expired-lock-cleaning-job[ExpiredLockCleaningJob].

Значение по умолчанию: `true`.

[[jmix.webdav.url-prefix]]
== jmix.webdav.url-prefix

Определяет префикс для ссылки на документ WebDAV.

Значение по умолчанию: `\https://localhost:8443/webdav`.

Оно должно соответствовать корневому URL приложения с дополнительным путем `/webdav`.

[[jmix.webdav.versioning-enabled]]
== jmix.webdav.versioning-enabled

Включает версионирование для всех атрибутов типа `WebdavDocument` без аннотации `@WebdavSupport`.

Значение по умолчанию: `true`.
