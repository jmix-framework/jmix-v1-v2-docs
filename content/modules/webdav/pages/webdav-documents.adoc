= Документы WebDAV

После того как дополнение добавлено в ваше приложение, в главном меню появляется пункт *WebDAV*.

Экран *WebDAV Documents* позволяет пользователям просматривать, редактировать и управлять документами, хранящимися на сервере WebDAV.

image::document-browser.png[align="center", width="1462"]

Этот экран отображает список документов и поддерживает следующие операции:

* *Upload*: кнопка *Upload* позволяет выбрать и загрузить файлы в систему.
* *Download*: кнопка *Download* позволяет скачать последнюю или предыдущие версии документа.
* *Manage Versions*: кнопка *Manage Versions* открывает экран xref:version-control.adoc#webdav-document-versions[версий документов WebDAV].
* *Enable/Disable Versioning*: кнопки *Enable Versioning* и *Disable Versioning* управляют версионированием для конкретного документа.
+
[[lock-unlock]]
* *Lock*: чтобы удалить документ, необходимо сначала заблокировать его, нажав кнопку *Lock*.
+
Если другие пользователи попытаются сохранить изменения в этом документе, они получат предупреждение о том, что документ заблокирован.
+
Продолжительность блокировки документа можно настроить с помощью свойства xref:webdav-properties.adoc#jmix.webdav.lock-timeout[jmix.webdav.lock-timeout].

[[collections]]
== Коллекции

Вы можете создать коллекцию `WebdavDocument`, используя кнопку *Create Collection* на экране *WebDAV Documents*.

Коллекция `WebdavDocument` представляет собой особый тип `WebdavDocument`, который выступает в роли контейнера для других документов. Родительская коллекция документа `WebdavDocument` указывается атрибутом `parent`. Если этот атрибут не задан для документа, документ считается принадлежащим корневой (верхнего уровня) коллекции.

По умолчанию пользователям разрешено загружать документы с одинаковыми именами в одну и ту же коллекцию (например, в корневой коллекции могут быть два разных документа с именем `Contract1.docx`). Если вы хотите обеспечить уникальность URI документов, имитируя настоящую файловую систему, вы можете установить свойство xref:webdav-properties.adoc#jmix.webdav.auto-generate-unique-resource-uri[jmix.webdav.auto-generate-unique-resource-uri] в значение `false`. В этом случае попытка загрузить документ с уже существующим URI приведет к нарушению ограничения уникальности.

Вы можете переименовывать и удалять коллекции с помощью кнопок *Rename* и *Remove*.
