= Часть 2. Продвинутый уровень

В этой главе вы создадите:

* Сущность `WebdavFolder`.

== Создание сущности WebdavFolder

Один из атрибутов сущности `WebdavFolder` — `classification`, который содержит информацию о типе папки. Поэтому создадим перечисление `Classification`, состоящее из двух значений: `Public` и `Restricted`.

Подробные инструкции по созданию перечислений можно найти в разделе xref:tutorial:enumerations.adoc[Использование перечислений] самоучителя.

image::enum-classification.png[align="center", width="427"]

Далее создайте сущность `WebdavFolder`. Подробные инструкции по созданию сущностей можно найти в разделе xref:tutorial:simple-crud.adoc[Простой CRUD] самоучителя.

Сущность `WebdavFolder` имеет следующие атрибуты:

* `name` типа `String`. Установите флажок *Mandatory*.
* `classification` типа перечисления `Classification`.
* `department` типа `Department`:
** *Attribute type*: `ASSOCIATION`
** *Type*: `Department`
** *Cardinality*: `Many to One`
** *FK constraint action*: `DENY`
* `parent` типа `WebdavFolder`:
** *Attribute type*: `ASSOCIATION`
** *Type*: `WebdavFolder`
** *Cardinality*: `Many to One`

== Добавление атрибута WebdavFolder в WebdavDocumentWrapper

Теперь добавьте атрибут `webdavFolder` в сущность `WebdavDocumentWrapper`:

Дважды щелкните на сущности `WebdavDocumentWrapper` в окне инструмента *Jmix* и выберите ее последний атрибут (чтобы добавить новый атрибут в конец):

image::add-attr-wbddocwrapper.png[align="center", width="912"]

Нажмите *Add* (image:add.svg[]) на панели инструментов *Attributes*. В диалоговом окне *New Attribute* введите `folder` в поле *Name*, выберите `ASSOCIATION` в списке *Attribute type* и `WebdavFolder` в списке *Type*. Выберите CASCADE в списке *FK constraint action*.

image::add-folder-attr.png[align="center", width="862"]

Нажмите *OK*.

=== Определение раздела данных

Согласно предоставленному эскизу дизайна, на экране будет два контейнера данных, данные из которых будут использоваться для отображения списка папок и списка документов WebDAV, относящихся к папкам.

. Сначала добавьте контейнер данных, который будет предоставлять коллекцию сущностей `WevdavFolder` для дерево-таблицы. Нажмите *Add Component* на панели действий, выберите раздел *Data components* и дважды щелкните на элементе *Collection*. В окне *Collection Properties Editor* выберите `WevdavFolder` в поле *Entity*, снимите флажок *Read only* и нажмите *OK*:
+
image::folder-collection-create.png[align="center", width="729"]
+
Studio создаст контейнер коллекции:
+
[source,xml]
----
<data>
    <collection id="webdavFoldersDc"
                class="com.company.onboarding.entity.WebdavFolder">
        <fetchPlan extends="_base"/>
        <loader id="webdavFoldersDl">
            <query>
                <![CDATA[select e from WebdavFolder e]]>
            </query>
        </loader>
    </collection>
</data>
----
. Затем добавьте контейнер данных, который будет предоставлять коллекцию сущностей `WebdavDocumentWrapper` для таблицы данных. Нажмите *Add Component* на панели действий, выберите раздел *Data components* и дважды щелкните на элементе *Collection*. В окне *Collection Properties Editor* выберите `WebdavDocumentWrapper` в поле *Entity*. Нажмите кнопку *Edit* (image:edit.svg[]) справа от поля *Fetch plan*.

+
image::wbdoc-wrapper-collection-create.png[align="center", width="729"]
+
Выберите атрибут `wevdavDocument`, а затем атрибут `lastVersion` для него в диалоговом окне *Edit Fetch Plan*.
+
image::wbdoc-wrapper-collection-create2.png[align="center", width="848"]
+
Studio создаст контейнер коллекции:
+
[source,xml,indent=0]
----
        <collection id="webdavDocumentWrappersDc"
                    class="com.company.onboarding.entity.WebdavDocumentWrapper">
            <fetchPlan extends="_base">
                <property name="webdavDocument" fetchPlan="_base">
                    <property name="lastVersion" fetchPlan="_base"/>
                </property>
            </fetchPlan>
            <loader id="webdavDocumentWrappersDl" readOnly="true">
                <query>
                    <![CDATA[select e from WebdavDocumentWrapper e]]>
                </query>
            </loader>
        </collection>
----
+
Запрос по умолчанию загрузит все экземпляры `WebdavDocumentWrapper`, но вам нужно выбирать только документы текущей папки webdav. Изменим запрос с помощью *JPQL Query Designer*. Выберите `webdavDocumentWrappersDl` на панели структуры *Jmix UI* и щелкните значение атрибута `query`. Затем добавьте условие `where` по атрибуту `folder` с параметром `:folder`.
+

image::wbdoc-wrapper-query.png[align="center", width="935"]
+
В результате запрос должен выглядеть так:
+
[source,xml,indent=0]
----
            <loader id="webdavDocumentWrappersDl" readOnly="true">
                <query>
                    <![CDATA[select e from WebdavDocumentWrapper e
                    where e.folder = :folder]]>
                </query>
            </loader>
----

Передачу параметра `:folder` в запрос мы реализуем немного позже, а сейчас создадим визуальные компоненты для отображения списка папок и документов.

=== Добавление UI-компоновки

Поскольку экран *Knowledge base* разделен на две области, мы используем компоновку xref:flow-ui:vc/layouts/split.adoc[split]. Добавьте компоновку `split`, а затем последовательно добавьте в нее два вертикальных блока (xref:flow-ui:vc/layouts/vbox.adoc[vbox]). В первом вертикальном блоке находится горизонтальный блок с кнопками управления дерево-таблицей и xref:flow-ui:vc/components/treeDataGrid.adoc[treeDataGrid] с иерархией папок. Во втором вертикальном блоке находится горизонтальная панель с кнопками управления таблицей данных и xref:flow-ui:vc/components/dataGrid.adoc[dataGrid] с документами WebDAV. Шаблон экрана выглядит так:

[source,xml,indent=0]
----
    <layout>
        <split width="100%" height="100%" splitterPosition="17">
            <vbox>
                <hbox id="webdavFoldersButtonsPanel"
                      classNames="buttons-panel"/>
                <!--We will later add a folder treeDataGrid here-->
            </vbox>
            <vbox>
                <hbox id="documentsButtonsPanel"
                      classNames="buttons-panel"/>
                <!--We will later add a webDAV document dataGrid here-->
            </vbox>
        </split>
    </layout>
----

=== Создание TreeDataGrid для WebdavFolder

Добавьте компонент `treeDataGrid` в первый вертикальный блок. Выберите `WebdavFolder` в поле *Entity* и контейнер данных `webdavFoldersDc` в диалоговом окне *TreeDataGrid Properties Editor*:

image::webdav-folder-tree-data-grid.png[align="center", width="762"]

Удалите лишнюю колонку `classification` и установите свойство `hierarchy` в значение `parent`.

[source,xml,indent=0]
----
                <treeDataGrid dataContainer="webdavFoldersDc"
                              hierarchyProperty="parent"
                              width="100%"
                              id="webdavFoldersTreeDataGrid">
                    <actions>
                        <action id="create" type="list_create"/>
                        <action id="edit" type="list_edit"/>
                        <action id="remove" type="list_remove"/>
                    </actions>
                    <columns>
                        <column property="name"/>
                    </columns>
                </treeDataGrid>
----
