= UI-компоненты

Дополнение WebDAV включает UI-компоненты, облегчающие работу с документами WebDAV.

Чтобы добавить эти компоненты на экран, используйте Jmix Studio.

Нажмите *Add Component* на панели действий, затем введите `webdav` в поле поиска. В списке результатов выберите нужный компонент и дважды щелкните на нем.

image::add-webdav-component.png[align="center",width="767"]

Новый элемент будет добавлен как на панели структуры *Jmix UI*, так и в XML. Вы можете настраивать атрибуты, такие как xref:flow-ui:vc/common-attributes.adoc#id[id], xref:flow-ui:vc/common-attributes.adoc#height[height], xref:flow-ui:vc/common-attributes.adoc#width[width] и т. д., так же, как это делается для других xref:flow-ui:vc/components.adoc[UI-компонентов].

[source,xml,indent=0]
----
<webdav:webdavDocumentUpload id="webdavDocumentField"
                             property="webdavDocument"
                             colspan="2"/>
----

Если вы не используете дизайнер экранов, объявите пространство имен `webdav` в XML-дескрипторе вашего экрана вручную:

----

[[webdav-document-link]]
== WebdavDocumentLink

`WebdavDocumentLink` — UI-компонент, позволяющий пользователям открывать документы в настольных офисных приложениях. Кроме того, если поддерживается версионирование документа, пользователи могут просматривать все его версии.

image::ui-webdav-document-link.png[align="center",width="994"]

Компонент предоставляет следующие возможности:

* Открытие последней версии документа для просмотра и редактирования.
* Открытие предыдущих версий документа в режиме только для чтения (подробнее см. xref:webdav:version-control.adoc#webdav-document-versions[Версии документов WebDAV]).

В примере ниже `WebdavDocumentLink` будет xref:flow-ui:vc/components/dataGrid.adoc#renderers[отрендерен] в левой колонке таблицы данных:

[source,xml,indent=0]
----
        <dataGrid id="webdavDocumentWrappersDataGrid"
                  width="100%"
                  minHeight="20em"
                  dataContainer="webdavDocumentWrappersDc"
                  columnReorderingAllowed="true">
            <columns resizable="true">
                <column property="webdavDocument"/>
                <column property="description"/>
                <column property="lastModifiedBy"/>
                <column property="lastModifiedDate"/>
            </columns>
        </dataGrid>
----

Обработчик `renderer` создает и возвращает компонент `WebdavDocumentLink`:

[source,java,indent=0]
----
include::example$/webdav-ex1/src/main/java/com/company/onboarding/view/webdavdocumentwrapper/WebdavDocumentWrapperListView.java[tags=webdavDocument-renderer]
----
<1> Метод возвращает объект `Renderer`, создающий UI-компонент для отображения в колонке.
<2> Экземпляр компонента `WebdavDocumentLink` создается с помощью фабрики `UiComponents`.

[[webdav-document-version-link]]
== WebdavDocumentVersionLink

`WebdavDocumentVersionLink` позволяет открывать конкретную версию документа в настольных офисных приложениях в режиме только для чтения. Компонент отображает имя файла конкретной версии документа.

Чтобы создать `WebdavDocumentVersionLink`, используйте фабрику `UiComponents`.

[source,java,indent=0]
----
WebdavDocumentVersionLink webdavDocumentVersionLink =
    uiComponents.create(WebdavDocumentVersionLink.class);
webdavDocumentVersionLink.setWebdavDocumentVersion(documentVersion);
----

[[webdav-document-upload-field]]
== WebdavDocumentUploadField

Компонент `WebdavDocumentUploadField` специально предназначен для работы с документами.

Имя XML-компонента: `webdavDocumentUpload`.

Компонент предоставляет следующие возможности:

* Загрузка файла для создания нового документа или новой версии существующего документа.
* Открытие документа для просмотра или редактирования.
* Скачивание последней или предыдущих версий документа.
* Создание новых версий документа на основе существующих версий.

=== Режимы работы

Компонент работает в двух режимах:

* *Versioning Enabled*: когда версионирование включено, компонент `WebdavDocumentUploadField` отображается без каких-либо ограничений.
* *Versioning Disabled*: когда версионирование отключено, компонент `WebdavDocumentUploadField` не отображает ссылку на последнюю версию документа.
