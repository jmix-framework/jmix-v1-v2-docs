= BPMN Modeler

Studio предоставляет Моделер BPMN, который позволяет проектировать бизнес-процессы в IDE. Моделер появляется только при добавлении в проект xref:bpm:index.adoc[дополнения BPM].

См. описание моделера в разделе xref:bpm:modeler-studio.adoc[].

[NOTE]
====
This feature requires a BPM xref:studio:subscription.adoc#enterprise-subscription[subscription]. If you don't have the subscription, see the xref:ROOT:account-management.adoc#enterprise-trial[Enterprise+BPM Trial] section for how to get a trial version.
====
