= BPMN Modeler

Studio provides BPMN Modeler that allows you to model business processes in the IDE.
The Modeler appears only when the xref:bpm:index.adoc[BPM add-on] is added to the project.
See the description of the xref:bpm:modeler-studio.adoc[BPMN Modeler] in Studio.

[NOTE]
====
This feature requires a BPM xref:studio:subscription.adoc#enterprise-subscription[subscription]. If you don't have the subscription, see the xref:ROOT:account-management.adoc#enterprise-trial[Enterprise+BPM Trial] section to learn how to get a trial version.
====
