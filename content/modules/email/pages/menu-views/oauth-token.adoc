= OAuth2 token

Административный экран *OAuth2 token* позволяет предоставлять или изменять значение токена обновления во время выполнения.

image::oauth-token-view.png[align="center"]

[NOTE]
====
Предоставьте ресурсную роль *Email: token manager*, чтобы разрешить доступ к этому экрану пользователям, не являющимися администраторами.
====
