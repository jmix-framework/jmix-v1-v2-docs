= Глобальная синхронизация пользователей

Дополнение предоставляет бин `LdapUserSynchronizationManager`, который синхронизирует пользователей из определенной группы LDAP, указанной в свойстве xref:ldap:properties.adoc#jmix.ldap.group-for-synchronization[jmix.ldap.group-for-synchronization]. Обычно этот бин вызывается при выполнении запланированной задачи, например, раз в день, но также может быть запущен через JMX-бин. Синхронизация также опирается на `LdapUserDetailsSynchronizationStrategy`, объявленную в приложении, а также на синхронизацию при входе в систему.
