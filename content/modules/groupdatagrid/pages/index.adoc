此扩展组件提供了 xref:groupdatagrid:groupdatagrid-component.adoc[groupDataGrid]。当需要在表格中对列进行分组时，可将其作为 xref:flow-ui:vc/components/dataGrid.adoc[] 和 xref:flow-ui:vc/components/treeDataGrid.adoc[] 的替代方案。

image::groupdatagrid-basic.png[align="center",width="1097"]

主要特性：

* *多层级分组：* 按多个条件对行进行分组。
* *用户可控：* 用户可以直接从 UI 进行分组并更改分组顺序。
* *内置排序：* 在分组内保持排序。
* *导出 Excel：* 导出时可将分组展平或保留原始分组结构。
* *样式灵活：* 配置分组、表头、图标以及表格的整体外观。

+

+
