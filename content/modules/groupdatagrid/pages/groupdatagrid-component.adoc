++++
<div class="jmix-ui-live-demo-container">

Компонент `groupDataGrid` — более функциональная версия базовой таблицы данных с широкими возможностями группировки строк. Он группирует строки по повторяющимся значениям столбца, объединяя их в сворачиваемые блоки, с поддержкой многоуровневой группировки и изменения порядка группировки перетаскиванием.

[[Basics]]
== Основы

Для начала работы xref:groupdatagrid:index.adoc#installation[установите дополнение], а затем добавьте компонент через палитру *Add Component* в xref:studio:view-designer.adoc[Дизайнере экранов] Studio.

image::groupdatagrid-palette.png[align="center",width="765"]

В следующем примере клиенты группируются по значениям столбца *Grade*.

image::groupdatagrid-basic.png[align="center",width="1097"]

====

----
include::example$/groupdatagrid-ex1/src/main/resources/com/company/groupdatagridex1/view/basicgroupgrid/basic-group-grid-view.xml[tags=view;data;facets;layout;customersDc;basics]

<3> Определение столбца группировки.

[[data-binding]]
== Привязка данных

Привязка данных — это связывание визуального компонента с контейнером данных. Чтобы связать компонент с данными, используйте атрибут `dataContainer` со ссылкой на xref:flow-ui:data/collection-container.adoc[контейнер коллекции]. См. пример выше.

[[group-item]]
== Элемент группы

Элементы группы — это специальные записи, создаваемые при группировке. Они отображаются как строки, содержащие только заголовок группы.

image::groupdatagrid-group-items.png[align="center",width="1097"]

Для отображения элементов группы уровень привязки данных создаёт временный пустой экземпляр сущности или DTO. Этот экземпляр не добавляется в xref:flow-ui:data/collection-container.adoc[контейнер коллекции] и существует только в памяти на время группировки.

[[hide-group-item-count]]
=== Скрытие счётчика элементов группы

По умолчанию элементы группы отображают количество вложенных записей. Чтобы скрыть это число, используйте свойство `displayItemCount` элемента <<groupColumn,groupColumn>>.

image::groupdatagrid-hide-count.png[align="center",width="1097"]

[[multi-level-grouping]]
== Многоуровневая группировка

Компонент поддерживает группировку по нескольким столбцам. Щёлкните значок столбца группировки, чтобы открыть диалог *Group by*, а затем добавьте или удалите столбцы.

image::groupdatagrid-multiple.png[align="center",width="1100"]

[[disable-grouping]]
== Отключение группировки

Чтобы запретить пользователям группировку по определённому столбцу, установите его свойству `groupAllowed` значение `false`. Это убирает столбец из диалога *Group by*. В примере ниже столбец *Country* не может быть сгруппирован:

image::groupdatagrid-groupallowed.png[align="center",width="1100"]

.XML code
[%collapsible]
====
[source,xml,indent=0]
----
include::example$/groupdatagrid-ex1/src/main/resources/com/company/groupdatagridex1/view/disablegrouping/disable-grouping-view.xml[tags=disable-grouping]
----
====

Чтобы полностью отключить группировку для пользователей, установите `displayColumnsGrouperOnIconClick="false"` на элементе <<groupColumn>>.

NOTE: Группировку по умолчанию можно всё равно задать с помощью элемента <<groupBy>> или программно, вызвав метод `groupBy()`.

[[export-to-excel]]
== Экспорт в Excel

Функциональность экспорта предоставляется бесплатным дополнением xref:grid-export:index.adoc[], которое поддерживает все виды таблиц: `groupDataGrid`, `dataGrid` и `treeDataGrid`.

image::groupdatagrid-export.png[align="center",width="1090"]

Дополнение предоставляет три варианта экспорта. Они влияют как на охват данных, так и на формат итоговой таблицы:

* *Все строки* — экспортирует все строки, разворачивая группировку в плоский список.
* *Текущая страница* — экспортирует только видимые строки, *сохраняя структуру группировки как в таблице*.
* *Выбранные строки* — экспортирует выбранные строки, разворачивая группировку в плоский список.

=== Иконка группировки

Компонент отображает `+` для свёрнутой группы и `-` для развёрнутой. Чтобы изменить иконки, добавьте нужные значки в таблицу стилей приложения. Замените значения `content` по умолчанию на коды нужных символов (например, `e7c1` и `e7bf` из коллекции https://github.com/vaadin/web-components/blob/main/packages/icons/assets/vaadin-font-icons.json[иконок шрифта Vaadin^]):

.application.css
[source,css,indent=0]
----
vaadin-grid-tree-toggle.jmix-group-toggle {
    &::part(toggle)::before {
        content: "\e7c1";
    }

    &[expanded]::part(toggle)::before {
        content: "\e7bf";
    }
}
----

=== Иконка столбца группировки

Иконка столбца группировки настраивается через атрибут `groupIcon` элемента <<groupColumn,groupColumn>>. Чтобы скрыть иконку, установите `groupIconVisible` в значение `false`.

== Элементы

[TIP]
====
Чтобы добавить элемент в выбранный компонент, нажмите кнопку xref:studio:screen-designer.adoc#add-column[Add] в панели инспектора *Jmix UI*.
====

[[groupBy]]
=== groupBy

Элемент `groupBy` содержит один или несколько элементов <<columnRef,columnRef>>, определяющих, по каким столбцам выполняется группировка.

[[columnRef]]
=== columnRef

Элемент `columnRef` определяет столбец, используемый для группировки.

[[columns]]
=== columns

Элемент `columns` содержит отдельные элементы `column` и задаёт набор атрибутов, общих для этих столбцов.

[[column]]
=== column

Элемент `column` определяет отдельный столбец. Атрибуты, заданные для отдельного столбца, переопределяют атрибуты, заданные для `columns`.

[[groupColumn]]
=== groupColumn

Элемент `groupColumn` описывает столбец, используемый для группировки, и его относительное положение среди других столбцов. Атрибут `key` является обязательным.
