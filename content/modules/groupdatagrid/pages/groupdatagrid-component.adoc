[[Basics]]
== Basics

To get started, xref:groupdatagrid:index.adoc#installation[install the add-on] and then add the component through the *Add Component* palette in Studio xref:studio:view-designer.adoc[View Designer].

image::groupdatagrid-palette.png[align="center",width="765"]

The following example groups customers based on their respective values in the *Grade* column.

image::groupdatagrid-basic.png[align="center",width="1097"]

.XML code
[%collapsible%open]
====
[source,xml,indent=0]
----
include::example$/groupdatagrid-ex1/src/main/resources/com/company/groupdatagridex1/view/basicgroupgrid/basic-group-grid-view.xml[tags=view;data;facets;layout;customersDc;basics]
----
<1> If the component is added manually rather than through the *Add Component* palette, declare the `groupg` namespace.
<2> Initial grouping is by the `grade` property; more groupings can be added.
<3> Group column definition.
====

[[data-binding]]
== Data Binding

Data binding refers to linking a visual component to a data container. To bind a component to data use the `dataContainer` attribute and reference xref:flow-ui:data/collection-container.adoc[collection container]. See the example above.

[[group-item]]
== Group Item

Group items are special records produced by grouping. They appear as rows that contain nothing but a group header.

image::groupdatagrid-group-items.png[align="center",width="1097"]

To render group items, the data-binding layer creates a temporary, empty entity or DTO instance. This instance is not added to the xref:flow-ui:data/collection-container.adoc[collection container] and exists only in memory for the duration of the grouping.

[[hide-group-item-count]]
=== Hide Group Item Count

By default, group items display the number of descendants. Use the `displayItemCount` property of <<groupColumn,groupColumn>> to hide this number.

image::groupdatagrid-hide-count.png[align="center",width="1097"]

[[multi-level-grouping]]
== Multi-level Grouping

The component supports grouping by multiple columns. Click the grouping column icon to open the *Group by* dialog, then add or remove columns.

image::groupdatagrid-multiple.png[align="center",width="1100"]

[[disable-grouping]]
== Disable Grouping

To prevent users from grouping by a specific column, set its `groupAllowed` property to `false`. This removes the column from the  *Group by* dialog. In the example below, the *Country* column cannot be grouped:

image::groupdatagrid-groupallowed.png[align="center",width="1100"]

.XML code
[%collapsible]
====
[source,xml,indent=0]
----
include::example$/groupdatagrid-ex1/src/main/resources/com/company/groupdatagridex1/view/disablegrouping/disable-grouping-view.xml[tags=disable-grouping]
----
====

To turn off grouping entirely for users, set `displayColumnsGrouperOnIconClick="false"` on the <<groupColumn>> element.

NOTE: Default grouping can still be declared with the <<groupBy>> element or applied programmatically via the `groupBy()` method.

[[export-to-excel]]
== Export to Excel

Exporting functionality is provided by free xref:grid-export:index.adoc[] add-on which supports all grid types: `groupDataGrid`, `dataGrid`, and `treeDataGrid`.

image::groupdatagrid-export.png[align="center",width="1090"]

The add-on provides three export options. It affects both the scope and the generated spreadsheet formatting:

* *All Rows* – Exports all rows and flattens the grouping.
* *Current Page* – Exports only the visible rows while *preserving the grouping structure as seen in the grid*.
* *Selected Rows* – Exports the currently selected rows and flattens the grouping.

=== Group Icon

The component shows `+` for a collapsed group and `-` for an expanded group. To customize, add your preferred icons to the application stylesheet. Replace the default `content` values for the desired icon character codes (e.g., `e7c1` and `e7bf` taken from https://github.com/vaadin/web-components/blob/main/packages/icons/assets/vaadin-font-icons.json[vaadin font icons^] collection):

.application.css
[source,css,indent=0]
----
vaadin-grid-tree-toggle.jmix-group-toggle {
    &::part(toggle)::before {
        content: "\e7c1";
    }

    &[expanded]::part(toggle)::before {
        content: "\e7bf";
    }
}
----

=== Group Column Icon

The group column icon is customizable via the `groupIcon` attribute of the <<groupColumn,groupColumn>> element. To hide the icon, set `groupIconVisible` to `false`.

[[groupBy]]
=== groupBy

The `groupBy` element contains one or more <<columnRef,columnRef>> elements specifying which columns to group by.

[[columnRef]]
=== columnRef

The `columnRef` element identifies a column to use for grouping.

[[columns]]
=== columns

The `columns` element contains individual `column` elements and defines a set of attributes shared by those columns.

[[column]]
=== column

The `column` element declares an individual column. Attributes set for an individual `column` override those set for `columns`.

[[groupColumn]]
=== groupColumn

The `groupColumn` element declares the column used for grouping and its relative position among other columns. The `key` attribute is required.
