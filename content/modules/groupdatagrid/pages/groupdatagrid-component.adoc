[[Basics]]
== 基本用法

首先，请 xref:groupdatagrid:index.adoc#installation[安装扩展组件]，然后通过 Studio xref:studio:view-designer.adoc[视图设计器] 的 *Add Component* 工具箱添加该组件。

image::groupdatagrid-palette.png[align="center",width="765"]

下面的例子中，用户按 *Grade* 列进行了分组：

image::groupdatagrid-basic.png[align="center",width="1097"]

.XML 代码
[%collapsible%open]
====
[source,xml,indent=0]
----
include::example$/groupdatagrid-ex1/src/main/resources/com/company/groupdatagridex1/view/basicgroupgrid/basic-group-grid-view.xml[tags=view;data;facets;layout;customersDc;basics]
----
<1> 如果组件是手动添加而不是通过 *Add Component* 工具箱添加，则需要声明 `groupg` 命名空间。
<2> 表格初始化是通过 `grade` 属性分组；也可以添加更多的分组配置。
<3> 添加分组列。
====

[[data-binding]]
== 数据绑定

数据绑定是指将组件与数据容器进行关联。将组件绑定数据时，使用 `dataContainer` 属性并引用 xref:flow-ui:data/collection-container.adoc[集合数据容器]。请参考上面的示例。

[[group-item]]
== 分组项

分组项是由分组产生的特殊记录。以行的形式出现，仅包含分组表头。

image::groupdatagrid-group-items.png[align="center",width="1097"]

为了渲染分组项，数据绑定层会创建一个临时的空实体或 DTO 实例。该实例不会添加到 xref:flow-ui:data/collection-container.adoc[集合容器] 中，仅在分组时存在于内存中。

[[hide-group-item-count]]
=== 隐藏分组项计数

默认情况下，分组项显示分组内条目的数量。使用 <<groupColumn,groupColumn>> 的 `displayItemCount` 属性可以隐藏该数字。

image::groupdatagrid-hide-count.png[align="center",width="1097"]

[[multi-level-grouping]]
== 多层分组

组件支持按多列分组。点击分组列的图标可以打开 *Group by* 对话框，然后可以添加或移除列。

image::groupdatagrid-multiple.png[align="center",width="1100"]

[[disable-grouping]]
== 禁用分组

如需禁止用于基于特定列进行分组，可以设置该列的 `groupAllowed` 属性为 `false`。这样就不会在 *Group by* 对话框中显示该列。下面的示例中，不允许按 *Country* 列分组：

image::groupdatagrid-groupallowed.png[align="center",width="1100"]

.XML 代码
[%collapsible]
====
[source,xml,indent=0]
----
include::example$/groupdatagrid-ex1/src/main/resources/com/company/groupdatagridex1/view/disablegrouping/disable-grouping-view.xml[tags=disable-grouping]
----
====

如需禁止终端用户使用分组功能，设置 <<groupColumn>> 元素的 `displayColumnsGrouperOnIconClick="false"`。

NOTE: 默认的分组仍然可以通过 <<groupBy>> 元素声明或 `groupBy()` 方法编程式设置。

[[export-to-excel]]
== 导出 Excel

导出功能由免费的 xref:grid-export:index.adoc[] 扩展组件提供，该扩展组件支持所有表格类型：`groupDataGrid`、`dataGrid` 和 `treeDataGrid`。

image::groupdatagrid-export.png[align="center",width="1090"]

该扩展组件提供三种导出选项。有不同的导出范围以及生成 Excel 的格式：

* *All Rows* – 导出所有行并展平分组。
* *Current Page* – 仅导出当前可见行，同时 *保留表格中显示的分组结构*。
* *Selected Rows* – 导出当前选中的行并展平分组。

    &::part(toggle)::before {
        content: "\e7c1";
    }

    &[expanded]::part(toggle)::before {
        content: "\e7bf";
    }
}
----

== XML 内部元素

[TIP]
====
如需为选中的元素添加内部元素，点击 *Jmix UI* 属性面板中的 xref:studio:screen-designer.adoc#add-column[Add] 按钮。

[[groupBy]]
=== groupBy

`groupBy` 元素包含一个或多个 <<columnRef,columnRef>> 元素，指定哪些列用于分组。

[[columnRef]]
=== columnRef

`columnRef` 元素定义用作分组的列。

[[columns]]
=== columns

`columns` 元素包含 `column` 元素，并且定义这些列的共享属性。

[[column]]
=== column

`column` 元素声明单独的一列。为单独的列设置属性会覆盖 `columns` 上的设置。

[[groupColumn]]
=== groupColumn

`groupColumn` 元素声明用于分组的列，以及该列相对于其他列的位置。`key` 属性为必需。
