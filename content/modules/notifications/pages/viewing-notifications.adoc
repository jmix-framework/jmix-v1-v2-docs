= Просмотр уведомлений

Чтобы отображать уведомления, отправленные через встроенный канал, добавьте UI-компонент `notificationsIndicator` на экран приложения, как описано в разделе xref:configuration.adoc#in-app-channel[Настройка].

Когда пользователь нажимает на индикатор, открывается диалоговое окно уведомлений:

image::ntf-programmatic.png[align="center" width="1270"]

Дважды щелкните по уведомлению, чтобы открыть его:

image::ntf-read.png[align="center", width="1270"]

Когда пользователь нажимает *OK*, окно уведомления закрывается, и уведомление помечается как прочитанное.
