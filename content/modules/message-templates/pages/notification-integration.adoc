= 集成通知消息

消息模板扩展组件可以无缝地与 xref:notifications:index.adoc[通知消息] 组件集成，通知消息组件包含在企业版订阅中。集成后可以使用预定义的消息模板发送通知。

如果项目中包含了这两个扩展组件，`CreateNotificationDialog` 界面的功能会升级，提供一个选择预定义消息模板的功能。

image::notification-dialog.png[align="center", width="926"]

在选择模板后，会弹出一个对话框，要求输入该模板所需的必要参数。这个对话框是根据模板中定义的 xref:message-templates.adoc#parameters[参数] 动态生成的，以确保提供的信息与所选的模板相关。

image::notification-params.png[align="center", width="927"]

在对话框中，可以根据需要修改参数值。例如可以输入特定的日期、验证码或者是个人的问候语等。可以输入的参数和其类型由模板设计时确定。

查看并确认参数后，就可以继续发送通知了。然后，消息模板扩展组件将使用选定的模板和输入的参数值来生成完整的，随时可发送的消息。这个过程中会将模板中的占位符变量替换为提供的变量值。

最后，通知消息扩展组件将处理该消息，发送给所需的用户。
