= 模板块

扩展组件提供了创建自定义块的功能，这些块可以使得模板的设计和构造更加灵活有效。如需创建自定义块，打开 *Message Templates → Template blocks* 然后点击 *Create* 按钮。

[[block-designer]]
== 模板块设计器

创建新的块时，会显示 *Template block* 视图。该视图支持：

* 拖拽预定义的 HTML 元素至画布。
* 通过调整元素的属性对元素进行自定义，例如大小、颜色、对齐方式等。
* 根据需要排布和组织元素创建可重用的块。

*Attributes* tab 中可以设置块的属性 `attributes`。在 GrapesJS 中，`attributes` 是与块关联的键值对。本质上，属性是一种在设计时存储和管理元素或块的附加数据的方法。除了基本的属性，比如内容、样式或位置之外，通过这些属性还可以自定义和配置组件的行为和外观。

[[using-custom-blocks]]
== 使用自定义块

自定义块创建完成后，可以在 xref:message-templates.adoc[消息模板] 视图中使用。可以很容易在模板中插入这些块，能节省时间并保证多个模板中相同元素的一致性。
