= Административный интерфейс отчетов
:page-aliases: report-view.adoc

Дополнение Reports предоставляет административные экраны для настройки и запуска отчетов.

[[reports-view]]
== Экран отчетов

Откройте пункт меню *Reports -> Reports*. Экран списка *Reports* отображает список доступных отчетов и содержит кнопки для управления ими.

image::report-list-view.png[align="center", width="1074"]

* Существует два способа создания отчетов во время выполнения: с помощью мастера отчетов или экрана деталей отчета.

** Нажмите на всплывающую кнопку *Create -> New*, чтобы создать отчет вручную. Откроется xref:creation/details.adoc[экран деталей отчета].

** Чтобы открыть xref:getting-started.adoc#creating-report-at-runtime[мастер отчетов], нажмите на всплывающую кнопку *Create -> Using wizard*.

* Нажмите кнопку *Copy*, чтобы быстро создать новый отчет на основе выбранного. Новый отчет будет иметь ту же структуру, параметры и шаблоны.

[[export-import]]
* Дополнение предоставляет возможность экспорта и импорта отчетов.

** Выберите отчеты, которые хотите экспортировать, и нажмите кнопку *Export* (image:download.png[width="18"]). Фреймворк создает ZIP-архив, содержащий все выбранные отчеты.

** Чтобы импортировать отчеты, нажмите кнопку *Import* (image:upload.png[width="18"]). Откроется диалоговое окно *Import report*:
+
image::import-report-dialog.png[align="center", width="482"]
+
Нажмите *Upload File*, чтобы выбрать ZIP-файл для загрузки в систему. Это также можно сделать, перетащив нужный файл в область загрузки. Если снять флажок *Import roles*, импортированные отчеты будут xref:creation/permissions.adoc[доступны всем пользователям].
+
Если отчет совместим с моделью данных проекта, он должен корректно работать после импорта. Это означает, что вы можете создавать отчеты в среде разработки и затем использовать их в рабочей системе.
+
TIP: Вы также можете импортировать отчеты _программно_, используя бин xref:report-import-export.adoc#report-import-export[ReportImportExport], предоставляемый фреймворком.

* Нажмите кнопку *Run*, чтобы выполнить выбранный отчет.

* Кнопка *Execution history* открывает xref:exec-history.adoc[экран истории выполнения].

[[report-groups-view]]
== Экран групп отчетов

Экран *Reports -> Report groups* позволяет пользователям создавать группы, которые упрощают управление отчетами. Группы отчетов - это просто категории с произвольными именами, которые не влияют на доступность или выполнение отчетов.

[[run-report-view]]
== Экран запуска отчета

Экран *Reports -> Run report* позволяет пользователям найти отчет и запустить его.

Этот экран показывает только отчеты, доступные пользователю в соответствии с xref:creation/permissions.adoc[правами доступа].
