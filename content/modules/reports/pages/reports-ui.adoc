= 报表管理 UI
:page-aliases: report-view.adoc

报表扩展组件提供了用于配置和运行报表的管理视图。

[[reports-view]]
== 报表视图

打开主菜单的 *Reports -> Reports*。*Reports* 列表视图显示可用的报表，并带有管理这些报表的按钮。

image::report-list-view.png[align="center", width="1074"]

* 有两种在运行时创建报表的方式：使用报表向导或使用报表详情视图。

** 点击 *Create -> New* 手动创建报表。将打开 xref:creation/details.adoc[报表详情视图]。

** 点击 *Create -> Using wizard* 则打开 xref:getting-started.adoc#creating-report-at-runtime[报表向导]。

* 点击 *Copy* 按钮，基于所选报表快速创建新报表。新报表将具有相同的结构、参数和模板。

[[export-import]]
* 扩展组件还提供导出和导入报表的功能。

** 选择要导出的报表，然后点击 *Export* (image:download.png[width="18"]) 按钮。框架会创建一个包含所有选定报表的 ZIP 压缩包。

** 导入报表时，点击 *Import* (image:upload.png[width="18"]) 按钮。将打开 *Import report* 对话框：
+
image::import-report-dialog.png[align="center", width="482"]
+
点击 *Upload File* 选择要上传至系统的 ZIP 文件。也可以将文件拖放到拖拽区域完成导入。如果不勾选 *Import roles*，导入的报表将 xref:creation/permissions.adoc[对所有用户可用]。
+
如果报表与项目的数据模型兼容，导入后应能正常工作。也就是说，可以在开发环境中创建报表，然后在生产系统中使用。
+
TIP: 还可以使用框架提供的 xref:report-import-export.adoc#report-import-export[ReportImportExport] bean _以编程方式_ 导入报表。

* 点击 *Run* 按钮执行选中的报表。

* *Execution history* 按钮打开 xref:exec-history.adoc[执行历史视图]。

[[report-groups-view]]
== 报表分组视图

*Reports -> Report groups* 视图支持用户创建分组，有助于管理报表。报表分组只是任意名称的类别，不影响报表的可用性或执行。

[[run-report-view]]
== 运行报表视图

在 *Reports -> Run report* 视图中，用户可以查找报表并运行。

该视图根据 xref:creation/permissions.adoc[访问权限] 仅显示当前用户可用的报表。
