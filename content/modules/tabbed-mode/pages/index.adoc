= Tabbed Application Mode

This add-on allows you to open views in separate tabs within the main view, allowing users to simultaneously access multiple views in a single browser tab and switch between them easily. It also supports opening multiple views within the same main view tab, creating a view stack represented by breadcrumbs.

[[installation]]
== Installation

[NOTE]
====
This add-on requires the Enterprise https://www.jmix.io/subscription-plans-and-prices/[subscription^]. If you don't have the subscription, see the xref:ROOT:account-management.adoc#enterprise-trial[Enterprise Trial] section for how to get a trial version.
====

For automatic installation, use a dedicated project template:

image::project-template.png[align="center",width="912"]

For manual installation:

. Make sure the premium repository is defined in `build.gradle`:
+
[source,groovy]
----
repositories {
    // ...
    maven {
        url = 'https://global.repo.jmix.io/repository/premium'
        credentials {
            username = rootProject['premiumRepoUser']
            password = rootProject['premiumRepoPass']
        }
    }
----

. Add the following dependency to your `build.gradle`:
+
[source,groovy,indent=0]
----
implementation 'io.jmix.tabbedmode:jmix-tabbedmode-flowui-starter'
----

. Change the base class of `MainView.java` from `StandardMainView` to `StandardTabbedModeMainView`.
+
[source,java,indent=0]
----
include::example$/tabbedmode-ex1/src/main/java/com/company/demo/view/main/MainView.java[tags=baseClass;!notifications;!tabsCollectionChangeEvent;!selectedChangeEvent]
----

. In the `main-view.xml`, change the `xmlns` attribute value of the `mainView` element to use the XSD schema from the add-on:
+
[source,xml,indent=0]
----
include::example$/tabbedmode-ex1/src/main/resources/com/company/demo/view/main/main-view.xml[tags=mainView]
----
+
Then replace `initialLayout` with the following `workArea` definition:
+
[source,xml,indent=0]
----
include::example$/tabbedmode-ex1/src/main/resources/com/company/demo/view/main/main-view.xml[tags=workArea]
----
