= Tabbed Application Mode

Дополнение позволяет открывать экраны в отдельных вкладках внутри главного экрана. Благодаря этому пользователи могут одновременно работать с несколькими экранами в одной вкладке браузера и быстро переключаться между ними. Экраны можно открывать последовательно в одной вкладке. В этом случае они образуют стек с навигацией в виде хлебных крошек.

== Установка

[NOTE]
====
Для этого дополнения требуется  https://www.jmix.ru/subscription-plans-and-prices/[Enterprise подписка^]. Если у вас нет подписки, ознакомьтесь с разделом xref:ROOT:account-management.adoc#enterprise-trial[Пробная Enterprise+BPM подписка], чтобы получить пробную версию.
====

Для новых проектов используйте специальный шаблон проекта:

image::project-template.png[align="center",width="912"]

Чтобы перевести существующий проект в режим вкладок, выполните следующие шаги.

. Убедитесь, что премиум-репозиторий определен в `build.gradle`:
+
[source,groovy]
----
repositories {
    // ...
    maven {
        url = 'https://nexus.jmix.io/repository/premium'
        credentials {
            username = rootProject['premiumRepoUser']
            password = rootProject['premiumRepoPass']
        }
    }
----

. Добавьте следующую зависимость в ваш `build.gradle`:
+
[source,groovy,indent=0]
----
implementation 'io.jmix.tabbedmode:jmix-tabbedmode-flowui-starter'
----

. Измените базовый класс `MainView.java` с `StandardMainView` на `StandardTabbedModeMainView`.
+
[source,java,indent=0]
----
include::example$/tabbedmode-ex1/src/main/java/com/company/demo/view/main/MainView.java[tags=baseClass;!notifications;!tabsCollectionChangeEvent;!selectedChangeEvent]
----

. В файле `main-view.xml` измените значение атрибута `xmlns` элемента `mainView`, чтобы использовать XSD-схему дополнения:
+
[source,xml,indent=0]
----
include::example$/tabbedmode-ex1/src/main/resources/com/company/demo/view/main/main-view.xml[tags=mainView]
----
+
Затем замените `initialLayout` следующим определением `workArea`:
+
[source,xml,indent=0]
----
include::example$/tabbedmode-ex1/src/main/resources/com/company/demo/view/main/main-view.xml[tags=workArea]
----
