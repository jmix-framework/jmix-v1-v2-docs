[[actions]]
== Действия

Компонент `mainTabSheet` реализует интерфейс `HasActions` и может содержать как стандартные, так и пользовательские действия. Действия вызываются из контекстного меню, которое появляется по щелчку правой кнопкой мыши на области вкладок.

image::main-tab-sheet/tabsheet-context-menu.png[align="center", width="500"]

Стандартными действиями являются следующие:

[[tabmod_closeThisTab]]
=== tabmod_closeThisTab

Класс действия: `CloseThisTabAction`

Закрывает выбранную вкладку.

[[tabmod_closeOtherTabs]]
=== tabmod_closeOtherTabs

Класс действия: `CloseOtherTabsAction`

Закрывает все открытые вкладки в `mainTabSheet`, кроме выбранной.

[[tabmod_closeAllTabs]]
=== tabmod_closeAllTabs

Класс действия: `CloseAllTabsAction`

Закрывает все открытые вкладки в `mainTabSheet`.

[[drag-and-drop]]
== Drag and drop

`mainTabSheet` поддерживает перетаскивание вкладок. Эта возможность может использоваться, например, для изменения порядка вкладок.

Изменяя значение атрибута `tabsDraggable`, вы можете разрешить или запретить пользователю перетаскивать вкладки. Значение по умолчанию — `false`.

image::main-tab-sheet/tabs-reordering.gif[align="center"]
