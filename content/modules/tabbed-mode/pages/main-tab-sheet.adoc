[[actions]]
== Actions

The `mainTabSheet` component implements the `HasActions` interface and can contain both standard xref:tabbed-mode:actions.adoc[MainTabSheet actions] and custom actions. Actions are invoked from the context menu that appears on the right click on the tabs area.

image::main-tab-sheet/tabsheet-context-menu.png[align="center", width="500"]

[[drag-and-drop]]
== Drag and Drop

`mainTabSheet` supports dragging and dropping tabs. This feature can be used, for example, to rearrange tabs.

By changing the `tabsDraggable` attribute value, you can set whether the tabs are draggable by the user. Default value is `false`.

image::main-tab-sheet/tabs-reordering.gif[align="center"]

[[theme-variants]]
== Theme Variants

.`centered`
[%collapsible]
====
Positions the tabs at the center of the main view, instead of their default left-aligned position:

image::main-tab-sheet/tabs-centered.png[align="center", width=700]
====

.`small`
[%collapsible]
====
Makes the tabs smaller:

image:main-tab-sheet/tabs-small.png[align="center", width=500]
====

.`minimal`
[%collapsible]
====
Reduces visual style to only show tab labels without any additional visual elements:

image:main-tab-sheet/tabs-minimal.png[align="center", width=500]
====

.`hide-scroll-buttons`
[%collapsible]
====
Hides the scroll buttons that assist in navigating overflown tabs:

image:main-tab-sheet/tabs-hide-scroll-buttons.png[align="center", width=376]

====

.`bordered`
[%collapsible]
====
Adds a border around the tabs themselves, as well as the content area.

image:main-tab-sheet/tabsheet-bordered.png[align="center", width=832]
====
