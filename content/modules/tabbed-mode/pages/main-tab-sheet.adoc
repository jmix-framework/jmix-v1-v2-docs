[[actions]]
== 操作

`mainTabSheet` 组件实现了 `HasActions` 接口，因此可以包含标准和自定义的操作。操作通过标签页的右键菜单调用。

image::main-tab-sheet/tabsheet-context-menu.png[align="center", width="500"]

标准操作包含：

[[tabmod_closeThisTab]]
=== tabmod_closeThisTab

操作类：`CloseThisTabAction`

关闭所选的标签页。

[[tabmod_closeOtherTabs]]
=== tabmod_closeOtherTabs

操作类：`CloseOtherTabsAction`

保留所选的标签页，关闭其他标签页。

[[tabmod_closeAllTabs]]
=== tabmod_closeAllTabs

操作类：`CloseAllTabsAction`

关闭所有打开的标签页。

[[drag-and-drop]]
== 拖拽

`mainTabSheet` 还支持标签页的拖拽。这个功能可以用来对标签页进行排序。

该功能通过 `tabsDraggable` 属性启用。默认值为 `false`。

image::main-tab-sheet/tabs-reordering.gif[align="center"]

== 主题样式

.`centered`
[%collapsible]
====
将标签页放置在主视图的中间位置，而不是默认的靠左排列：

image::main-tab-sheet/tabs-centered.png[align="center", width=700]
====

.`small`
[%collapsible]
====
使用小的标签页：

image:main-tab-sheet/tabs-small.png[align="center", width=500]
====

.`minimal`
[%collapsible]
====
减少可视化样式，仅显示标签页的文本，不带任何可视化元素：

image:main-tab-sheet/tabs-minimal.png[align="center", width=500]
====

.`hide-scroll-buttons`
[%collapsible]
====
隐藏标签的滚动按钮：

image:main-tab-sheet/tabs-hide-scroll-buttons.png[align="center", width=376]

====

.`bordered`
[%collapsible]
====
为标签和内容区域添加边框。

image:main-tab-sheet/tabsheet-bordered.png[align="center", width=832]
====
