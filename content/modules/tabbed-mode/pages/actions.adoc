= MainTabSheet Actions

This section describes the default actions available for the `mainTabSheet` component.

When an action is added to a `mainTabSheet`, it can be invoked from the component’s context menu.

[[tabmod_closeThisTab]]
== tabmod_closeThisTab

Action class: `CloseThisTabAction`

Closes the selected (trigger) tab.

[[tabmod_closeOtherTabs]]
== tabmod_closeOtherTabs

Action class: `CloseOtherTabsAction`

Closes all currently open tabs in the `mainTabSheet` except the selected (trigger) tab.

[[tabmod_closeAllTabs]]
== tabmod_closeAllTabs

Action class: `CloseAllTabsAction`

Closes all currently open tabs in the `mainTabSheet`.
