= Редактирование геометрий геообъектов на карте

Дополнение Maps позволяет пользователям визуально редактировать геометрии геообъектов. Вместо редактирования данных геометрии в виде текста в поле, пользователи теперь могут взаимодействовать с геометриями непосредственно на карте. Этот интуитивный интерфейс позволяет пользователям перемещать геометрии, изменять линии и выполнять другие правки визуально, упрощая процесс управления геоданными.

И xref:maps:layers-sources.adoc#vector-source[VectorSource], и xref:maps:layers-sources.adoc#data-vector-source[DataVectorSource] поддерживают три режима редактирования сущностей:

* *Режим выбора*: позволяет пользователям выбирать сущности на карте.
* *Режим перетаскивания*: позволяет пользователям перетаскивать сущности в новые места на карте.
* *Режим изменения*: позволяет пользователям изменять геометрию сущностей, например, вершины и линии.

[[select-mode]]
== Режим выбора

Чтобы включить выбор сущностей, установите атрибут `featureSelectEnabled` для xref:layers-sources.adoc#vector-source[векторного источника] в значение `true`.

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/select-mode-view.xml[tags=select-mode1]
----

Когда режим включен, пользователи могут выбирать сущности на карте, нажимая на них. Для множественного выбора пользователи могут использовать комбинацию `Shift` + щелчок.

image::layers-select-example.gif[width="780"]

NOTE: Когда режим выбора используется вместе с режимами перетаскивания или изменения, только выбранные сущности можно перетаскивать или изменять.

Режим выбора предоставляет событие выбора для обработки выделения и снятия выделения с сущностей. Для получения более подробной информации смотрите раздел xref:maps:events.adoc#source-events[События источника].

Вы также можете стилизовать выбранные сущности, чтобы визуально их выделить. Для получения дополнительной информации обратитесь к разделу xref:maps:style.adoc#select-mode-styles[Стили режима выбора].

[[drag-mode]]
== Режим перетаскивания

Чтобы включить перетаскивание сущностей, установите атрибут `featureDragEnabled` для xref:layers-sources.adoc#vector-source[векторного источника] в значение `true`. Это активирует кнопку управления image:layers-drag-icon.png[width="24"] на карте, которая включает режим перетаскивания.

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/drag-mode-view.xml[tags=drag-mode1]
----

Например, вот как выглядит режим перетаскивания, когда он включен:

image::layers-drag-example.gif[width="445"]

Этот режим предоставляет события для обработки начала и окончания перетаскивания; для получения более подробной информации смотрите раздел xref:maps:events.adoc#source-events[События источника].

[[modify-mode]]
== Режим изменения

Чтобы включить изменение сущностей, установите атрибут `featureModifyEnabled` для xref:layers-sources.adoc#vector-source[векторного источника] в значение `true`.

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/modify-mode-view.xml[tags=modify-mode1]
----

Это активирует кнопки управления на карте:

* image:layers-modify-icon.png[width="24"] - активирует режим изменения. В этом режиме отображается вершина, которую можно перетащить для изменения сущности или нажать для ее удаления.
* image:layers-delete-icon.png[width="24"] - активирует режим удаления. Когда этот режим активен, пользователи могут нажать на сущность, и перед удалением появится диалоговое окно подтверждения.

Например, вот как выглядит режим изменения, когда он включен:

image::layers-modify-example.gif[width="545"]

Этот режим предоставляет события для обработки начала и окончания изменений. Кроме того, xref:layers-sources.adoc#vector-source[векторный источник] имеет событие удаления. Для получения дополнительной информации смотрите раздел xref:maps:events.adoc#source-events[События источника].

Вы также можете стилизовать сгенерированные точки вершин. Для получения более подробной информации смотрите раздел xref:maps:style.adoc#modify-mode-styles[Стили режима изменения].
