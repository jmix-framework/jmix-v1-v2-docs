= Стиль

Объект `Style` позволяет разработчикам настраивать цвет, размер, шрифт и другие визуальные свойства xref:maps:features-geometries.adoc[объектов] карты.

Стили также могут применяться на уровне xref:maps:layers-sources.adoc[слоя], определяя единообразный внешний вид для всех объектов внутри слоя.

Чтобы изменить стиль для xref:maps:features-geometries.adoc#point-feature[PointFeature], обычно определяют объект `PointStyle` с нужными свойствами внешнего вида, такими как `image`, `fill`, `stroke` и т.д., и затем применяют этот стиль к `PointFeature`.

== Стили режима выбора

Каждый тип объекта в векторном источнике имеет стили по умолчанию для xref:editing-geometries.adoc#select-mode[режима выбора]. [[modify-mode-styles]]
== Стили режима изменения

Векторные источники предоставляют xref:editing-geometries.adoc#modify-mode[режим изменения]. При активации этот режим генерирует точки в вершинах геометрии, позволяя выполнять такие изменения, как добавление новых вершин и изменение позиций существующих вершин. Этот режим также определяет стили для этих сгенерированных вершин, которые отображаются на карте для представления геометрии.
