= 样式

使用 `Style` 对象可以自定义地图 xref:maps:features-geometries.adoc[要素] 的颜色、大小、字体和其他可视化属性。

样式也可以在 xref:maps:layers-sources.adoc[图层] 级别应用，从而为图层中的所有要素定义一致的外观。

[[styling-point-features]]
== 点要素的样式

xref:maps:features-geometries.adoc#point-feature[PointFeature] 的外观可以通过定义一个 `PointStyle` 对象进行自定义，例如 `image`、`fill`、`stroke` 和 `text`，然后将该样式应用于 `PointFeature`。
