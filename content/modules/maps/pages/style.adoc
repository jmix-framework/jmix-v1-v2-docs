= Style

The `Style` object enable developers to customize the color, size, font, and other visual properties of map xref:maps:features-geometries.adoc[features].

Styles can also be applied at the xref:maps:layers-sources.adoc[layer] level, defining a consistent appearance for all features within a layer.

== Modify Mode Styles

Vector sources provide the xref:editing-geometries.adoc#modify-mode[modify mode]. When activated, this mode generates points at the geometry's vertices, allowing for modifications such as adding new vertices and changing existing vertex positions. This mode also defines the styles for these generated vertices, which are displayed on the map to represent the geometry.
