= Компонент карты

UI-компонент `GeoMap` отображает географические данные, предоставляемые xref:maps:layers-sources.adoc[слоями].

Карта строится путем наложения слоев. Изначально карта не имеет слоев.

Вы можете определить общие параметры карты вместе со слоями в XML-дескрипторе экрана.

[[map]]
== Карта

Чтобы добавить компонент на экран, используйте Jmix Studio.

Нажмите *Add Component* на панели действий, найдите элемент `GeoMap` и дважды щелкните по нему.

image::adding-map.png[align="center", width="1136"]

Новый элемент `geoMap` будет добавлен как на панели структуры *Jmix UI*, так и в XML. Вы можете настраивать атрибуты, такие как xref:flow-ui:vc/common-attributes.adoc#id[id], xref:flow-ui:vc/common-attributes.adoc#height[height], xref:flow-ui:vc/common-attributes.adoc#width[width] и т.д., так же, как это делается для других xref:flow-ui:vc/components.adoc[UI-компонентов].

[source,xml,indent=0]
----
<maps:geoMap id="map"
             height="100%"
             width="100%"/>
----

Если вы не используете дизайнер экранов, объявите пространство имен `maps` в XML-дескрипторе вашего экрана вручную:

----

----

[[layer]]
== Слой

Компонент `GeoMap` может включать несколько xref:maps:layers-sources.adoc[слоев], которые отображают различные типы географической информации, такие как растровые слои и векторные слои.

Изначально карта не имеет слоев.

Например, давайте добавим xref:maps:layers-sources.adoc#tile-layer[TileLayer] на карту.

Выберите элемент `geoMap` на панели структуры *Jmix UI* или в XML-дескрипторе экрана, затем нажмите кнопку *Add* на панели инспектора. В выпадающем списке выберите *Layers -> TileLayer*.

== Источник

xref:maps:layers-sources.adoc[Источник] представляет данные, которые используются для отрисовки слоев карты на компоненте карты. Источники предоставляют пространственную информацию, которая определяет содержимое и внешний вид слоев карты.

Например, давайте добавим xref:maps:layers-sources.adoc#osm-source[OsmSource] для тайлового слоя.

Выберите `maps:tile` на панели структуры *Jmix UI* или в XML-дескрипторе экрана, а затем нажмите кнопку *Add* на панели инспектора. В выпадающем списке выберите *OsmSource*.

[[view]]
== Отображение

https://openlayers.org/en/v8.2.0/apidoc/module-ol_View-View.html[Отображение (View)^] определяет, как карта отображается с точки зрения ее центра, уровня масштабирования, поворота и проекции. По сути, отображение задает начальное состояние карты при ее загрузке в пользовательском интерфейсе.

По умолчанию компонент `geoMap` отображает карту мира с начальным географическим центром в `(0,0)`.

Выберите `geoMap` на панели структуры *Jmix UI* или в XML-дескрипторе экрана, а затем нажмите кнопку *Add* на панели инспектора. В выпадающем списке выберите *MapView*.

image::add-map-view.png[align="center", width="372"]

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/mapbasic/map-basic-view.xml[tags=mapView]
----

Вы можете указать дополнительные параметры:

* `centerX` определяет широту начального географического центра карты. Передается в объект `org.locationtech.jts.geom.Coordinate`.
* `centerY` определяет долготу начального географического центра карты. Передается в объект `org.locationtech.jts.geom.Coordinate`.
* `maxZoom` - устанавливает максимальный уровень масштабирования для отображения.
//The default value is 28. For more details see https://openlayers.org/en/v8.1.0/apidoc/module-ol_View-View.html#setMaxZoom[setMaxZoom^].
* `minZoom` - устанавливает минимальный уровень масштабирования для отображения.
//The default value is 0. For more details see https://openlayers.org/en/v8.1.0/apidoc/module-ol_View-View.html#setMinZoom[setMinZoom^].
* `projection` определяет систему координат (CRS), используемую для отображения географических данных на карте. Она преобразует трехмерные координаты Земли в двухмерную плоскость. Распространенные проекции включают `EPSG:3857` (Web Mercator) и `EPSG:4326` (WGS 84). Проекция по умолчанию - https://epsg.io/3857[EPSG:3857^]. Вы можете задать пользовательскую проекцию:

* `rotation` - устанавливает поворот для отображения в радианах (положительный поворот по часовой стрелке, 0 означает Север). Подробнее смотрите https://openlayers.org/en/v8.2.0/apidoc/module-ol_View-View.html#setRotation[setRotation^].
* `zoom` определяет конкретный уровень масштабирования. Уровень масштабирования начинается с 0, представляя вид с максимальным отдалением, и постепенно увеличивается по мере приближения.

[[extent]]
== Экстент

https://openlayers.org/en/v8.2.0/apidoc/module-ol_extent.html#~Extent[Экстент (extent)^] задает географические границы <<view,отображения>> карты или конкретного <<layer,слоя>> в терминах координат, определяя видимую область на карте.

Экстент обычно определяется минимальными (левый верхний угол) и максимальными (правый нижний угол) значениями координат в форме [`minX`, `minY`, `maxX`, `maxY`], представляя ограничивающую рамку области.

Выберите слой или элемент `mapView` на панели структуры *Jmix UI* или в XML-дескрипторе экрана, а затем нажмите кнопку *Add* на панели инспектора. В выпадающем списке выберите *Extent* и настройте атрибуты `minX`, `minY`, `maxX` и `maxY`, как указано ниже.
