Дополнение Maps предоставляет компонент `GeoMap` и функциональные возможности, которые позволяют разработчикам интегрировать интерактивные карты и геопространственные функции в свои веб-приложения.

image::overview-map.png[align="center", width="598"]

[[overview]]
== Обзор

Дополнение помогает вам обогатить ваше приложение визуальным представлением и интуитивно понятным управлением пространственными данными. Вы можете использовать предпочтительного поставщика карт, который соответствует вашим потребностям.

Дополнение основано на JavaScript-библиотеке https://openlayers.org/[OpenLayers^] (версия 8.2.0). По умолчанию все API работают с CRS - https://epsg.io/4326[EPSG:4326^].

Компонент интегрирует пространственные типы (точка, полилиния, полигон) из https://locationtech.github.io/jts/[JTS Topology Suite^] (JTS) - самой популярной Java-библиотеки для работы с пространственными данными.

Дополнение Maps поддерживает традиционную многослойную структуру, обычно используемую в профессиональных ГИС-системах. Слои представлены как структурные единицы карт.

[[features]]
== Возможности

Ознакомьтесь с этими разделами, чтобы узнать об основных функциях дополнения Maps:

* xref:maps:layers-sources.adoc[Слои]. Дополнение поддерживает следующие типы слоев:
** xref:maps:layers-sources.adoc#tile-layer[Тайловый слой]
** xref:maps:layers-sources.adoc#image-layer[Растровый слой]
** xref:maps:layers-sources.adoc#vector-layer[Векторный слой]
+
Эти слои представлены как структурные единицы карт.
* xref:maps:features-geometries.adoc#marker-feature[Маркеры] - это элементы карты для визуального представления конкретного местоположения или точки.
* xref:maps:map-component.adoc#view[Отображение карты]. Дополнение Maps позволяет настраивать отображение карты, включая координаты центра, уровень масштабирования, угол поворота и определение проекции.
* xref:maps:events.adoc[События]. Карты генерируют события, на которые разработчики могут подписываться, что позволяет настраивать поведение карты на основе пользовательских взаимодействий, таких как события клика по карте или события клика по объекту.
* xref:maps:style.adoc[Стили]. Дополнение Maps предоставляет возможность настраивать значки маркеров и создавать новые стили для различных объектов карты, таких как полигоны, точки и т.д.

== Установка

[NOTE]
====
Для этого дополнения требуется Enterprise https://www.jmix.ru/subscription-plans-and-prices/[подписка^]. Если у вас нет подписки, ознакомьтесь с разделом xref:ROOT:account-management.adoc#enterprise-trial[Пробная Enterprise+BPM подписка], чтобы получить пробную версию.
====

Для автоматической установки через Jmix Marketplace следуйте инструкциям в разделе xref:ROOT:add-ons.adoc#installation[Дополнения].

Для ручной установки выполните следующие шаги.

. Настройте доступ к премиум-репозиторию.
+
include::ROOT:partial$premium-repo.adoc[]

. Добавьте зависимости в ваш `build.gradle`:
+
[source,groovy,indent=0]
----
implementation 'io.jmix.maps:jmix-maps-starter'
implementation 'io.jmix.maps:jmix-maps-flowui-starter'
----
