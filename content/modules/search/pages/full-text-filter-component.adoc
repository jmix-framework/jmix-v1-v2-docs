[[basic]]
== 基本用法

使用 Studio 将该组件添加至视图。

在操作面板点击 *Add Component*，找到 `Full-text filter` 并双击。

image::create-full-text-filter-component.png[align="center", width="690"]

由于 <<dataLoader,dataLoader>> 是必需属性。Studio 会电视一个对话框用于选择数据加载器。选择所需的数据加载器并点击 *OK*。

会在 *Jmix UI* 结构面板和 XML 中添加 `fullTextFilter`。与其他 xref:flow-ui:vc/components.adoc[UI 组件] 一样，可以配置标准属性（xref:flow-ui:vc/common-attributes.adoc#id[id]、xref:flow-ui:vc/common-attributes.adoc#height[height]、xref:flow-ui:vc/common-attributes.adoc#width[width] 等）。

[source,xml,indent=0]
----
include::example$/search-ex1/src/main/resources/com/company/demo/view/search/filter-view.xml[tags=data;layout;fullTextFilter;dataGrid]
----

如果不使用视图设计器，可以手动在视图 XML 中声明 `search` 命名空间：

[source,xml,indent=0]
----
include::example$/search-ex1/src/main/resources/com/company/demo/view/search/search-view.xml[tags=xmlns]
----

`FullTextFilter` 组件的操作方式如下：

. 执行全文搜索以查找与搜索条件匹配的实体标识符。

. 将包含这些标识符的条件附加到关联的 `dataLoader` 上。

. 当 `DataGrid`（或其他列表组件）与此数据加载器关联时，仅显示与全文搜索条件匹配的那些记录。

全文条件还可以与数据加载器的其他过滤器结合使用，提供更精细的结果集。

[[attributes]]
== XML 属性

xref:flow-ui:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `fullTextFilter` 的特殊属性：

[cols="1h,7a,1",grid=rows,frame=none]
|===
|*名称*|*描述*|*默认值*

|[[autoApply]]autoApply
| 设置为 `true` 时，`FullTextFilter` 组件在值变化时自动应用到关联的 `DataLoader`。
|-
|[[dataLoader]]dataLoader
| `dataLoader` 是一个 _必需_ 属性。设置当前 `fullTextFilter` 关联的 xref:flow-ui:data/data-loaders.adoc[数据加载器]。
|-

|[[searchStrategy]]searchStrategy
|设置搜索策略。参阅 xref:search:search-in-ui.adoc#search-strategies[搜索策略]。
|`anyTermAnyField`

|===
