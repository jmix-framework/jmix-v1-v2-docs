[[basic]]
== Basics

To add the component on the view, use Jmix Studio.

Click *Add Component* in the actions panel, then find the `Full-text filter` item and double-click it.

image::create-full-text-filter-component.png[align="center", width="690"]

Since the <<dataLoader,dataLoader>> attribute is required, Studio will display a dialog to select a data loader. Choose the appropriate data loader and click *OK*.

The new `fullTextFilter` element will be added both in the *Jmix UI* structure panel and in the XML descriptor. You can configure standard attributes (xref:flow-ui:vc/common-attributes.adoc#id[id], xref:flow-ui:vc/common-attributes.adoc#height[height], xref:flow-ui:vc/common-attributes.adoc#width[width], etc.) just like any other xref:flow-ui:vc/components.adoc[UI component].

[source,xml,indent=0]
----
include::example$/search-ex1/src/main/resources/com/company/demo/view/search/filter-view.xml[tags=data;layout;fullTextFilter;dataGrid]
----

If you don't use the view designer, declare the `search` namespace in your view's XML descriptor manually:

[source,xml,indent=0]
----
include::example$/search-ex1/src/main/resources/com/company/demo/view/search/search-view.xml[tags=xmlns]
----

The `FullTextFilter` component operates as follows:

. Performs a full-text search to find entity identifiers matching the search criteria.

. Appends a condition containing these identifiers to the associated `dataLoader`.

. When a `DataGrid` (or other listing component) is linked to this data loader, it displays only those records that match the full-text search criteria.

The full-text condition combines with any other filters applied to the data loader, providing refined result sets.

[[attributes]]
== Attributes

xref:flow-ui:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.
The following attributes are specific to `fullTextFilter`:

[cols="1h,7a,1",grid=rows,frame=none]
|===
|*Name*|*Description*|*Default*

|[[autoApply]]autoApply
| When set to `true`, the `FullTextFilter` component automatically applies itself to the `DataLoader` upon changes to its value.
|-
|[[dataLoader]]dataLoader
| `dataLoader` is a _required_ attribute. It sets a xref:flow-ui:data/data-loaders.adoc[data loader] related to the current `fullTextFilter`.
|-

|[[searchStrategy]]searchStrategy
|Determines the search strategy applied. See xref:search:search-in-ui.adoc#search-strategies[Search Strategies].
|`anyTermAnyField`

|===
