[[basic]]
== 基本用法

使用 Studio 添加组件至视图。

点击操作面板的 *Add Component*，找到 `SearchField` 然后双击。

image::create-search-field-component.png[align="center", width="692"]

[[settings-button]]
== 运行时配置

`searchField` 包含一个 *设置按钮*（垂直省略号 `⋮`），点击该按钮会打开一个配置对话框，用户可以在不修改 XML 的情况下动态调整搜索参数。

image::search-settings-dialog.png[align="center", width="483"]

用户可以在运行时配置以下选项：

[cols="2,2,4", options="header"]
|===
| 配置 | 对应属性 | 描述

| Search Strategy（搜索策略）
| <<searchStrategy,searchStrategy>>
| 确定搜索词的处理方式

| Size（数量）
| <<searchSize,searchSize>>
| 限制搜索结果的数量

| Entities（实体）
| <<entities,entities>>
| 指定要搜索的实体（可以选择多个实体）
|===

[[search-results-view]]
== 搜索结果视图

默认情况下，`searchField` 会打开内置的 `SearchResultsView`。该视图处理搜索引擎的查询过程，并根据 <<openMode,openMode>> 属性，在当前导航视图或对话框中显示结果。

[[searchCompletedHandler]]
如需修改此行为，需要配置一个 `SearchCompletedHandler`。可以通过 `@Install` 注解以声明方式，或使用 `setSearchCompletedHandler()` 以编程方式配置。

[[attributes]]
== XML 属性

xref:flow-ui:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `searchField` 的特殊属性：

[cols="1h,7a,1",grid=rows,frame=none]
|===
|*名称*|*描述*|*默认值*

|[[entities]]entities
| 指定要搜索的实体。多个实体可以用逗号分隔。

[source,xml,indent=0]
----
include::example$/search-ex1/src/main/resources/com/company/demo/view/search/my-search-view.xml[tags=search-field]
----
|-

|[[openMode]]openMode
| 指定 <<search-results-view,搜索结果视图>> 的打开模式。`NAVIGATION` 在主窗口打开；`DIALOG` 在模态窗打开。
|`NAVIGATION`

|[[searchButtonVisible]]searchButtonVisible
|设置是否显示搜索按钮。
|`true`

|[[searchSize]]searchSize
|设置搜索结果中一页显示的结果数量。
|默认使用 xref:search:search-properties.adoc#jmix.search.searchResultPageSize[jmix.search.search-result-page-size] 的配置。

|[[searchStrategy]]searchStrategy
|设置搜索策略。参阅 xref:search:search-in-ui.adoc#search-strategies[搜索策略]。
|`anyTermAnyField`

|[[settingsButtonVisible]]settingsButtonVisible
|设置是否显示设置按钮（`⋮`）。参阅 <<settings-button,运行时配置>>。
|`true`

|===
