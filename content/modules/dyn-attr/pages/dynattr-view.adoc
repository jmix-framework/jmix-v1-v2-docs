= Отображение динамических атрибутов

При создании нового экрана деталей или списка в проекте с установленным дополнением Dynamic Attributes фреймворк предоставляет возможность использования фасета <<using-dynamicattributes-facet,dynamicAttributes>> в XML-дескрипторах.

Другой метод отображения динамических атрибутов на экранах - использование <<dynamic-attributes-panel,DynamicAttributesPanel>>.

[[using-dynamicattributes-facet]]
== Использование фасета dynamicAttributes

Фасет `dynamicAttributes` позволяет отображать динамические атрибуты в `DataGrid` или `FormLayout`, связанных с контейнером данных, содержащим сущности с динамическими атрибутами.

Добавьте фасет `dynamicAttributes` в раздел `facets` XML-дескриптора экрана:

[source,xml,indent=0]
----
include::example$/dyn-attr-ex1/src/main/resources/com/company/demo/view/car/car-detail-view.xml[tags=dynamicAttributes]
----

Впоследствии вы можете выбрать этот экран в *Category attribute details* на вкладке xref:dyn-attr:dynattr-managing.adoc#visibility[Visibility].

[[dynamic-attributes-panel]]
== Использование DynamicAttributesPanel

Если сущность реализует интерфейс `Categorized`, у вас есть возможность использовать компонент `DynamicAttributesPanel` для отображения динамических атрибутов, связанных с сущностью. Этот компонент упрощает выбор категории для конкретного экземпляра сущности и указание значений для динамических атрибутов в этой категории.

Для интеграции компонента `DynamicAttributesPanel` в экран деталей выполните следующие шаги:

* Убедитесь, что атрибут `category` включен в фетч-план вашей категоризированной сущности:
+
[source,xml,indent=0]
----
include::example$/dyn-attr-ex1/src/main/resources/com/company/demo/view/car/car-detail-view.xml[tags=fetchPlan]
----
+
* Добавьте визуальный компонент `dynamicAttributesPanel` на экран:
+
[source,xml,indent=0]
----
include::example$/dyn-attr-ex1/src/main/resources/com/company/demo/view/car/car-detail-view.xml[tags=dynamicAttributesPanel]
----
+
