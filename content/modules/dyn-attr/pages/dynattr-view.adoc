= Отображение динамических атрибутов

При создании нового экрана деталей или списка в проекте с установленным дополнением Dynamic Attributes фреймворк предоставляет возможность использования фасета <<using-dynamicattributes-facet,dynamicAttributes>> в XML-дескрипторах.

Другой метод отображения динамических атрибутов на экранах - использование <<dynamic-attributes-panel,DynamicAttributesPanel>>.

[[using-dynamicattributes-facet]]
== Использование фасета dynamicAttributes

Фасет `dynamicAttributes` позволяет отображать динамические атрибуты в `DataGrid` или `FormLayout`, связанных с контейнером данных, содержащим сущности с динамическими атрибутами.

=== В экранах

Чтобы использовать динамические атрибуты в экране, включите фасет `dynamicAttributes` в раздел `facets` XML-дескриптора экрана:

[source,xml,indent=0]
----
include::example$/dyn-attr-ex1/src/main/resources/com/company/demo/view/car/car-detail-view.xml[tags=dynamicAttributes]
----

После добавления фасета вы можете выбрать этот экран в диалоге *Category attribute details* на вкладке xref:dyn-attr:dynattr-managing.adoc#visibility[Visibility].

[[dynamicAttributes]]
=== Во фрагментах

Фасет `dynamicAttributes` также может использоваться в xref:flow-ui:fragments/fragments.adoc[фрагментах].

Добавьте фасет в XML фрагмента:

[source,xml,indent=0]
.dynamic-attributes-fragment.xml
----
include::example$/dyn-attr-ex1/src/main/resources/com/company/demo/view/dynamicattributesfragment/dynamic-attributes-fragment.xml[]
----

Пример контроллера фрагмента:

.DynamicAttributesFragment.java
[source,java,indent=0]
----
include::example$/dyn-attr-ex1/src/main/java/com/company/demo/view/dynamicattributesfragment/DynamicAttributesFragment.java[tags=fragment-java]
----

Затем создайте экран, который использует этот фрагмент.

[CAUTION]
====
Фрагмент, использующий фасет `dynamicAttributes`, *должен иметь* идентификатор (ID). Вы можете установить его в xref:flow-ui:fragments/facets-in-fragment.adoc#facets-with-required-id[XML или программно].

При настройке xref:dyn-attr:dynattr-managing.adoc#visibility[видимости] динамических атрибутов идентификатор для экрана, использующего фрагмент, следует шаблону: `<view_ID>.<fragment_ID>`. Например, если экран с ID `DynAttrFacetView` содержит фрагмент с ID `xmlFragment`, полный идентификатор будет `DynAttrFacetView.xmlFragment`.

====

[[dynamic-attributes-panel]]
== Использование DynamicAttributesPanel

Если сущность реализует интерфейс `Categorized`, у вас есть возможность использовать компонент `DynamicAttributesPanel` для отображения динамических атрибутов, связанных с сущностью. Этот компонент упрощает выбор категории для конкретного экземпляра сущности и указание значений для динамических атрибутов в этой категории.

Для интеграции компонента `DynamicAttributesPanel` в экран деталей выполните следующие шаги:

* Убедитесь, что атрибут `category` включен в фетч-план вашей категоризированной сущности:
+
[source,xml,indent=0]
----
include::example$/dyn-attr-ex1/src/main/resources/com/company/demo/view/car/car-detail-view.xml[tags=fetchPlan]
----
+
* Добавьте визуальный компонент `dynamicAttributesPanel` на экран:
+
[source,xml,indent=0]
----
include::example$/dyn-attr-ex1/src/main/resources/com/company/demo/view/car/car-detail-view.xml[tags=dynamicAttributesPanel]
----
// +
// You can specify the number of columns to display dynamic attributes using the `cols` parameter. Or you can use the `rows` parameter to specify the number of rows (in this case, the number of columns will be calculated automatically). By default, all attributes will be displayed in one column.
// +
// image::dynamic-attribute-panel.gif[align=centre]
// +
// NOTE: On the xref:dyn-attr:dynattr-managing.adoc#attributes-location[Attributes location] tab of the category editor, you can more flexibly customize the position of the dynamic attributes. In this case, the values of the cols and rows parameters will be ignored.
