= Экспортеры

Интерфейс `DataGridExporter` предназначен для экспорта содержимого `DataGrid` в определенный формат и его загрузки. Экземпляр `DataGridExporter` передается в метод `setDataGridExporter()` действия xref:grid-export:actions.adoc[ExportAction].

`DataGridExporter` имеет две стандартные реализации:

* `ExcelExporter` используется в действии xref:grid-export:actions.adoc#excel-export-action[ExcelExportAction].

* `JsonExporter` используется в действии xref:grid-export:actions.adoc#json-export-action[JsonExportAction].
